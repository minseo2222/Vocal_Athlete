# PROTOTYPE — 레슨 UX 모바일 변주 (throwaway, sub-shape B)

## 질문
한 레슨(10–15분) *진행 화면*이 모바일에서 어떻게 보여야 하나? 무납득(운동 지시 cue만,
"왜" 없음)·막지 않는 완료+선택형 "다시?" 넛지·유성 마이크로윈·시각 피치 피드백·
레슨 해부(진입/본/쿨다운 스킵가능) 제약 하에서.

## 실행
```
python -m http.server -d prototypes/lesson-ui 8000
```
→ 브라우저 `http://localhost:8000/?variant=A` (모바일 폭으로 창 좁히거나 기기 에뮬레이션)
하단 흰 알약: ◀ / 라벨 / ▶, 또는 ← → 키로 변주 전환.

## 3안 (구조적으로 다름)
- **A 풀스크린 피치 캔버스** — 피치 곡선이 화면 전체, 크롬 최소, cue·넛지는 오버레이. 피드백 몰입 최대.
- **B 단계 카드 스택** — 진입→본운동→쿨다운 세로 스테퍼 카드 + 좌측 진행 레일, 피치는 본운동 카드 안. 구조·분절형.
- **C 코치 cue + 하단 시트** — 큰 운동 지시 cue가 중앙, 피치·완료·넛지는 끌어올리는 하단 시트. 대화형이되 "왜" 없음.
