# 프로토 결론

질문: ADR 결정 충돌이 한 타임라인에서 느낌이 맞는가?

## 검증 완료 (사용자 확인: "이 외 문제없음")
- 1일1레슨 캡 동작 OK
- 복귀 복습 7–14일→1 / >14일→2, 복귀일=복습이 그날 레슨, 신규 해금 다음날 OK
- 관대 스트릭: 공백에도 0 리셋·freeze 없음 OK (※ "영원히 안 깨짐"이 너무 물렁한지는 추후 체감 재확인 여지 — 현재는 OK)
- 졸업 → 비구속 장르 선택 → 미출시 유지 모드 → 출시 시 자동 연결 OK
- 졸업 후 장르 변경(비구속) OK

## 발견 + 해결
- **졸업 경계 ↔ 1일1레슨 캡 충돌**: 48과(=오늘 치 레슨)로 졸업한 *같은 날* 장르 선택 후
  레슨 시도 → 캡이 막으며 밋밋한 "이미 했음" 에러 → *데드엔드처럼 느껴짐*.
  코드 버그 아님(ADR-0003대로 정확). **메시징/어포던스 결함.**
- **결정: 옵션 1 (메시징만, 캡 불변).** 졸업/전이 순간은 *에러*가 아니라 *전이 화면*:
  - 졸업·장르 미선택 + 오늘 소진 → "🎉 경로 완주! 오늘 훈련 여기까지 — 장르 고르고 내일부터"
  - 장르 선택한 같은 날 → "🎉 전이 완료 — 오늘 훈련 끝(졸업 레슨). 내일 [다음] 1과부터"
  - 다음날 → 정상 진행(유지/중급 1과)
  progression.py에 `transition_day` 1필드로 반영, 3경로 검증 통과.

## 결론
상태머신 = ADR대로 정확. 유일한 실제 이슈는 *졸업일 캡 충돌의 표현*이었고
옵션 1(전이 메시지)로 해소. ADR-0003 불변, ADR-0010(통합 전이)에 메시징 규칙 추가.
→ 검증된 progression.py 로직(특히 `transition_day` 패턴)은 실코드로 흡수 가능. TUI는 폐기.
