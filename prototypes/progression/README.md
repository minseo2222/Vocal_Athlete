# PROTOTYPE — 진행 상태머신 (throwaway)

## 질문
잠긴 ADR 결정들이 *한 타임라인에서 충돌*할 때 느낌이 맞는가?
완료 기반 해금 · 1일1레슨 캡 · 관대 스트릭(0 리셋·freeze 없음) ·
복귀 복습(7+일 공백 → 1 or 2일, 복귀일=복습이 그날 레슨, 신규 해금 다음날) ·
졸업(경로 완주) → 통합 전이(축하→비구속 장르 선택→출시됐으면 진입/아니면 유지 모드→출시 시 자동 연결) ·
유지 모드(직전 코스 스킬 반복, 스트릭 유지, 신규 해금 없음).

## 실행
```
python prototypes/progression/tui.py
```
키 + Enter. `l`레슨 `n`다음날 `s`N일건너뜀 `g`장르선택 `r`중급출시토글 `x`초기화 `q`종료.

## 밀어볼 충돌 지점
- 같은 날 `l` 두 번 → 캡
- `s`로 3일 / 8일 / 20일 공백 만든 뒤 `l` → 복귀 복습 0 / 1 / 2일 차이 체감
- 1–6일 공백을 반복 → *스트릭이 절대 안 깨짐*이 너무 물렁한가?
- `l` 48회로 졸업 → `g` 장르 선택 → 미출시면 유지 모드 → `r`로 출시 → 자동 연결
- 졸업 후 `g`로 장르 바꿔보기(비구속)

`progression.py`는 검증되면 실코드로 들어갈 순수 모듈. `tui.py`는 버림.
