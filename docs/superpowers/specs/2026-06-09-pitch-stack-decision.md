## 1. 특성화 — 현 f0의 정량 거동 (D1, 실측)

측정 하네스: `app/test/f0_characterization_test.dart` (sr=16000, frame=2048, 합성 신호).

### 1a. 깨끗한 사인 — cents 오차 (정수 lag 양자화)
| f0(Hz) | 추정(Hz) | 오차(cents) |
|---|---|---|
| 110 | 110.3 | +5 |
| 131 | 131.1 | +2 |
| 165 | 164.9 | −1 |
| 220 | 219.2 | −6 |
| 330 | 333.3 | +17 |
| 440 | 444.4 | +17 |
| 523 | 516.1 | −23 |
| 659 | 666.7 | +20 |
| 880 | 888.9 | +17 |

→ **저음(≤220Hz)은 ≤6c로 양호, 고음(330~880Hz)은 ±17~23c**. 최악 ~23c(반음=100c 이내). 원인은 lag가 정수라 고음일수록 주기 샘플 수가 적어 해상도가 거침. **포물선 보간으로 <10c로 개선 가능**.

### 1b. 배음많음 / 잃은 기음 / SOVT 버즈 — 옥타브·검출
| 신호 | 131Hz | 220Hz | 440Hz |
|---|---|---|---|
| harmonics(f0+2·3·4배음) | 정확 | 정확 | 정확 |
| missingFundamental(2f0·3f0만) | 정확 | 정확 | 정확 |
| sovtBuzz(피치+강배음+30Hz AM) | 정확 | 정확 | 정확 |

→ **옥타브 오류 미관측.** naive 자기상관이 (적어도 이 합성 신호들에선) 옥타브-강건. ⚠️ 단 *실제 숨소리·기식 섞인 비기너 입력*은 합성으로 재현 못 해 **미측정 = 잔여 갭**(기기 검증 시 실측 필요).

### 1c. 잡음 / 무음 — 신뢰 게이트 부재
- 백색잡음 5프레임 → **5/5 spurious f0 반환**(82, 198, 552, 232, 314 Hz).
- 무음 → null(에너지게이트 정상).

→ **실질 최대 약점: 신뢰 게이트 없음.** 에너지만 있으면(잡음·기식·언보이스드) 명확한 주기가 없어도 `bestCorr>0`이라 *아무 f0나* 반환. 비기너의 불안정·숨소리 입력에서 **틀린 점이 떠다님** — 시각 전용 비차단 피드백(ADR-0002/0014)의 "틀린 피드백 회피" 원칙과 충돌.

### 1d. 종합
| 항목 | 현 상태 | 심각도 | 해법 |
|---|---|---|---|
| 고음 양자화 오차 ~23c | 보간 없음 | 중 | 포물선 보간 |
| 옥타브 오류 | (합성상) 강건 | 낮음 | 정규화로 안전망 |
| 잡음/언보이스드 spurious | 신뢰게이트 없음 | **높음** | 정규화(NSDF/CMNDF)+신뢰 임계→null |
| 타깃 220 하드코딩 | 카드 무관 | 중 | 카드별 타깃 주입 |
| 단일 점(곡선 아님) | — | 낮음(UX) | _recent 버퍼로 스크롤 곡선(선택) |

## 2. 옵션 3안 + 추천 (D2)

| 안 | 정확도 | 노력 | 빌드 리스크 | ADR/제약 적합 |
|---|---|---|---|---|
| **A. Dart 자기상관 하드닝** (포물선 보간·정규화 신뢰게이트·옥타브 안전망·카드 타깃 주입) + ADR 정직 개정 | 시각전용 비차단엔 충분(보간 후 <10c, 저신뢰=미표시) | **소~중**(순수 Dart, 기존 인터페이스) | **없음**(네이티브 0) | 높음 — ADR-0014 저신뢰 미표시·시각전용과 정확히 정합 |
| B. pYIN (Dart 포팅 또는 FFI/C) | 최상급 | 대 | **높음** — record_linux처럼 네이티브 의존이 이 스택 빌드를 깨뜨린 이력; FFI는 플랫폼별 빌드·CI 복잡 | ADR 문구와 일치하나 기기검증 미완 단계 고비용 |
| C. CREPE / tflite (ML) | SOTA | 최대(모델 ~수MB·추론 perf·배터리) | 높음(tflite 네이티브) | 과함 — 비차단 시각 피드백에 SOTA 불필요 |

### 추천: **A (자기상관 하드닝 + ADR 정직 개정)**
근거:
1. **실질 최대 약점(잡음 spurious)을 정면 해결** — 정규화 자기상관(NSDF/CMNDF)의 clarity 값으로 신뢰 임계를 두면 언보이스드/잡음/기식 입력은 **점을 안 띄움**. 이게 비기너 안전(틀린 피드백 회피)과 ADR-0014(저신뢰 미표시)에 정확히 부합.
2. **고음 양자화(23c)는 포물선 보간으로 반음 이하**로.
3. **옥타브는 측정상 이미 강건** → 고비용 알고리즘의 주 이점(옥타브 처리)이 현 단계 결정적이지 않음.
4. **네이티브 0 = 빌드 리스크 0** — record_linux 교훈(네이티브 의존이 빌드를 깨뜨림). FFI/tflite는 Android/iOS·CI 복잡도↑.
5. **시점** — 마이크 기기검증조차 미완인데 pYIN/CREPE 고비용 투자는 시기상조. `PitchSource`/`estimateF0`가 **교체 seam**이라, 실 기기 데이터로 A가 부족함이 *입증*되면 그때 B/C로 승급(인터페이스 불변).

→ B/C는 "정확도 부족이 실 사용자 검증으로 드러날 때의 **타깃**"으로 보류.

## 3. ADR-0014 개정 **초안** (제안 — 비준 전) (D3)

> 원 ADR-0014가 "pYIN 온디바이스(C via FFI)"를 단정하나 구현은 자기상관이고 측정상 A가 합리적. 아래는 *교체 제안 초안*이며, 사람 비준 시 docs/adr/0014에 반영.

```
# ADR-0014 (개정 제안): V1 피치 검출 = 온디바이스 자기상관 + 보간 + 신뢰 게이트

Status: 개정 제안(2026-06). 원안의 "pYIN C via FFI" 단정을 대체.

Decision:
- V1 피치 = 온디바이스 **Dart 자기상관 + 포물선 보간 + 정규화 신뢰 게이트**.
- 시각 전용·비차단. **저신뢰(언보이스드·기식·잡음)는 표시하지 않음**(틀린 점 ❌).
- 카드별 목표음을 타깃으로 주입(220 하드코딩 제거).
- pYIN/CREPE는 정확도 부족이 *실 기기 사용자 검증*으로 드러날 때의 **타깃**.
  PitchSource/estimateF0 인터페이스를 교체 seam으로 유지.

Rationale (측정 근거):
- 특성화(f0_characterization_test): 옥타브 강건, 고음 양자화 ~23c(보간으로 <10c),
  잡음 spurious 5/5(신뢰 게이트로 해결). 비기너 안전 = 틀린 피드백 회피.
- 네이티브 의존 빌드 리스크 회피(record_linux 교훈). 기기검증 미완 단계 고비용 회피.

Consequences:
- 정확도 SOTA 아님 — 그러나 시각 전용 비차단엔 충분. 신뢰 게이트가 "틀린 점보다
  없는 점"을 보장(ADR-0002/0014 정합). 실 기기 데이터가 반증하면 B/C 승급 경로 열림.
```

## 4. 후속 구현 plan **초안** (비준 후 별도 goal)
경로 무관 견고화(어느 방향이든 유효):
1. `estimateF0` — (a) 정규화 자기상관(NSDF 또는 CMNDF)으로 clarity 산출 + **신뢰 임계(저신뢰→null)**, (b) bestLag 부근 **포물선 보간**(sub-lag), (c) 옥타브 안전망(½·2× lag 비교). TDD: 특성화 테스트를 회귀 가드로 강화(보간 후 고음 <10c·잡음 null 비율↑).
2. `pitch_display` — `targetHz`를 카드/레슨에서 **주입**(card에 targetHz 필드 또는 lesson 전달), 220 하드코딩 제거. 저신뢰 null → 점 미표시 유지.
3. (선택) 단일 점 → `_recent` 버퍼로 짧은 **스크롤 곡선**(UX).
4. 실 기기 마이크 검증과 연계 — 실 입력에서 A의 신뢰게이트·정확도 실측(현 미측정 갭 1b).
