# 01-B 온보딩·안전·법무

**대상**: 제품 매니저·법무·의료 자문위원회·운영팀
**범위**: 학습자가 앱에 *진입하는 순간*부터 *위험 상황 처리*·*데이터 보호*까지의 전 라이프사이클.

> 본 앱은 *교육*이지 *치료*가 아니다. 강사 부재·자가주도 모델에서 학습자 안전과 법적 책임은 *앱 운영자*와 *콘텐츠 검수 위원회*가 진다. 본 문서는 그 책임 구조를 정의한다.

---

## 1. 콘텐츠 검수 위원회 (강사 자격 대체 메커니즘)

### 1.1. 구성 (최소)
- **음성언어치료사 (SLP) 1+명** — 한국 후두학회 또는 대한언어재활사협회 회원
- **보컬 페다고지 박사·석사 1+명** — Journal of Singing 또는 KCI 등재 학술지 게재 경력
- **음성과학 연구자 1+명** — 음성학·음향학 전공
- **의료 자문 (이비인후과 1+명, 자문 계약)** — 적색 신호 트리거 검증·의료 의뢰 라인

### 1.2. 책임 범위
- 모든 훈련 카드 콘텐츠 검수·승인
- 분기별 콘텐츠 갱신 (의학 가이드라인·새 RCT 반영)
- 적색 신호 트리거 로직 검토
- 학습자 의료 의뢰 라인 관리
- 본 앱 *내부 evidence base* 축적·평가 (사용자 코호트 분석)

### 1.3. 갱신 주기
- 콘텐츠 분기 점검 (3개월)
- 신규 RCT·메타분석 반영 (6개월)
- 본 앱 자체 evidence base 보고서 (연 1회)

## 2. 온보딩 플로우 (5–10분, 첫 실행 시 의무)

### 2.1. 단계별 흐름

```
1. 환영 화면 (15초)
   └ 본 앱이 무엇을 *하지 않는지* 명시: "본 앱은 의료기기가 아닙니다"

2. 연령 게이트 (필수)
   └ "만 18세 이상입니까?" Y/N
       Y → 다음
       N → 미성년자 차단 화면 + 보호자 동의 모듈 (V2)

3. 의료 동의서 + 면책 (필수)
   └ §3 참조. 스크롤 끝까지 읽고 체크박스 + 서명(이름 입력)

4. 의학 이력 설문 (필수, 기본)
   └ 결절·폴립·MTD·LPR·천식·알레르기·수술 이력
   └ 약물 복용 (항히스타민·일부 항정신약·코르티코스테로이드 흡입)
   └ "현재 진단·치료 중이신가요?" Y → §4 진단 보유자 정책

5. 가창 목표·배경 설문 (선택, 추천 시스템용)
   └ 트랙: 클래식 / 뮤지컬 / CCM / 미정
   └ 경력: 입문 / 합창 경험 / 학원 경험 / 자가 학습
   └ 일주일 발성 사용량 (말소리 부하 산정)

6. 환경 분석 (필수, §5 참조)
   └ 마이크·노이즈·잔향 자동 측정

7. 베이스라인 측정 (필수)
   └ EASE 22문항 (5분)
   └ VHI-10 (3분)
   └ 표준 샘플 녹음 (3분, P7-01 SOP)

8. 적색 신호 학습 (필수, 30초)
   └ 5개 신호 시각 + 음성 안내, 학습자가 *암기 확인*
   └ "다음 5개 중 어느 것이 적색 신호입니까?" 퀴즈 1회

9. Phase A Day 1 추천
   └ 첫 일일 세션 진입
```

### 2.2. 온보딩 미완료 처리
- 의료 동의서·연령 게이트·환경 분석·적색 신호 학습은 *건너뛰기 불가*
- 의학 이력 설문·목표 설문은 건너뛰기 가능 (나중에 입력)
- 표준 샘플 녹음은 *권장*, 건너뛰면 진행 일부 제한

## 3. 의료 동의서 + 면책 (학습자에게 표시될 정확한 문구)

> 본 문구는 한국 의료법·교습소법·개인정보보호법 검토를 거친 *법무 검수 후* 최종 확정. 본 문서엔 초안.

### 3.1. 핵심 명시 사항

```
본 앱(이하 "본 앱")은 다음을 알립니다:

1. 본 앱은 의료기기가 아닙니다. 본 앱은 음성 진단·치료를 제공하지 않습니다.
2. 본 앱의 모든 콘텐츠는 *교육 목적*이며, 음성언어치료(speech therapy)·이비인후과 진료를 *대체하지 않습니다*.
3. 본 앱의 AI 분석은 *참고 도구*이며, 의료 진단의 근거가 될 수 없습니다.
4. 본 앱이 제공하는 적색 신호 안내는 *의료 의뢰 시기 안내*이며, 진단이 아닙니다.

이용자는 다음을 이해하고 동의합니다:

A. 다음 신호 발생 시 *즉시 본 앱 사용을 중단하고 이비인후과를 방문*해야 합니다:
   - 2주 이상 지속되는 쉰 목소리
   - 발성 시 지속적 통증
   - 객혈·가래 혈흔
   - 호흡곤란·흡기 천명
   - 갑작스러운 음성 상실

B. 본 앱 사용 중 발생할 수 있는 음성 손상에 대해 본 앱 운영자는
   *과실 없는 한* 책임을 지지 않습니다. 학습자는 자기 위험으로 사용합니다.

C. 다음 학습자는 본 앱 사용 *전 의료 전문가 상담을 권장*합니다:
   - 현재 결절·폴립·MTD·후두 수술 이력
   - 천식·만성 LPR
   - 임신 후기·산후 6주 이내
   - 항히스타민·코르티코스테로이드·기타 음성 영향 약물 복용 중

D. 본 앱은 만 18세 이상 성인 사용자를 대상으로 합니다.
   미성년자는 보호자 동의 모듈(V2 출시 예정) 이전엔 사용 불가입니다.

[ ] 위 내용을 모두 읽고 이해했으며 동의합니다.
이름: ________________  날짜: ________________
```

### 3.2. 동의서 갱신
- 콘텐츠 검수 위원회 결정 시 (의학 가이드라인 변경 등)
- 사용자에게 푸시 알림 + 재동의 요구
- 재동의 미완료 시 앱 일부 기능 잠금

## 4. 진단 보유 학습자 정책

### 4.1. 입학 거부 조건 (절대)
- 활성 출혈성 폴립
- 6개월 이내 후두 수술 이력 (단, 의료 진단서 첨부 시 검토)
- 진행성 신경학적 음성 장애
- 활성 후두암 진단·치료 중

### 4.2. 조건부 입학 (의료 동의 + 자가 책임)
- 결절 (안정 상태, SLP 동시 진료 중인 경우)
- LPR (안정 상태, 약물 관리 중)
- MTD (안정 상태, 음성 치료 동시 진행 중)

→ 위 조건자는 온보딩에서 **별도 동의서 추가 + SLP 협진 권고** 강제 표시.

### 4.3. 입학 거부 화면 (UX)
- 거부 사유 명시 (학습자 자신만의 의료 정보로)
- 한국 후두음성언어의학회 / 대한언어재활사협회 협력 의료기관 리스트 제공
- "의료 안정 후 재신청 가능" 안내

## 5. 환경 분석 모듈 (온보딩 + 분기별 재실행)

### 5.1. 측정 항목

| 항목 | 측정 방법 | 기준값 | 학습자 안내 |
|---|---|---|---|
| 방 노이즈 | 5초 무음 녹음 → SPL 추정 | < 35 dB SPL | "조용한 방에서" |
| 마이크 모델 | 시스템 메타데이터 | 클래스별 정확도 매핑 | "당신 마이크는 ____ 클래스" |
| 마이크 거리 | F0 sustain 시 SPL 추세 | 15–30 cm | "휴대폰을 X cm 거리에" |
| 잔향 (RT60) | 박수 1회 후 감쇠 | < 0.5s | "잔향이 큰 방은 정확도 ↓" |

### 5.2. 정직성 표기

학습자에게 *모델별 정확도 한계*를 직접 노출:

```
당신 환경 분석 결과:
✓ 방 노이즈: 32 dB SPL (양호)
⚠ 마이크: iPhone 14 내장 마이크
   - F0(피치) 측정 신뢰도: 높음
   - jitter/shimmer 측정 신뢰도: ⚫ 낮음
     (Manfredi 2017 / PMC 검증 데이터 [CITE: MANFREDI2017])
✓ 마이크 거리: 22 cm (적정)
✓ 잔향: 0.3s (양호)

→ 본 앱은 위 한계를 *정직하게 반영*하여 점수를 산정합니다.
   완전한 음성 평가는 임상 마이크 환경(이비인후과)에서만 가능합니다.
```

이 *정직성 표기*가 본 앱의 핵심 차별화. 컨슈머 앱들이 안 함.

## 7. 잘못된 폼 자동 감지

### 7.1. 1차 신호 (영상 분석 — 카메라 사용 시 옵션)
- 어깨 들기 (드래그 픽셀 분석)
- 턱 과도한 움직임
- 자세 무너짐 (척추-목 정렬 이탈)

### 7.2. 2차 신호 (음향 분석)
- F0 변동 ±20 cents 초과 (sustain 카드)
- 음량 변동 ±5 dB 초과
- 비주기성·strain 신호 (CPPS 급락)
- sustain 길이 미달

### 7.3. 누적 신호 처리
- 3회 연속 실패 → 도움말 영상 강제 노출
- 7일 연속 실패 → 페이즈 진행 잠금
- 14일 연속 실패 → SLP 의뢰 권유

→ "더 잘하라" 압박 ❌. "당신과 안 맞을 수 있다, 다른 접근을 시도해보자" 톤.

## 8. 데이터 프라이버시·개인정보 보호 (한국 개인정보보호법)

## 9. 의료기기·약사법·교습소법 검토 (운영 전 법무 의무)

### 9.1. 의료기기법
- 본 앱이 *의료기기로 분류되지 않도록* 모든 마케팅 문구·UI 검토
- "진단", "치료", "회복" 단어 사용 금지 (교육·훈련·연습으로)
- AI 분석 결과는 *참고*로만 표시, *진단 점수* ❌

### 9.2. 약사법
- 약물·보충제 추천·판매 금지
- 수분·영양 가이드는 *일반 정보*로만 (특정 제품 추천 ❌)

### 9.3. 교습소법
- 본 앱은 *물리적 교습소*가 아니므로 신고 의무 없음
- 단, 1:1 라이브 코칭 V3+ 도입 시 *원격 교습소* 검토 필요

### 9.4. 광고 표시법
- 효능 과장 ❌
- "벨트 마스터", "고음 보장" 등 결과 약속 ❌
- "RCT 검증된 SOVT 운동" 같은 *근거 명시* ✓

## 10. 운영 정책

### 10.1. 인시던트 대응 (학습자 손상 발생 시)
- 24시간 이내 콘텐츠 검수 위원회 보고
- 위원회 검토 후 콘텐츠 수정·잠금 결정
- 손상 학습자에 대한 *연결*만, 의료비 부담 ❌
- 패턴 발생 시 (3+ 학습자 같은 콘텐츠로 손상) 콘텐츠 즉시 잠금

### 10.2. 환불 정책
- 30일 이내 무조건 환불
- 30일 후 적색 신호 자동 트리거로 사용 중단 시 잔여 비례 환불

### 10.3. 사용자 신고
- 콘텐츠 오류 신고 → 위원회 24시간 내 검토
- 의료 안전 관련 신고 → 즉시 처리
