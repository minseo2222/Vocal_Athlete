# 01-A 앱 콘텐츠 사양서 — 초급 (0–6개월)

**대상**: 콘텐츠 제작팀 (영상·오디오·UI/UX·QA)
**전제**: `curriculum/01 초급 공통 커리큘럼.md` 의 *훈련 정의*를 *앱 콘텐츠*로 변환.
**범위**: Phase A·B·C 전 14개 훈련 카드 + UI 플로우 + 게이미피케이션 + 적응형 진도.

> 본 문서는 *학습자가 보고·듣고·따라하는 모든 자료*의 사양서다. AI 분석 사양은 `01-C`에, 온보딩·법무는 `01-B`에 분리.

---

## 1. 콘텐츠 제작 표준 — 모든 훈련 공통

### 1.1. 영상 표준

| 항목 | 사양 |
|---|---|
| 해상도 | 1920×1080 (16:9), 60fps (느린 동작 정밀 시현) |
| 길이 | 30–90초 (한 카드당), 마이크로 클립 |
| 각도 | **정면 + 측면 + 클로즈업** 3종 동시 제공 (학습자가 선택) |
| 자막 | 한국어 + 영어 (선택), 음소거 시 절차 이해 가능해야 함 |
| 배경 | 단색·무 패턴, 시각 노이즈 최소화 |
| 모델 시연자 | SLP 또는 인증된 보컬 교사. 의료 자문위원 검수 필수 (`01-B` §콘텐츠 검수 위원회) |
| 화면 표시 | 우상단 *훈련명*, 우하단 *경과 시간*, 좌하단 *근거 등급 배지* |

### 1.2. 오디오 가이드 표준

- **음성 가이드 톤**: 차분·중립. 동기부여 톤 `❌` (부하 ↑ 압박 위험)
- **카운트**: "들숨 사·삼·이·일… 날숨 사·삼·이·일…"
- **격려·교정 트리거 문구**: 사전 정의 (§1.5)
- **음원 분리 트랙**: 가이드 음성 / 메트로놈 / 참조 음원 분리 — 학습자가 토글

### 1.3. "이렇게 하지 마세요" (Anti-pattern) 영상

각 훈련 카드마다 흔한 오류 **3–5종**:
- 5–10초 짧은 클립
- 빨간 X 오버레이 + "왜 잘못된지" 1줄 자막
- 학습자 자가 거울 비교 가능

### 1.4. 참조 음원 라이브러리

- 정상 시연 (balanced)
- 잘못된 시연 (breathy / pressed / strained)
- A/B 슬라이더 비교 UI

### 1.5. 사전 정의 격려·교정 문구 (음성 가이드용)

```
[안전 트리거]
- "어지러우면 즉시 멈추세요"
- "통증이 느껴지면 중단하고 다음 페이즈로"
- "오늘 컨디션이 5점 이하라면 강도를 절반으로"

[격려 (안전 방향)]
- "충분합니다. 더 크지 않게."
- "오늘은 여기까지. 내일 다시."
- "느낌이 좋다면 그대로 유지하세요."

[금지 문구 ❌]
- "더 크게!", "한 번 더!", "끝까지 가보세요" — 부하 ↑ 압박
```

## 2. 자가 관찰 체크리스트 표준

각 훈련 *직후* 표시. 4–6개 Y/N 문항. 응답에 따라 분기:

| 응답 패턴 | 앱 동작 |
|---|---|
| 모두 ✓ | 다음 훈련 잠금 해제 |
| 1개 ✗ | 도움말 영상 + 재시도 권유 |
| 2+ ✗ | 페이즈 진행 정지, 강사 연결 권유 또는 1주차 후퇴 |
| "어지럼" / "통증" 응답 | 즉시 P8-12 적색 신호 플로우 (`01-B` §의료 의뢰 트리거) |

## 3. UI 플로우

### 3.1. 첫 실행 (온보딩)
세부는 `01-B` 참조. 요약:
1. 연령 게이트 (18+)
2. 의료 동의서
3. 베이스라인 설문 (EASE, VHI-10, 의학 이력)
4. 환경 분석 (마이크·노이즈)
5. 표준 샘플 베이스라인 녹음
6. Phase A Day 1 추천

### 3.2. 일일 세션 (대표 60분 또는 짧은 세션 옵션)

```
[App 진입]
  ↓
[Daily 컨디션 게이트] (5분 — 매번 필수)
  - 1–10 척도
  - 적색 신호 11개 (응급 A·신속 ENT B·두경부 방사선 C 분기) 자가 체크
  - 적색 신호 양성 → P8-12 플로우로 즉시 분기
  ↓
[오늘 추천 세션] (앱 자동 결정, 학습자 변경 가능)
  - 세션 길이 옵션: 15분 / 30분 / 60분
  - 60분 = 전체 페이즈 표준 구조
  - 15분 = SOVT 워밍업만 (바쁜 날 모드)
  ↓
[훈련 카드 1] → 영상 → 가이드 → 자가 관찰
[훈련 카드 2] → ...
  ↓
[쿨다운] (5분, 매 세션 의무)
  ↓
[자기보고]
  - VAS 1–10 (피로·노력감)
  - 격주 EASE / 분기 VHI-10
  - 메모 입력 (선택)
  ↓
[녹음] (주 1회, 표준 샘플 P7-01 압축본)
  ↓
[일일 진도 카드 + 다음 추천]
```

### 3.3. 화면 표준 컴포넌트

- **상단 진도 바**: Phase A/B/C × 주차 (1–24)
- **하단 안전 핑거프린트**: 컨디션 게이트 통과 시각, 누적 부하, 다음 휴식일
- **근거 등급 배지**: 매 훈련에 RCT/feasibility/observational/tradition 4단 색상 코드
  - 🟢 RCT — SOVT, VFE, Alexander
  - 🟡 Feasibility — CVT 모드 적용 시
  - 🟠 Observational — Bel Canto·Miller 류
  - ⚫ `[근거 부족]` — 컨슈머 마이크 정확도 등

## 5. 풀 예시 — 빨대 발성 (P3-13)

```yaml
훈련명: 빨대 발성 / Straw Phonation
훈련ID: P3-13
페이즈: B
주차 범위: 9-10 (도입), 11-24 (지속)
근거 등급: 🟢 RCT
인용 키: [CITE: TITZE2006SOVT] [CITE: ANDRADE2024]

시각 콘텐츠:
  - 정면 영상: 45s — 학습자 정면, 빨대 잡는 법·입술 봉인 시현
  - 측면 영상: 30s — 자세·턱 위치 측면 시현
  - 클로즈업: 30s — 입·빨대 접촉부, 호흡 흐름
  - Anti-pattern (5종):
    1. 빨대 이로 물기 ❌
    2. 어깨 들기 ❌
    3. 음정 지나치게 변동 ❌
    4. 강도 너무 큼 (귀에 거슬리는 짜내는 소리) ❌
    5. 5분 초과 지속 ❌

오디오 콘텐츠:
  - 음성 가이드 스크립트:
    "빨대를 입술 안에 부드럽게 물어주세요. 이로 물지 마세요.
     자연스럽게 호흡 한 번… 들숨 사·삼·이·일.
     빨대를 통해 부드러운 /u/ 소리, 5초 sustain.
     음정은 편한 중음으로. 어지러우면 즉시 멈추세요.
     ... (계속)"
  - 카운트 트랙: 4초 들숨 + 5초 sustain × 5회
  - 참조 음원:
    - balanced_straw.mp3 — 균형 발성
    - breathy_straw.mp3 — 과기식
    - pressed_straw.mp3 — 과압착

절차:
  1. 일반 음료 빨대 (직경 5–6mm) 준비
  2. 빨대 한쪽 끝을 입술 안에 부드럽게 봉인 (이 ❌)
  3. 자연스러운 호흡 한 번
  4. 들숨 4초 후 빨대 통해 부드러운 /u/ 5초 sustain
  5. 5세트 반복
  6. 빨대 제거 후 같은 음으로 /u/ 모음 (carryover)

자가 관찰 체크리스트:
  - [ ] 어지럽지 않았다
  - [ ] 입술이 빨대를 부드럽게 봉인했다 (이로 물지 않음)
  - [ ] 5초 sustain 가능했다
  - [ ] 음정이 안정적이었다 (큰 변동 없음)
  - [ ] 강도가 편안했다 (짜내는 느낌 없음)

AI 분석 항목 (01-C 참조):
  - F0 안정성 (cents 변동)
  - 음량 일관성 (dB 변동)
  - jitter — 마이크 한계 자동 경고 (Manfredi 2017 [CITE: MANFREDI2017])
  - sustain 길이 (초)

잘못된 폼 자동 감지 트리거:
  - F0 ±20cents 이상 변동 (목표 음에서)
  - 음량 ±5dB 이상 변동
  - sustain 3초 미만
  - 5분 초과 지속 시 자동 알림

진도 잠금 조건:
  - 체크리스트 5개 중 4+ 7일 연속 만족
  - 미달 시 도움말 영상 + 재시도 권유

게이미피케이션:
  - 배지: "빨대 입문" (3일 연속 4+ 체크), "빨대 마스터" (14일 연속 5/5)
  - 일일 streak: 포함

안전 한계:
  - 한 세트 5분 이내
  - 즉시 중단 조건:
    - 어지럼·시야 흐림
    - 가슴 통증
    - 음정 통제 불가
```

## 7. 적응형 진도 (Adaptive Pacing)

강사 부재로 *앱이 자동으로* 컨디션 따라 부하 조정. 3가지 입력으로 결정:

### 입력
1. **EASE 점수** (격주) — 피로·노력감
2. **컨디션 게이트** (매일) — 1–10 주관 점수
3. **자가 관찰 체크리스트** (매 훈련) — 통과/미달

### 조정 로직 (예시 규칙)

| 신호 | 앱 동작 |
|---|---|
| EASE 점수 직전 대비 +20% ↑ | 다음 7일 부하 자동 −30% |
| 컨디션 ≤ 5점 3일 연속 | 페이즈 진행 정지, 휴식·구조적 의뢰 권유 |
| 자가 관찰 2+ ✗ 3회 연속 | 도움말 영상 강제 노출 + 강사 연결 권유 |
| 적색 신호 11개 (응급 A·신속 ENT B·두경부 방사선 C 분기) 중 1+ | 즉시 중단 + 의료 의뢰 (`01-B`) |
| 7일 미접속 | 복귀 시 전 주차로 자동 후퇴 |
| 표준 샘플 비교 호전 ❌ (월 단위) | 페이즈 연장 |

→ "더 빠른 진행" 트리거는 *없음*. 우리 앱은 "더 안전하게"만.

## 8. 게이미피케이션 + 지루함 해소·동기 시스템 (안전 방향)

> 페다고지 토대: `curriculum/01 초급 공통 커리큘럼 §13 훈련 변이 정책` (Schmidt & Lee 2019 [CITE: SCHMIDT_LEE2019] blocked vs random 원리). 본 §은 그 운영 사양.

### 8.1. 허용 패턴 — 습관 형성·정확성·성장 가시화

- **일일 streak** — 연속 접속·SOVT 워밍업·자가보고 (부하 ↑이 아닌 *습관 형성*)
- **배지** — 자가 관찰 체크리스트 통과 누적 (정확성 보상)
- **주간 챌린지** — "이번 주 SOVT 5분 × 7일" (반복 보상)
- **1주차 vs 현재 비교 카드** (성장 가시화) — 매주 자동 A/B 표준 샘플 비교
- **변이 5축 진척 표시** (커리큘럼 §13.2) — *오늘의 변이* 추천: 음역/모음/글라이드/멜로디/세션 위치
- **자기 곡 라이브러리** (11주차+) — 학습자 자기 곡 1곡 등록 시 SOVT 모방용 *조옮김 자동 감지*·*1옥타브 안전 음역* 표시 (§5.9)

### 8.2. 지루함 해소 사양 — 5가지

1. **도구 자율 선택** — 매 세션 시작 시 *오늘 어떤 SOVT 도구로 시작할까?* 학습자 선택. 단, 그 주의 *신규 도구 의무 시간*(예: 11주차 립 트릴 5분) 보장.
2. **변이 추천 엔진** — 학습자가 같은 음역·같은 모음 *3일 연속* 사용 시 *오늘은 음역 변이 시도* 자동 제안 (§13.2 5축 기반 회전).
3. **자기 곡 도입** (11주차+) — `curriculum §5.9` 학습자 자기 곡 SOVT 모방 모듈. 곡 등록·조옮김 자동·가드레일(belt·고음·distortion 곡 ❌).
4. **진도 시각화** — 1주차 표준 샘플 vs 매주 자동 A/B + *내가 못했던 것이 가능해진* 카드 푸시 (CPP·MPT·sustain 시간 등 향상 자동 감지).
5. ***반복의 학술 정당화* 마이크로 강의** — 학습자 첫 주 영상 1편 (90초): "왜 같은 빨대 발성을 며칠 반복하나? Fitts & Posner cognitive 단계의 학술 근거". 학습자가 *반복 = 학술 검증된 자동화 과정*임을 이해하면 지루함이 *동기*로 전환.

### 8.3. 페이즈별 변이 비율 (커리큘럼 §13.5 매핑)

| Phase | Blocked 비율 | Variable 비율 | 앱 동기 메시지 |
|---|---|---|---|
| **A** (1–8주) | 80% | 20% (음역만) | "지금은 *몸에 새기는* 시기" |
| **B** (9–16주) | 60% | 40% (음역·모음·멜로디) | "변이가 retention 만든다" |
| **C** (17–24주) | 40% | 60% (5축 + 적용곡) | "이제 *내 곡*으로" |

### 8.4. 금지 패턴 ❌

- "더 크게·더 길게·더 높게" 트리거 — 부하 ↑ 압박
- 음역 확장 보상 — 24주는 *현 음역 안에서* 학습
- 고난도 곡 도전 보상 — 자기 곡 등록은 *1옥타브 안전 음역*만
- 다른 사용자와 *수치 비교* 리더보드 — 불안 유발 + 부하 ↑ 압박
- 자기 곡 *원곡 음역 따라하기* 강요 — 조옮김 자동 + 학습자 음역 우선
- *연속 접속 못하면 streak 0* 페널티 — 자가주도 학습자 빈도 다양 (M4 적응형 진도 정책)

### 8.5. 사용자 경험 원칙

- **반복 ≠ 단조** — 같은 운동의 *5축 변이*로 표면을 바꿈
- **자율 + 가드레일** — 학습자 도구·곡 선택권 + 앱이 학술 안전성 보장
- **과학 교육으로 동기** — 게이미피케이션만이 아닌 *왜 이렇게 하나* 학습자 이해

## 11. 표준 샘플 녹음 SOP (P7-01 압축)

매주 1회 학습자가 녹음하는 표준 자료. *동일 조건*이 핵심.

### 녹음 항목 (3분)
1. **읽기** — 표준 텍스트 (예: 한국 표준 발음법 예시문 30초)

3. **글라이드** — /a/로 저→고→저 한 호흡 (편한 범위)

## 12. RC3 딥 리서치 통합 — 학술 근거 강화 모듈 (2026-05 갱신)

`research/RESEARCH_COMPILATION_3.md` 결과를 본 앱 콘텐츠로 직접 변환. 4개 신규 모듈:

### 12.1. Onboarding 학습 평가 — 청지각 ↔ 산출 *분리* 테스트

**근거**: Pfordresher & Brown 2007 [CITE: PFORDRESHER2007PP] — *"Poor-pitch singers did not differ from good singers in pitch discrimination accuracy"*. 음치 ≠ 청지각 결손, 산출/매핑 문제로 재정의.

**테스트 구성** (온보딩 4단계, 각 5–10초):
1. **청지각 단독**: 두 음 들려주고 "같다/다르다" 또는 "위/아래" 응답. 학습자 *듣기* 능력 측정.
2. **산출 단독**: 짧은 음 (편한 중음) 들려주고 학습자가 *가능한 한 가까이* 모방. F0 정확도 측정 (cents).
3. **자가 모방 산출**: 학습자 자신의 직전 녹음을 들려주고 다시 모방. Pfordresher P2 self-imitation [CITE: PFORDRESHER2014SWY] 효과 확인.
4. **시각 피드백 산출**: 실시간 피치 곡선 보면서 같은 음 모방. Berglin 2022 [CITE: BERGLIN2022FB] 효과 확인.

**레벨링** (Pfordresher P3 [CITE: PFORDRESHER2021SSAP] 분포 기반):
- 산출 정확도 ±50 cents 이내 → 정상 분포 (~70%)
- ±50–100 cents → 경계
- ±100 cents 이상 → 부정확 분포 꼬리 (~30%) — 별도 *Phase A 자기 청취 강화 트랙* 권유

### 12.2. "내 목소리 따라부르기" 모듈 (Self-Imitation Drill)

**근거**: Pfordresher & Mantell 2014 [CITE: PFORDRESHER2014SWY] — *"All singers imitated sung pitch more accurately when imitating recordings of themselves; the advantage was enhanced for poor-pitch singers."* 자가 녹음 모방 > 일반 모델 모방.

**도입 시점**: Phase A 후반 (5–8주, 가벼운 첫 소리 도입과 함께)

**모듈 구성**:
1. 학습자가 편한 음 1개를 짧게 (2초) 녹음
2. 앱이 그 녹음을 *재생*
3. 학습자가 다시 모방
4. F0 비교 시각화
5. 5회 반복으로 *자기-자기 청각-운동 매핑* 강화

**적용**: 일반 음정 모방 모듈 *전*에 self-imitation 주 1회 의무 배치. 음치 분포 꼬리 학습자에게 특히 효과.

### 12.3. 실시간 피치 시각화 UI 사양

**근거**: Berglin et al. 2022 [CITE: BERGLIN2022FB] — *시각 피드백(피아노 롤·실시간 피치 곡선) > 청각 피드백 단독*. 성인 음치 재교육에서 시각 피드백 유의 효과.

**UI 요소**:
- **피아노 롤**: 목표 음 가로선 + 학습자 실시간 피치 곡선
- **편차 색상 코드**: 목표 ±10 cents 이내 녹색 / ±10–30 cents 노랑 / ±30+ 빨강
- **누적 비교**: 마지막 5초 평균 편차 표시
- **잔향 보정 토글**: 환경 분석(`01-B §5`) 결과에 따라 자동 보정 또는 *정직 표기*

**사용**: Phase B 전체 + Phase C 모음 안정. 컨슈머 마이크 신뢰도 표기와 함께 (`01-C §5`).

### 12.4. 무대 공포 모듈 — Greene 7-Step Centering (Phase C)

**근거**: Greene 2002 [CITE: GREENE2002] (1차 원형 Nideffer 1976 [CITE: NIDEFFER1976]) + Inner Game [CITE: GREEN_GALLWEY1986] + Helding 2020 [CITE: HELDING2020] + Kenny K-MPAI [CITE: KENNY2011].

**도입**: Phase C 17–24주, 적용곡 작업과 함께. *전 회기 사전 루틴*으로 매 세션 시작 시.

**7-step 절차** (앱이 음성 가이드로 학습자 안내):
1. **Pick a focal point** — 시야 외부 한 점 (예: 화면 한 점)
2. **Form a clear intention** — 단일·긍정·동사형 ("let it sing")
3. **Breathe mindfully** — 4초 들숨 / 6초 날숨 비대칭
4. **Scan and release tension** — 머리 → 목·어깨 → 가슴·복부 → 다리
5. **Find your center** — 단전(*hara*, 배꼽 약 2인치 아래) 의식
6. **Repeat a process cue** — 결과 단어 ❌ ("perfect"/"잘") , 과정 단어 ✓ ("breathe"/"호흡")
7. **Direct your energy** — focal point으로 에너지 방출

**진행**:
- 17주: 7-step 학습 (10–15분)
- 18–20주: 매 세션 5분 단축 적용
- 21–24주: 5–10초 단축 (Greene 라인 — 1–2주 연습 시 단축 가능)

**Inner Game 보조 모듈** [CITE: GREEN_GALLWEY1986]:
- 자가 녹음 리뷰 시 *non-judgmental prompt*: "어디가 어떻게 들렸는가" (✓) vs "좋다/나쁘다" (❌)
- Self 1 (비판) vs Self 2 (직관) 인식 — 학습자 안내 영상

**저작권**: 7-step 자체는 *방법론*으로 비저작권. Greene 문구·다이어그램·자가평가 inventory는 보호 대상. 앱은 *방법론을 자체 표현으로 재서술*. 7-Skill Performance Inventory는 라이선스 검토 후 사용 또는 *자체 항목 개발*.
