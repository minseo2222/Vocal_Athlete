# 01-C AI 분석 차별화 사양

**대상**: ML 엔지니어·데이터 사이언티스트·제품 매니저
**범위**: 본 앱의 AI 분석 기능 5종 + 기술 스택 + MVP 범위 + 평가 메트릭
**전제**: `research/part 11 §"갭"` 5개를 *직접 우리 앱의 차별화 기능*으로 변환.

> 컨슈머 보컬 앱 시장(Yousician·Riyaz·SingSharp·Vanido 등)은 대부분 자기상관 피치 검출 + 룰 기반 채점에 의존하며 학술 검증이 거의 없다. 본 앱은 *학술 검증된 SOTA + 정직한 한계 표기*로 포지셔닝한다.

## 2. 기능 1 — 가창자 특화 음성 평가

### 2.1. 문제 정의
기존 음성 평가 모델 (CAPE-V·GRBAS 자동화)은 *임상 병리 음성*으로 학습됨. 가창 스타일 (sustain·vibrato·dynamic 변화)에는 *false positive* 多.

### 2.2. 기술 스택 (권장)

| 레이어 | 선택 |
|---|---|
| Foundation model | wav2vec 2.0 / WavLM (음성 표현 학습) |
| Fine-tune base | VOQANet [CITE: VOQANET2025] — attention-based 임상 평가 |
| 가창 특화 데이터 | 본 앱 사용자 옵트인 코호트 + 공개 데이터셋 (NUS Sung & Spoken, VocalSet 등) |
| 출력 | CAPE-V 6차원 점수 (0–100 VAS) + 신뢰도 |

### 2.3. MVP 범위 (V1 출시)
- *지속 모음* sustain만 평가 (가장 안정적 측정)
- CAPE-V 6차원 중 4차원 (overall severity·breathiness·strain·roughness)
- 점수 + 신뢰도 + *정확도 한계 명시*

### 2.4. V2+ 확장
- 글라이드·노래 구절 평가
- pitch·loudness 차원 추가
- 학습자 개인 베이스라인 대비 *상대 점수*

### 2.5. 평가 메트릭 (모델 성능)
- SLP 평정 vs 모델 예측 ICC (Intraclass Correlation) ≥ 0.7 목표
- 가창 false positive rate (정상 가창 → 병리 판정) < 10% 목표

## 3. 기능 2 — 발성 분류 (초급 3분류)

### 3.1. 분류 체계

**초급 (Phase B·C)**:
- 과기식 (Breathy / Hypo-adduction / 저접지) — 김형미 2025 매핑 [CITE: KOR_KIM2025]
- 균형 (Balanced / 균형 접지) — P3-07 [CITE: TITZE2006SOVT]
- 과압착 (Pressed / Hyper-adduction / 과접지)

**중급 (V2)**:
- belt vs mix vs head/M2 (Henrich/Roubeau M0–M3 [CITE: ROUBEAU2009])
- twang 검출 (AES narrowing 음향 지표 [CITE: GIBIAT2024])

### 3.2. 입력 시그널
- F0 (피치) 안정성
- Spectral tilt (H1-H2, H1-A3)
- CPP (cepstral peak prominence) — Hosoya 2023 GRBAS 자동화 활용 [CITE: HOSOYA2023]
- 음량 변동
- Onset 특성 (글로털 vs balanced vs aspirate)

### 3.3. 학습 데이터 — 라벨링 전략
- SLP 1+명 평정 *황금 라벨* + 전문가 합의 (κ ≥ 0.7)
- 본 앱 사용자 옵트인 → 자가 평정 + SLP 검증
- 합성 데이터 (synth larynx model 기반 — Galindo 2023 라인 [CITE: GALINDO2023]) 보충

### 3.4. UI 표시
```
[당신의 발성 분석]
  과기식 ━━━━━░░░░░ 22%
  균형   ━━━━━━━━━░ 65%  ← 가장 유사
  과압착 ━━━━░░░░░░ 13%

  → 균형 발성에 가깝습니다. 그대로 유지하세요.

  신뢰도: ⭐⭐⭐⭐ (높음)
  단, 컨슈머 마이크 환경에서는 jitter/shimmer 측정 신뢰도가 낮습니다 [CITE: MANFREDI2017].
```

### 3.5. *학습자에게 *진단*하지 않음*
- "당신은 과기식입니다" ❌
- "현재 샘플은 과기식 *경향*이 보입니다" ✓
- 의료 동의서 §3.A에 명시된 면책과 일치

## 4. 기능 3 — 한국어 음성 검증

### 4.1. 문제 정의
본 보고서 part 11 §"갭" 4번: 한국어 화자 가창 데이터로 학습된 모델 거의 부재. K-pop 음성 검증 부재.

### 4.2. 데이터 자산
- **공개 데이터**: Lee 2020 TASLP K-pop tagged singing dataset [CITE: LEE2020TASLP]
- **한국 1차 자료**: KOR_VISUAL_QUANT (한국 공학 측 가창력 평가) [CITE: KOR_VISUAL_QUANT], KOR_CAI (한국 CAI 선례) [CITE: KOR_CAI]
- **자체 코호트** (V2+): 한국어 옵트인 학습자 표준 샘플 → 익명 코호트

### 4.3. V1 구현
- 한국어 모음 (/ㅏㅣㅜ/) 표준 모델
- 모음 식별 정확도: 한국어 화자 90%+ 목표
- F1/F2 측정은 Hillenbrand 1995 미국 영어 표준 차용 + *한국어 가창 formant DB 부재* 명시 (Part QI §5 잔존 갭 [CITE: KOR_SOPRANO_ACOUSTIC])

### 4.4. V2+ 확장
- 한국어 가창 formant DB 자체 구축 (옵트인 코호트 1000+ 사용자)
- 본 앱 자체가 *한국 1차 학술 자료*가 됨 — 콘텐츠 검수 위원회 + KCI 등재 학회 협력
- 한국어 평/경/격음 VOT 분석 (Part 6-KR P6KR-01 카드)

### 4.5. K-pop 명명 ↔ 학술 어휘 자동 매핑
학습자가 "립버블"이라 검색하면 → "립 트릴 (P3-17, 동일 운동)"로 자동 변환:
- Part 9-KR §"K-pop 명명 ↔ 음성과학 매핑" 표 시스템화
- K-pop 어휘 사용자 (CCM 트랙)에게 *학술 어휘 자동 표시* 옵션

## 5. 기능 4 — 컨슈머 마이크 한계 정직 표기

본 앱의 *정직성 차별화 핵심*. 다른 앱은 안 함.

### 5.1. 측정값별 신뢰도 등급 (모든 출력에 표시)

| 측정값 | 컨슈머 마이크 신뢰도 | 표시 |
|---|---|---|
| F0 (피치) | 높음 (cents 단위 정확) | ⭐⭐⭐⭐⭐ |
| sustain 길이 | 높음 | ⭐⭐⭐⭐⭐ |
| 음량 (상대값) | 중간 | ⭐⭐⭐⭐ |
| jitter (%) | 낮음 (마이크 의존) | ⭐⭐ + ⚠경고 |
| shimmer (%) | 낮음 | ⭐⭐ + ⚠경고 |
| HNR (dB) | 낮음 | ⭐⭐ + ⚠경고 |
| CPP / CPPS (dB) | 중간 (잡음 의존) | ⭐⭐⭐ |
| AVQI v6.0 | 낮음 | ⭐⭐ + ⚠경고 |
| Spectral tilt | 중간 | ⭐⭐⭐ |

### 5.2. 학습자 화면 표기 표준

```
[측정값]               [값]      [신뢰도]
F0 (피치)              220 Hz    ⭐⭐⭐⭐⭐ 높음
sustain 길이           4.8s      ⭐⭐⭐⭐⭐ 높음
jitter                 1.2%      ⭐⭐ 낮음 ⚠
                                 (Manfredi 2017 검증 — 임상 마이크에서만 신뢰)
```

### 5.3. 환경 분석 결과 반영
- §`01-B §5` 환경 분석에서 측정한 마이크 클래스 → 신뢰도 자동 조정
- 잔향 큰 방·노이즈 ↑ → 신뢰도 자동 ↓

### 5.4. 마케팅 메시지
- "본 앱이 측정한 jitter 수치는 *진단 목적이 아닙니다*"
- "임상 평가는 임상 마이크 + 무반향실에서만 가능합니다"
- "본 앱은 *추세 추적*에 강하고, *절대값 비교*에는 약합니다" — 정직 표기

## 9. 평가 메트릭 (출시 후)

### 9.1. 모델 성능
- CAPE-V 자동 vs SLP 평정 ICC ≥ 0.7
- 3분류 정확도 (SLP 합의 라벨 대비) ≥ 80%
- 한국어 모음 식별 정확도 ≥ 90%
- F0 정확도 (cents) ≤ ±5 cents

### 9.2. 학습자 outcome (옵트인 코호트)
- 24주 졸업률 (vs 첫 출시 베이스라인)
- 손상 발생률 (vs Bretl 2023 22% 베이스라인 [CITE: BRETL2023])
- EASE 점수 변화
- 표준 샘플 CPP/AVQI 변화 (전후)
- 학습자 만족도 NPS

### 9.3. 안전 메트릭
- 적색 신호 자동 트리거 발생률
- 의료 의뢰 권유 후 실제 의료 방문률 (옵트인 학습자만)
- 부정확한 false positive (불필요한 의료 의뢰) — 위원회 분기별 검토

## 10. 차별화 메시지 (제품 마케팅용)

### 10.1. 한 줄 포지셔닝

### 10.2. 비교 포인트

| 비교 항목 | Yousician / Riyaz / Vanido | 본 앱 |
|---|---|---|
| 피치 검출 | 자기상관 (YIN 등) | CREPE + YIN 백업 |
| 음성 평가 | 게이미피케이션 점수만 | CAPE-V 4차원 + 신뢰도 등급 |
| 발성 분류 | ❌ | 3분류 (V1) → 6분류 (V2) |
| 한국어 검증 | ❌ | 한국어 가창 옵트인 코호트 (V2+ 자체 DB) |
| 마이크 한계 표기 | ❌ ("AI 보컬 코치!") | ⭐ 신뢰도 등급 모든 측정값 |
| 안전 트리거 | ❌ | 적색 신호 자동 감지 + 의료 의뢰 |
| 학술 검증 | ❌ | 콘텐츠 검수 위원회 (SLP·페다고지 박사·음성과학자) |
| 부하 ↑ 압박 | ✓ ("더 잘하세요!") | ❌ ("안전하게 유지하세요") |

### 10.3. 학습자에게 직접 노출하는 *근거 등급* UI
- 모든 훈련 카드에 RCT/feasibility/observational/⚫근거부족 배지
- 모든 측정값에 신뢰도 ⭐ 등급
- 본 앱의 *정직성*을 학습자가 *체감*
