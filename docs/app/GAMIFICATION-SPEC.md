# GAMIFICATION-SPEC — 보컬형 게임화 원칙

> 목적: 듀오링고형 동기 구조를 보컬 안전에 맞게 변형한다. 일반 학습 앱의 경쟁·고득점 구조를 그대로 가져오지 않는다.

## 1. 게임화의 목표

게임화의 목표는 “더 높게, 더 크게, 더 오래”가 아니라 **안전하게 다시 돌아와 루틴을 완료하는 것**이다.

## 2. 허용되는 요소

| 요소 | V1 적용 | 보상 기준 |
|---|---|---|
| Streak | 적용 | 오늘 레슨 완료, 복귀 복습 완료 |
| XP | 제한 적용 | 안전 완료, 쿨다운, 표준샘플, 복귀 |
| Badge | 적용 가능 | 루틴 지속·복귀·같은 조건 기록 |
| Mission | 적용 가능 | SOVT 3회, 복귀 복습, 표준샘플 재기록 |
| Level | 기술별 표시 | SOVT/자기모방/시각피치 등 루틴 숙련 |
| Review | 적용 | 오답노트가 아니라 nudge log |
| Personalization | 제한 적용 | 복귀·변주·저신뢰 피드백 조정 |

## 3. XP 정책

XP는 다음에 부여한다.

- 오늘 레슨 완료
- 쿨다운 완료
- 복귀 복습 완료
- 표준샘플을 같은 조건으로 기록
- 저신뢰 피드백에서 무리하지 않고 멈춤
- SOVT warm-up 유지

XP를 다음에 부여하지 않는다.

- 더 큰 음량
- 더 높은 음역
- 더 긴 sustain
- 더 빠른 run
- 더 많은 반복
- 경쟁 순위

## 4. Streak 정책

- 하루 놓쳐도 0 reset 없음.
- streak freeze 없음.
- 공백은 복귀 복습으로 흡수.
- 장기 공백 후에도 사용자에게 실패감을 주지 않는다.

추천 카피:

- “다시 이어갈 준비가 됐어요.”
- “오늘은 가볍게 복습부터.”
- “쉰 것도 목 관리의 일부예요.”

금지 카피:

- “연속 기록이 깨집니다.”
- “오늘 안 하면 손해예요.”
- “목표를 실패했습니다.”

## 5. Nudge log

보컬에는 “오답” 표현을 쓰지 않는다. 대신 `nudge log`를 사용한다.

예시:

- “오늘은 시작 음이 조금 높게 잡혔어요.”
- “저신뢰 구간이 많아 피치 점을 숨겼어요.”
- “내일은 같은 cue를 한 번 더 가볍게 해볼게요.”

nudge는 낙인·진단·정체성 라벨이 아니다.

금지:

- “당신은 과압착형입니다.”
- “음치입니다.”
- “실패했습니다.”

## 6. 금지되는 게임화

- 리더보드
- 고음 랭킹
- 음량 랭킹
- sustain 길이 랭킹
- 벨트 챌린지
- 연속 고음 미션
- 공개 음성 비교
- “perfect pitch score” 집착형 점수
- pain/hoarseness 무시를 유도하는 streak 압박

## 7. MVP 적용 우선순위

1. Streak + 관대한 복귀
2. 완료/쿨다운/복귀 XP
3. 표준샘플 badge
4. nudge log
5. mission
6. 기술별 level

리더보드와 공개 커뮤니티는 V1에서 제외한다.
