# Repertoire Application Take Review Spec — v7

## Purpose

Review short phrase takes recorded during Repertoire Application / 곡 적용 훈련.
This is a vocal-training review screen, not a songwriting or music-production feature.

## Included in v7

- Settings entry: `곡 적용 훈련 리뷰`.
- Filter: `RecordingPurpose.repertoirePhrase`.
- Group by card ID.
- Show slot, duration, tone tag, comfort rating.
- Playback if a local playable file exists.
- Delete individual take.

## Copy boundaries

Allowed:

- “짧은 프레이즈 take를 다시 듣습니다.”
- “배운 보컬 기술이 실제 노래 구간으로 옮겨졌는지 확인합니다.”

Disallowed:

- “노래를 만들어 봅니다.”
- “내 곡을 제작합니다.”
- “음원을 완성합니다.”
