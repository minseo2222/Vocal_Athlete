# MVP-SCOPE — V1 출시 범위

> 목적: 문서·코드·콘텐츠 제작자가 같은 V1을 만들도록 출시 범위를 고정한다. 본 문서는 `APP-SPEC.md`의 하위 실행 문서이며, 중급/고급 아이디어가 V1 범위를 침범하지 못하게 하는 릴리스 게이트다.

## 1. V1 제품 명제

V1은 **성인 초보자가 매일 10–15분, 안전한 기초 발성 루틴을 반복하게 만드는 앱**이다. 목표는 “노래 실력 판정”이 아니라 “노래 전제조건을 만드는 일일 루틴”이다. R2부터는 이 루틴을 실제 노래 학습 체감으로 연결하기 위해 **듣기·박자·짧은 선율 모양·한국어 음절 bridge**를 낮은 부하로 포함한다. R3부터 전체 장기 구조는 **초급 Foundation → 중급 Universal Core → Repertoire Application → 고급 장르 Lab**으로 확장하되, V1 출시는 여전히 초급 Foundation에 한정한다.

- 진단·치료·임상 모니터링 아님.
- 곡 훈련 앱 아님.
- 고음·belt·run 도전 앱 아님.
- AI 점수 경쟁 앱 아님.

## 2. V1에 반드시 포함

| 영역 | 포함 항목 | 기준 |
|---|---|---|
| 커리큘럼 | 초급 48레슨 / 18 IN 카드 | `docs/curriculum/beginner/CURRICULUM.md` 기준 |
| 진행 | 1일 1레슨 cap | 완료 후 당일 재진도 불가 |
| 완료 | 완료 기반 해금 | 수행 품질·AI 점수로 차단하지 않음 |

| 전이 | 초급 완주 후 중급 Universal Core 진입 CTA | 장르 선택은 초급 직후 열지 않음 |
| 안전 | 앱 실행 경고 1회 + 비진단 목 상태 micro-check | 초급 V1 안전 범위. 고위험 카드는 미출시 |
| 레슨 | 진입/본운동/쿨다운 | 매 레슨 유성 마이크로-윈 1개 이상 |

| 자기비교 | self-imitation | 자기 녹음→재모방→시각 비교 |
| 전이훈련 | 청음-허밍, 4박 pulse, 2–3음 contour, 한국어 음절 bridge | 곡/고음/가사 훈련이 아닌 낮은 부하 bridge |
| 표준샘플 | Day 1 / Day 24 / Day 48 고정 비교 | 점수 아님, 같은 조건의 시각 전후 비교 + tone tag seed |
| UI | TodayHero/JourneyPreview/Map | 짧은 루프와 성취감 중심 |
| 데이터 | 로컬 우선 | 클라우드 업로드는 V1 기본값 아님 |

## 4. V1 성공 지표

V1의 1차 성공은 “높은 점수”가 아니라 **사용자가 안전하게 다시 돌아와 실제로 소리를 내는 것**이다.

- D1/D7/D30 retention
- 첫 레슨 완료율
- 마이크 권한 허용 후 본운동 진입률
- `completed_under_60s` 비율
- 7일+ 공백 후 복귀 복습 완료율
- 표준샘플 재기록률
- 저신뢰 피치 null 비율과 사용자 이탈률
- stop/safety 문구 노출 후 중단 선택률

세부 이벤트는 `METRICS-AND-EXPERIMENTS.md`를 따른다.

## 5. V1 출시 판정

V1 출시 전 최소 판정:

1. 초급 48레슨 전수 카드 resolve 통과.
2. 표준샘플이 Day 1 / Day 24 / Day 48에만 배치됨.
3. CARD-12가 고정 Hz가 아니라 relative target + deferred feedback으로 동작함.
4. 진입 단계에서 바로 완료할 수 없음.
5. 저신뢰 F0는 추정값을 숨김.
6. 녹음/마이크 데이터 기본 로컬 처리.
7. 고급 장르 Lab 롤아웃 config 기본 비어 있음.
8. pending safety 카드가 기본 잠금.
9. 앱 스토어/플레이스토어 문구가 진단·치료·의료 효능을 암시하지 않음.



## 6. R3 장기 경로와 V1 경계

- 코드상 초급 완주 후 장르 선택 화면은 제거하고 `중급 공통 코어 시작` 전이로 바꾼다.
- `Universal Vocal Core`와 `Advanced Genre Labs` 문서는 장기 설계/후속 릴리스 기준이다.
- V1 앱스토어/플레이스토어 카피는 여전히 초급 Foundation에 맞춰야 한다.
- 음색 훈련은 V1에서 `Tone Snapshot Lite` 수준으로만 노출하고, 본격 tone A/B는 Universal Core 이후로 둔다.
