# TODAY OPTIONAL REVIEW SPEC — v13

## 목적

지연 재현과 조건 전이 복습을 설정 안쪽에 숨겨두지 않고 Today 화면에서 발견할 수 있게 한다. 다만 복습은 정규 레슨, streak, 진도 해금과 분리된 선택 과제다.

## 표시 조건

- `dueEpochDay <= todayEpochDay`
- `status == pending`
- due item이 1개 이상일 때만 Today 카드 표시
- 정규 `오늘 레슨` CTA보다 시각적 우선순위를 높이지 않음

## 카피

- 제목: `오늘의 선택 복습 N개`
- 보조: `3–5분 · 건너뛰어도 진도와 streak에 영향 없음`
- CTA: `복습 보기`

## 흐름

```text
Today 선택 복습
→ 복습 큐
→ 복습 시작
→ 목 상태 선택
→ 기억에서 1회 재현 또는 무성 대체
→ 자기점검/선택 녹음
→ ReviewEvidence 저장
```

## 오늘 넘기기

- 실패 또는 dismiss로 기록하지 않는다.
- due date를 다음 날로 옮긴다.
- streak, XP, 정규 진도에 불이익을 주지 않는다.
- 반복적으로 미뤘다는 사실을 사용자에게 죄책감 카피로 노출하지 않는다.

## 안전

- `쉰 느낌`: voiced attempt를 요구하지 않는다.
- 이전 take 낮은 볼륨 청취, 리듬 탭, 가사·호흡 위치 확인 중 하나를 명시적으로 체크한 뒤 다음 날 재예약한다.
- `조금 피곤함`: 시도 1회 상한.
- `괜찮음`: 시도 2회 상한.

## 금지

- 복습 미완료 때문에 streak 초기화
- E2/E3 자동 달성 표시
- 복습 횟수 랭킹
- 목 상태가 좋지 않은데 발성 강행
