# Recording Library Management Spec — v7

## Purpose

The recording library gives users control over local vocal-training artifacts.
It is not a cloud export feature, social sharing feature, or song-production workspace.

## Included in v7

- Local recording summary.
- Count and size by recording purpose.
- Metadata-only export preview with local file paths redacted.
- Clear-all local recordings action.
- Settings entry: `녹음 관리`.

## Recording purposes

- Standard samples: Day 1 / 24 / 48 before-after evidence.
- Tone A/B: timbre comparison takes.
- Repertoire phrase: short vocal-training phrase application takes.
- Portfolio: future best-take collection.

## User-facing rules

- Use “녹음 관리”, not “음원 관리” or “노래 제작”.
- Export preview must clearly say that audio files are not included.
- Clear-all must be explicit and irreversible in v7.
- Keep the local-first copy visible.

## Not included

- Audio file sharing.
- Cloud sync.
- Expert upload.
- Public feed.
- Singer-match or voiceprint export.
- Auto-generated vocal health reports.
