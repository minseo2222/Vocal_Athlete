# AI 분석 (AI-ANALYSIS)

> 옛 `01-C AI 분석 차별화 사양`을 대체(archive 보존). 용어 루트 `CONTEXT.md`. 근거 ADR-0002(개정).

## 1. 원칙 — 막지 않는 인-레슨 피드백

AI 분석은 *정보·연습 재료*일 뿐 **해금·졸업을 막지 않는다**(완료 기반). 학습자에게 *진단·판정*하지 않는다 — "현재 샘플은 …경향" ✓, "당신은 …입니다" ❌.

## 2. 표시하는 것 (신뢰 가능)

- **F0 / 피치** — 컨슈머 마이크에서 신뢰 가능. 시각 곡선으로.
- **sustain 길이** — 신뢰 가능.
- **3분류 발성**(과기식 / 균형 / 과압착) — 정보 표시(예: "균형에 가까움 ━━━ 65%"). 결과가 무엇이든 레슨은 완료·다음 해금. 김형미 2025 성대접지 3분류 [CITE: KOR_KIM2025].
- **표준 샘플 A/B** — 동일 조건 녹음 #1/#2/#3의 전후 *시각* 비교(스펙트로그램/피치).
- **시각 피치 매칭** — 피아노롤 목표선 + 실시간 곡선, ±편차 색상(±10/±30 cents). 빗나가도 완료 인정.
- **self-imitation** — 자기 녹음 재생 → 재모방 → 시각 비교.

## 3. 표시하지 않는 것 (구조적 한계 제거)

- **jitter · shimmer · HNR · AVQI · 마이크 민감 음향 지표** — 컨슈머 마이크 신뢰도 낮음 → *애초에 표시 안 함*. 한계를 설명할 필요 자체가 사라짐(ADR-0002 개정).
- **CAPE-V/GRBAS 임상 평정** — 제품에서 제거(임상 도구, 동반자 트랙 폐기).
- "듣고 스스로 평가하라" 식 청각 자가판정 — 골전도 착각 → **시각 전용**으로 대체.

## 4. 한국어 (V1)

한국어 모음 /ㅏㅣㅜ/ 식별(목표 정확도 ~90%)을 *정보*로 제공. F1/F2 절대비교는 한국어 가창 formant DB 부재로 *표시하지 않음*(시각 상대 비교만). 옵트인 코호트·자체 DB 구축은 V2+.

## 5. 기술 (V1 권장)

- 온디바이스 우선(프라이버시·지연). iOS Swift/AVAudioEngine, Android Kotlin/Oboe.
- F0: CREPE + YIN 백업. 스펙트럼: librosa/Parselmouth.
- 3분류 모델: 옵트인 코호트 + 공개 데이터 fine-tune. *출력은 정보용*, 게이트 아님.
- 클라우드(옵트인): 한국 리전, 개인정보보호법 준수.

## 7. 정직성

차별점은 *정직*이다 — 신뢰 못 할 수치는 *그럴듯하게 보이게 하지 않고 아예 안 보여준다*. 측정은 *추세(시각 전후 비교)*에 강하고 절대값 진단엔 약하다는 전제 위에서만 피드백한다.
