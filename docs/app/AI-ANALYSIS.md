# AI 분석 (AI-ANALYSIS)

> 옛 `01-C AI 분석 차별화 사양`을 대체(archive 보존). 용어 루트 `CONTEXT.md`. 근거 ADR-0002·ADR-0014(개정). 본 문서는 사용자에게 표시할 피드백의 경계와 V1/V2 범위를 정한다.

## 1. 원칙 — 막지 않는 인-레슨 피드백

AI 분석은 *정보·연습 재료*일 뿐 **해금·졸업을 막지 않는다**(완료 기반). 학습자에게 *진단·판정*하지 않는다.

허용:

- “현재 샘플은 목표선보다 약간 높게 지나갔어요.”
- “저신뢰 구간은 표시하지 않았어요.”
- “이전 표준샘플과 비교해 곡선이 더 안정적으로 보입니다.”

금지:

- “당신은 과압착형입니다.”
- “성대 상태가 나쁩니다.”
- “이 점수 미만이면 다음으로 갈 수 없습니다.”

## 2. V1에 표시하는 것

- **F0 / 피치** — 컨슈머 마이크에서 상대적으로 쓸 수 있는 지표. 시각 곡선/점으로만 표시.
- **저신뢰 null** — 언보이스드·기식·잡음 등 명확한 주기가 없으면 점을 표시하지 않음. 틀린 점보다 없는 점이 낫다.
- **sustain 길이** — 짧은 과제의 정보용 표시. 점수·랭킹으로 쓰지 않음.
- **표준 샘플 A/B** — 동일 조건 녹음 #1/#2/#3의 전후 *시각* 비교(피치/스펙트럼 계열). 좋고 나쁨의 판정이 아니라 변화 관찰.
- **시각 피치 매칭** — 목표선이 있는 카드에서는 목표선 + 곡선. R2부터 초급 CARD-12는 고정 Hz가 아니라 세션 초반 안정 F0에서 상대 기준선을 잡고, 수행 중 화면 의존을 줄이기 위해 기본값을 “시도 후 곡선 보기”로 둔다.
- **self-imitation** — 자기 녹음 재생 → 재모방 → 시각 비교.

## 3. V1에 표시하지 않는 것

- **jitter · shimmer · HNR · AVQI · 마이크 민감 음향 지표** — 기기·거리·환경 영향을 크게 받을 수 있으므로 사용자 표시 없음.
- **CAPE-V/GRBAS 임상 평정** — 제품에서 제거(임상 도구, 동반자 트랙 폐기).
- **청각 자가판정** — 골전도 착각을 피하기 위해 “듣고 스스로 평가” 흐름 제거, 시각 전용.
- **3분류 발성 AI 정식 표시** — V1 사용자 표시에서 제외. 데이터셋·기기별 검증 전까지 opt-in 실험/내부 연구로만 다룸.
- **한국어 모음 식별 AI 정식 표시** — V1 사용자 표시에서 제외. 한국어 가창 DB와 정확도 검증 필요.

## 4. 기술 (V1)

- 앱 스택: Flutter.
- 피치 소스: `PitchSource` 인터페이스로 교체 가능하게 유지.
- F0: 온디바이스 Dart 자기상관 + 포물선 보간 + 정규화 신뢰 게이트(ADR-0014 개정).
- 저신뢰 처리: null을 그대로 노출해 점/곡선을 숨김.
- 카드 목표음: `targetHz`가 있는 카드에만 절대 목표선 표시. `relativePitchTarget=true` 카드(CARD-12)는 초반 voiced F0 median을 오늘의 기준선으로 잡는다. 둘 다 없으면 절대 피치 관찰만.
- pYIN/CREPE: V1 기본 아님. 실기기·사용자 데이터에서 현재 방식의 부족이 확인될 때 V2 승급 후보.
- 클라우드 분석: V1 기본 아님. 도입 시 별도 opt-in·개인정보 정책 필요.

## 5. V2+ 후보

### 5.1 3분류 발성 모델

과기식/균형/과압착(저접지/균형/과접지) 모델은 제품 차별화 가능성이 있으나 V1 표시 기능이 아니다.

필요 조건:

- opt-in 한국어/가창 데이터셋
- 기기·거리·소음별 정확도 검증
- 초보자 음성에서의 false label 검토
- 사용자 카피 안전성 검토
- “당신은 X형”이 아닌 “현재 샘플은 X 경향” 문구 검증

### 5.2 한국어 모음 식별

/ㅏㅣㅜ/ 식별은 가요·한국어 diction 차별화 후보이나 V1 표시 기능이 아니다.

필요 조건:

- 한국어 가창 formant/모음 DB
- 성별·음역·장르별 변이 검토
- 목표 정확도와 실패 UX 정의
- F1/F2 절대값 표시 금지 원칙 유지

### 5.3 LLM 코치

V1 제외. 도입 시 진단·의료·과사용 조언을 막는 강한 가드레일이 필요하다.

## 7. 정직성

차별점은 *정직*이다. 신뢰 못 할 수치는 그럴듯하게 보이게 하지 않고 아예 안 보여준다. 측정은 *추세와 시각 전후 비교*에 강하고 절대값 진단에는 약하다는 전제 위에서만 피드백한다.

## 8. R2 피드백 빈도 원칙

- 초급자의 화면 의존을 줄이기 위해 CARD-12/14/16은 `deferredVisualFeedback=true`를 기본값으로 둔다.
- 수행 중에는 recording/안내만 보여주고, 사용자가 `곡선 보기`를 누른 뒤 시각 피드백을 확인한다.
- 실시간 표시가 필요한 후속 실험은 opt-in으로 분리한다.
- 피치 피드백은 점수·해금·랭킹과 연결하지 않는다.


## 음색/Timbre 분석 정책 (R3)

V1/R3에서 음색은 자동 점수화하지 않는다. 앱은 A/B 녹음 재생, 사용자 tone tag, 편안함 점수, clipping/noise 안내만 제공한다. spectral centroid, CPPS, formant 추정, onset shape는 researchOnly 또는 전문가 보조 후보이며 스마트폰 기기 검증 전 사용자-facing 점수로 쓰지 않는다.

금지: 음색 점수, 성대 접촉률 자동 판정, 유명 가수 매칭률, 성대 건강 진단, belt 성공 판정.
