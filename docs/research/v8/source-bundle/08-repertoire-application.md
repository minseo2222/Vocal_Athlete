### 2.3 비판: 근거의 한계

**[D]** 성인 대상 모바일 보컬 앱에서 “B 단계가 A 방식보다 실제 노래 전이에 우월하다”를 직접 검증한 대규모 RCT는 부족하다. 따라서 B 방식의 권장은 텍스트-멜로디 이중과제 연구, 운동학습 피드백 원리, 보이스 페다고지 현장 합의, 곡 습득 연구를 통합한 설계 추론이다. ([Springer][1])

**[B/D]** NATS/Journal of Singing 자료는 보컬 페다고지 우선 출처로 강하지만, 일부는 실험연구라기보다 전문가 통합·현장 기반 제안이다. 따라서 제품에서는 “절대 법칙”이 아니라 **adaptive rule**로 구현해야 한다. ([NATS][3])

**[D]** 녹음 리뷰 연구와 자기조절 학습 연구는 음악교육 전반에서 근거가 있으나, 보컬 앱의 자동 피드백·모바일 녹음 환경에 그대로 일반화하기에는 제한이 있다. ([Sage Journals][12])

### 2.4 통합: 전이 메커니즘

보컬 기술의 전이는 다음 5개 층이 모두 작동할 때 발생한다.

1. **Motor pattern stabilization**: 사용자가 특정 조절을 반복해 안정화한다. **[A/B]**
2. **Phrase embedding**: 안정화된 조절을 실제 프레이즈의 음역, 리듬, 발음, 호흡 안에 넣는다. **[B/C]**
3. **Context coupling**: 반주, 템포, 가사 의미, 스타일을 붙인다. **[B/D]**
4. **Feedback fading**: 가이드 보컬과 외부 피드백을 줄여 내부 기준을 만든다. **[A/B]**
5. **Retention/transfer proof**: 지연 재녹음과 새 프레이즈에서 확인한다. **[A/B]**
   이 구조는 Crocco & Meyer의 acquisition–retention–transfer 구분, Nix의 exercise–phrase–whole synthesis 구조, 그리고 전이 학습 정의와 일치한다.

| 난이도는 최고음만이 아니다               | 사용자는 자기 목소리에 맞는 곡을 고른다            | range/tessitura/passaggio/phrase length 기반 추천      | “이 곡은 높은 음보다 높은 음 체류 시간이 어렵다”처럼 설명 | 사용자가 안전한 난이도 곡을 직접 선택                   | **[B/C]** |
| 반주는 문맥을 제공하지만 오류를 가릴 수 있다    | 사용자는 반주 안에서도, 단순 반주에서도 정확히 부른다    | full backing → sparse backing → backing-only check | 반주별 점수 차이 표시                       | full backing과 sparse/backing-only 모두 통과 | **[B/D]** |
| 모델링은 유용하지만 의존 위험이 있다         | 사용자는 guide vocal 없이 수행한다          | guide 100% → 50% → 25% → off                       | guide-off에서만 졸업 피드백 활성화            | guide-off target tempo pass             | **[B/C]** |
| 녹음 리뷰는 자기조절 학습을 돕는다          | 사용자는 녹음을 듣고 다음 시도를 계획한다           | A take, B take, self-note, retry                   | “이번 take의 1순위 수정점”만 제안             | 다음 take에서 사용자가 고른 오류가 개선                | **[B/D]** |
| 안전은 학습 조건이다                  | 사용자는 위험 신호를 인식하고 중단한다             | fatigue check, hoarseness check, range load check  | stop/yellow/red gate               | 위험 신호가 있으면 레슨 졸업보다 중단 우선                |   **[A]** |

### 5.1 핵심 커리큘럼 원칙

**[C]** Repertoire Application Track의 커리큘럼 목표는 “곡을 많이 부르게 하기”가 아니라 다음 능력을 만드는 것이다.

### 6.2 피드백 규칙

**[A/B]** 앱은 오류를 많이 보여줄수록 좋은 것이 아니다. 모터러닝 근거는 피드백 목표와 빈도를 제한하고, 점진적으로 줄이며, 학습자가 내부 기준을 만들게 하는 방향을 지지한다. 

권장 규칙:

1. **Self-rating first:** 사용자가 먼저 “pitch / rhythm / lyric / breath / tone / confidence” 중 문제를 고른다. **[A/B]**
2. **One correction per take:** 한 take 후 1개 primary issue만 제시한다. **[A/B]**
3. **External focus first:** “후렴 첫 음을 반주 코드 위에 착지시켜라”처럼 결과 중심 언어를 우선한다. **[A/B]**
4. **Feedback fade:** 초반 every take → 중반 every 2–3 takes → 후반 user-requested feedback. **[A/B]**
5. **Guide fade:** guide vocal이 켜진 상태의 pass는 practice pass이고, graduation pass가 아니다. **[B/C]**

| A0 Diagnostic     | 실제 곡 수행 baseline | Lyrics → Sing                        | 아무 도움 없이 불러보기  | 오류 유형 분류                        | 기준 미달이면 B scaffold 진입     |
| B1 Scaffold       | 오류 원인 분리         | Speak/Rhythm/Chant/Hum/Vowel 중 필요 단계 | 단계별 1개 문제 해결   | 단계별 micro feedback              | 해당 단계 2회 연속 pass          |
| A1 Integrated     | 실제 프레이즈 재통합      | Lyric + backing                      | guide 감소 후 부르기 | A0 대비 개선 표시                     | guide-off 또는 guide 25% 이하 |
| A2 Guide-off      | 독립 수행            | Lyric + backing only                 | 목표 템포          | pitch/rhythm/lyric/phrase score | level threshold 통과        |
| R1 Delayed Retake | retention 확인     | 24–48h 후 같은 조건                       | 사전 연습 최소화 후 녹음 | A2 대비 유지율                       | 점수 하락 허용폭 이내              |
| T1 Transfer       | 새 프레이즈 전이        | 같은 difficulty band의 새 phrase         | scaffold 최소화   | 전이 성공/실패 분석                     | 3회 이내 pass                |

**[C]** 자동 점수는 제품 루브릭이다. pitch, rhythm, lyric accuracy는 강력한 학습 보조 지표가 될 수 있지만, 예술성 전체를 대체하지 않는다.

## 7. Safety Considerations

**[A]** 사용자가 쉰 목소리, 거칠어진 음색, 고음 상실, 갑자기 낮아진 목소리, 목의 raw/achy/strained 느낌, 말하기 노력 증가, 반복적 목청 가다듬기를 보고하면 앱은 훈련을 중단하거나 낮은 강도의 회복 모드로 전환해야 한다. NIDCD는 이러한 항목을 voice problem 신호로 제시하고, ASHA는 음성 오남용이 성대 조직 변화나 결절로 이어질 수 있음을 설명한다. ([청각 및 의사소통 장애 연구소][13])

**[A/B]** 앱은 의학적 진단을 하지 말아야 한다. 2주 이상 지속되는 쉰 목소리, 통증, 고음 상실, 말하기 어려움, 성대 질환 병력, 공연/직업 음성 사용자는 ENT 또는 SLP 상담을 안내해야 한다. ([청각 및 의사소통 장애 연구소][13])

**[B/D]** Warm-up은 “부상 방지 보장”으로 표현하지 말고, coordination reset과 readiness로 표현한다. Sandage & Hoch는 warm-up이 기술 재확립과 심리적 준비에는 의미가 있을 수 있으나, laryngeal blood-flow 증가 같은 생리학적 근거는 아직 제한적이며, 긴 warm-up은 피로를 유발할 수 있다고 설명한다. 

Safety gate 예시:

| 상태     | 트리거                                | 앱 행동                                  |        근거 |
| ------ | ---------------------------------- | ------------------------------------- | --------: |
| Green  | 통증 없음, 피로 낮음, 범위 안전                | 정상 레슨                                 |   **[C]** |
| Yellow | 목 피로, 음정 불안정 증가, high tessitura 반복 | 반복 수 감소, key down, rest prompt        | **[B/C]** |
| Red    | 쉰 목소리, 통증, 고음 상실, 말하기 어려움          | 레슨 중단, hydration/rest 안내, 필요 시 전문가 상담 |   **[A]** |

## 8. Recommended Framework

### 8.1 Skill Transfer Model

**Skill Transfer Model: “Exercise-to-Song Transfer Loop”**

| 단계                       | 사용자가 할 수 있게 되는 것      | 훈련과제                           | 피드백                          | 졸업기준                    |          근거 |
| ------------------------ | --------------------- | ------------------------------ | ---------------------------- | ----------------------- | ----------: |
| 1. Isolated Coordination | 특정 기술 조절을 짧은 패턴에서 재현  | 3–5개 짧은 vocalise 또는 SOVT/모음 과제 | 감각 설명 최소화, 결과 중심             | 2회 연속 안정                |   **[B/C]** |
| 2. Phrase Mapping        | 같은 조절을 2–4마디 프레이즈에 적용 | vocalise 직후 유사 프레이즈            | “연습에서 된 것이 프레이즈 어디에서 깨졌는가”   | 프레이즈 내 동일 조절 유지         |   **[B/C]** |
| 3. Context Coupling      | 반주·리듬·가사 문맥 안에서 유지    | backing track, lyric, tempo 추가 | rhythm/pitch/lyric 중 1개만 피드백 | target tempo lyric pass | **[A/B/C]** |
| 4. Feedback Fading       | 외부 피드백 없이 자기 수정       | self-rating first, guide fade  | 피드백 빈도 감소                    | guide-off pass          |   **[A/B]** |
| 5. Retention             | 시간이 지나도 유지            | 24–48h retake                  | A2 vs R1 차이                  | 하락 허용폭 이내               |   **[A/B]** |
| 6. Transfer              | 새 프레이즈에 적용            | 같은 난이도 새 phrase                | 최소 피드백                       | 3회 이내 pass              | **[A/B/C]** |

### 8.2 Repertoire Selection Framework

**곡 단위 추천보다 phrase-first 추천을 기본으로 한다.** **[C]**

| 점수 영역               | 비중 | 세부 항목                                                                           | 제품 판단                             |
| ------------------- | -: | ------------------------------------------------------------------------------- | --------------------------------- |
| Vocal Fit           | 35 | range, tessitura, passaggio exposure, key options, fatigue risk                 | 안전 필터. 기준 초과 시 추천 제외 또는 transpose |
| Musical Complexity  | 25 | rhythm complexity, melodic complexity, tempo, melisma, interval size            | 난이도 레벨링                           |
| Lyric/Language Load | 15 | syllable density, language familiarity, consonant clusters, semantic complexity | Speak/Rhythm scaffold 필요성 판단      |
| Phrase Architecture | 10 | phrase length, breath points, rests, repeated patterns                          | sub-phrase chaining 여부 판단         |
| Context Assets      |  5 | backing quality, guide vocal, slow versions, stems                              | lesson 제작 가능성 판단                  |
| Motivation/Identity | 10 | user preference, genre goal, cultural appropriateness, veto option              | 사용자 선택권과 윤리 필터                    |

난이도 레벨:

| Level | 특징                                                        | 사용자 능력                       |
| ----- | --------------------------------------------------------- | ---------------------------- |
| R0    | 5음 이내, 짧은 프레이즈, 느린 템포, 단순 가사                              | 음정·리듬 baseline               |
| R1    | limited range, stepwise, short phrase, simple rhythm      | 쉬운 프레이즈 독립 수행                |
| R2    | moderate range, 일부 leap, 중간 phrase, 반복 패턴                 | B scaffold 후 lyric 통합        |
| R3    | syncopation, passaggio 인접, 빠른 가사, medium-high tessitura   | guide fade 가능                |
| R4    | long phrase, larger intervals, melisma, 높은 tessitura      | backing-only performance     |
| R5    | style nuance, riff/ornament, expressive timing, endurance | transfer와 performance polish |

### 8.3 Phrase Difficulty Framework

**Phrase Difficulty Score =**
0.20 Tessitura Load + 0.15 Range Span + 0.15 Melodic Complexity + 0.15 Rhythm Complexity + 0.15 Lyric Complexity + 0.10 Phrase Length/Breath + 0.05 Backing Independence + 0.05 Style/Ornament Load. **[C]**

| 변수                   | 측정 예                                       | 난이도 상승 조건                |
| -------------------- | ------------------------------------------ | ------------------------ |
| Tessitura Load       | phrase note-time 중 high zone 비율            | high zone 체류 길수록 상승      |
| Range Span           | phrase 내 semitone span                     | span이 넓고 극단음 포함 시 상승     |
| Melodic Complexity   | leap, chromaticism, contour turns          | 큰 도약·반음계·melisma 증가      |
| Rhythm Complexity    | subdivision, syncopation, pickup           | off-beat, 빠른 syllable 증가 |
| Lyric Complexity     | syllable/sec, consonant clusters, language | 빠른 가사·낯선 언어·자음군 증가       |
| Phrase Length        | seconds, syllables, breath points          | 긴 phrase와 숨쉴 지점 부족       |
| Backing Independence | guide 필요도, harmonic ambiguity              | guide-off 실패 시 상승        |
| Style Load           | vibrato, riff, belt, diction, articulation | 스타일 효과가 기술 안정성을 흔들 때 상승  |

### 8.4 72~120 Lesson Structure

권장 기본안은 **96 lessons = 12 modules × 8 lessons**이다. 72 lessons 버전은 각 모듈 6 lessons로 압축하고, 120 lessons 버전은 각 모듈 10 lessons로 확장한다. **[C]**

| Module                         | Lessons | 사용자 졸업 능력                      | 핵심 훈련과제                                       | 졸업기준                        |
| ------------------------------ | ------: | ------------------------------ | --------------------------------------------- | --------------------------- |
| 1. Voice Profile & Safety      |     1–8 | 자기 안전 범위와 위험 신호를 안다            | range check, comfort zone, fatigue log        | safe range profile 생성       |
| 2. Repertoire Fit              |    9–16 | 자기에게 맞는 프레이즈를 선택한다             | range/tessitura 비교, key 선택                    | 3개 후보 중 안전 곡 선택             |
| 3. Recording Literacy          |   17–24 | 자기 녹음을 듣고 오류를 분류한다             | A0 take, self-rating, waveform/pitch view     | 주요 오류 1개 정확히 선택             |
| 4. Text & Rhythm               |   25–32 | 가사를 리듬으로 말할 수 있다               | Speak, Rhythm Speak, clapped rhythm           | target rhythm 2회 pass       |
| 5. Chant & Contour             |   33–40 | 멜로디 윤곽을 단순화해 유지한다              | chant, contour tracing, slow tempo            | contour error 감소            |
| 6. Hum/Vowel Mapping           |   41–48 | 가사 없이 멜로디와 성도 조절을 안정화한다        | hum, vowel, slow lyric                        | vowel pass 후 lyric 진입       |
| 7. Lyric Reintegration         |   49–56 | 가사와 멜로디를 재통합한다                 | slow lyric → target tempo lyric               | lyric accuracy + pitch 유지   |
| 8. Range/Tessitura Application |   57–64 | 높은/낮은 구간에서 무리 없이 유지한다          | key adjust, high-zone phrase caps             | yellow/red 없이 pass          |
| 9. Rhythm/Melodic Complexity   |   65–72 | syncopation/leap/melisma를 처리한다 | variable tempo, interval drills, phrase loops | 같은 난이도 3 phrase pass        |
| 10. Backing Track Independence |   73–80 | 반주 안에서 독립적으로 부른다               | full backing → sparse → backing-only          | backing-only pass           |
| 11. Guide Vocal Fade           |   81–88 | guide 없이 수행한다                  | guide 100/50/25/off                           | guide-off target tempo pass |
| 12. Performance & Transfer     |   89–96 | 새 프레이즈로 전이한다                   | delayed retake, unseen phrase, final set      | retention + transfer pass   |

Lesson template:

1. **Context Listen**: 전체 문맥 20–40초. **[C]**
2. **A0 Diagnostic**: Lyrics → Sing. **[C]**
3. **Scaffold Decision**: 오류 유형별 B 단계 선택. **[C]**
4. **Micro Drill**: Speak/Rhythm/Chant/Hum/Vowel 중 1–2개. **[A/B/C]**
5. **A1 Integrated Take**: lyric + backing. **[C]**
6. **Self Review First**: 사용자가 오류 선택. **[A/B]**
7. **App Feedback**: 1개 우선 피드백. **[A/B]**
8. **Graduation or Loop**: pass, repeat, regress, rest 중 하나. **[C]**

### 8.5 Recording A/B System

**목표:** 사용자가 “좋아졌는지”가 아니라 **왜 좋아졌는지, 다음에 혼자 재현할 수 있는지**를 알게 한다. **[C]**

| 비교          | 질문                        | 지표                              | 통과                   |
| ----------- | ------------------------- | ------------------------------- | -------------------- |
| A0 vs A1    | scaffold 후 실제 프레이즈가 좋아졌는가 | pitch/rhythm/lyric/phrase score | 1개 primary metric 개선 |
| A1 vs A2    | guide를 줄여도 유지되는가          | guide-off score                 | guide-off pass       |
| A2 vs R1    | 시간이 지나도 유지되는가             | delayed retention               | 하락 허용폭 이내            |
| A2 vs T1    | 새 프레이즈로 전이되는가             | transfer phrase pass            | 3회 이내 pass           |
| Self vs App | 사용자가 자기 오류를 들었는가          | self-rating calibration         | 동일 오류 범주 선택          |

### 8.6 Graduation Criteria

다음 threshold는 연구에서 보편적으로 확정된 임상 기준이 아니라 **제품 루브릭**이다. 장르, 비브라토, 마이크 품질, 표현 의도에 따라 조정해야 한다. **[C/D]**

| 레벨               | 졸업 기준                                                                               |
| ---------------- | ----------------------------------------------------------------------------------- |
| Phrase Pass      | guide-off, backing-only, target tempo에서 pitch/rhythm/lyric/phrase 기준 충족             |
| Retention Pass   | 24–48시간 후 같은 조건에서 기준 유지                                                             |
| Transfer Pass    | 같은 difficulty band의 unseen phrase를 3회 이내 통과                                         |
| Self-review Pass | 사용자 자기평가가 앱 또는 human rubric과 같은 오류 범주                                               |
| Safety Pass      | 통증, 쉰 목소리, 고음 상실, 과도한 피로 없이 완료                                                      |
| Module Pass      | 서로 다른 2곡 이상에서 같은 기술 적용                                                              |
| Track Graduation | 사용자가 새 곡을 선택하고, 난이도를 판단하고, B scaffold를 설계하고, guide-off backing-only performance를 완성 |

예시 metric:

| 지표               |                          Beginner |           Intermediate |                   Advanced |
| ---------------- | --------------------------------: | ---------------------: | -------------------------: |
| Pitch target     | note-time 70–80% within tolerance |                 80–88% |                    88–92%+ |
| Rhythm onset     |                         넓은 window |              중간 window |                  좁은 window |
| Lyric alignment  |                          핵심 단어 정확 |     syllable alignment |       diction/style nuance |
| Guide dependency |                      guide 25% 허용 |              guide-off | guide-off + sparse backing |
| Transfer         |                   같은 곡 내 새 phrase | 같은 difficulty 새 phrase |          다른 곡·다른 key/tempo |

### 8.8 Copyright Safe Phrase Strategy

**[A]** 음악 앱은 “짧은 구절이면 안전하다”는 가정으로 설계하면 안 된다. 미국 저작권청은 저작권이 고정된 원저작물에 발생하며, musical composition과 sound recording이 별도 권리라고 설명한다. 또한 fair use에는 특정 단어 수, 음표 수, 퍼센트에 관한 안전 규칙이 없고 상황별 판단이라고 안내한다. ([저작권청][15])

권장 전략:

1. **Original micro-repertoire 우선**: 유명곡을 직접 쓰지 말고, “높은 tessitura + syncopation + 8 syllables/sec” 같은 난이도 프로파일만 모사한 새 프레이즈를 제작한다. **[C]**
2. **Public domain도 녹음은 별도 확인**: 곡이 public domain이어도 특정 음원 녹음은 별도 sound recording 권리일 수 있으므로 자체 녹음한다. ([저작권청][16]) **[A/C]**
3. **Licensed catalog는 composition + lyrics + sound recording + derivative/interactive use를 별도 확인**: 반주 제작, 가이드 보컬 녹음, 앱 내 재생, 사용자 녹음 저장은 권리 범위가 다를 수 있다. **[A/C]**
4. **No “safe number of notes” rule**: 공정이용을 상업 앱의 기본 전략으로 삼지 않는다. ([저작권청][17]) **[A]**
5. **Difficulty clone, not song clone**: 멜로디 윤곽, 가사, 리듬 훅, 코드 진행의 조합이 원곡을 식별 가능하게 만들지 않도록 법무 검토 기준을 둔다. **[C]**
6. **User-upload mode는 별도 정책**: 개인 학습용 분석, 서버 저장, 공유, 공개 피드, AI 재생산은 권리 리스크가 다르므로 지역별 법무 검토와 이용약관이 필요하다. **[C]**
7. **Asset CMS에 권리 상태를 필수 필드화**: “original / public domain composition + original recording / licensed / blocked territory / expiration date”를 lesson publish gate로 만든다. **[C]**
