## 1. Executive Summary

**결론:** Advanced R&B / Soul Lab은 “빠른 run/riff 앱”이 아니라 **tone color, vowel agility, groove, timing nuance, phrasing restraint, controlled ad-lib, recording review literacy**를 반복적으로 통합하는 **performance-skill loop**로 설계해야 합니다. NATS / *Journal of Singing* 계열 CCM 논문들은 CCM 스타일이 클래식 발성의 단순 응용이 아니며, R&B는 가벼운 전달감, 장식음, melisma, 빠른 vibrato가 자주 나타나고 Soul은 legato, dynamic range, 정서적 전달을 중시한다고 정리합니다. 다만 이 설명만으로 R&B/Soul 전체를 환원하면 안 되며, Berklee·NYU의 contemporary voice 커리큘럼은 rhythm articulation, syncopation, tone color, microphone/recording, improvisation, style integrity까지 학습성과로 다룹니다. [B] 

**제품 원칙:** 사용자가 “무엇을 배웠는가”가 아니라 **무엇을 안정적으로 할 수 있게 되었는가**로 커리큘럼을 정의해야 합니다. 즉, “melisma lesson”이 아니라 “사용자가 한 모음 위에서 3-note run을 느린 템포로 정확히 연결하고, 같은 패턴을 lyric vowel로 옮겨도 groove와 tone이 무너지지 않는다”가 졸업 기준입니다. Motor learning 연구는 세션 중 즉시 좋아진 수행과 실제 학습을 구분하고, retention과 transfer를 확인해야 한다고 봅니다. [A/B]

## 3. Consensus

### 전문가 합의 Consensus

1. **R&B/Soul 역량은 run/riff 하나로 정의되지 않는다.** Tone quality, style-specific phonation, registration, rhythmic phrasing, melisma, dynamic nuance, improvisation, recording awareness를 함께 다뤄야 한다. [B] 

2. **느린 run 훈련은 빠른 run의 선행 조건이다.** 다만 느린 연습은 최종 수행과 다른 breath, vowel, jaw, tongue pattern을 쓰면 transfer가 약하다. 앱은 “느리게 성공”이 아니라 “느려도 같은 모음 연결, 같은 subdivision, 같은 phrase breath”를 검증해야 한다. [B/C] 

3. **SOVTE는 R&B/Soul Lab의 기본 안전 fallback으로 적합하다.** Straw, lip trill, hum, nasal, fricative 계열은 high-load drill 사이의 reset 또는 warm-up bridge로 설계할 수 있다. 다만 healthy singer에게 모든 SOVTE가 항상 우월하다는 결론은 아니므로, 앱은 치료 효과를 약속하면 안 된다. [A/B] 

4. **Breathy tone은 색채로는 허용되지만 기본 발성값이 되면 위험하다.** ASHA와 NIDCD는 breathy, rough, strained, hoarse quality와 vocal fatigue를 voice problem sign으로 다루며, NIDCD는 피곤하거나 쉰 상태에서 노래하지 말라고 권고한다. [A] ([ASHA][1])

5. **Groove는 beat accuracy보다 넓은 개념이다.** Timing, attack shape, timbre, intensity가 상호작용하므로, R&B/Soul 앱은 pitch tuner처럼 “정확/부정확”만 표시하면 안 된다. [A/B] ([Cambridge University Press & Assessment][2])

6. **Behind-the-beat / ahead-of-beat은 tempo를 늦추거나 당기는 것이 아니다.** 안정된 pulse를 유지하면서 특정 phrase anchor를 미세하게 배치하는 기술로 설계해야 한다. 이 부분은 연구와 교육 현장 모두 “단순 공식화”에 주의가 필요하다는 방향으로 모인다. [B/D] 

7. **Ad-lib은 자유도가 아니라 제한된 선택지를 다루는 능력에서 시작한다.** Berklee 계열 자료는 pop/R&B improvisation을 melody, rhythm, harmony, language, pentatonic/blues vocabulary, tone color의 결합으로 설명한다. [B] ([Berklee Online][3])

8. **녹음 리뷰는 pitch보다 넓은 performance rubric이어야 한다.** Advanced R&B/Soul에서는 pitch가 기본 통과 조건일 뿐, groove, tone color stability, vowel continuity, dynamic arc, phrase intent, onset/offset, self-reported effort가 더 큰 제품 가치를 만든다. [A/B] ([음악정보검색국제학회 트랜잭션][7])

## 4. Controversies

### 전문가 논쟁 Controversy

1. **SOVTE의 효과와 dosing은 아직 단일 공식이 없다.** SOVTE의 acoustic/aerodynamic rationale은 강하지만, 건강한 singer에게 즉각적 효율 향상이 항상 나타나는 것은 아니며, 일부 연구는 효과가 조건·대상·과제에 따라 달라진다고 본다. 제품에서는 “SOVTE = 만능 해결책”이 아니라 “저부하 reset option”으로 둬야 한다. [A/B] 

2. **Microtiming이 groove를 항상 높인다는 믿음은 논쟁적이다.** Groove 연구는 microtiming, attack, timbre, intensity의 상호작용을 보지만, Davies et al.은 systematic microtiming deviation이 일부 조건에서 groove rating을 낮출 수 있음을 보고했다. 그래서 앱은 “항상 beat 뒤로 밀어라” 같은 규칙을 금지해야 한다. [A] ([Cambridge University Press & Assessment][2])

3. **CCM/R&B pedagogy의 표준 용어와 progression은 아직 통일되지 않았다.** NATS/Journal of Singing 자료는 CCM-specific training의 필요성을 강조하지만, R&B/Soul run, melisma, airy tone, ad-lib을 앱 레벨 progression으로 검증한 표준 모델은 부족하다. [B/C] 

4. **Breathy tone의 미학과 건강 리스크 사이에는 긴장이 있다.** R&B/Soul에서 airy intimacy는 스타일 자원일 수 있지만, breathy/weak/hoarse voice는 voice disorder sign으로도 나타난다. 앱은 “소리의 미학”과 “사용자 상태”를 분리해 평가해야 한다. [A/B/C] ([ASHA][1])

### 근거 부족 Insufficient Evidence

1. **R&B/Soul 전용 melisma 앱 progression의 직접 연구는 부족하다.** 따라서 3-note → 5-note → vowel-linked → groove phrase → ad-lib 구조는 연구 기반 원칙과 교육 현장 합의를 통합한 제품 설계안이며, 직접 임상·교육 검증 모델은 아니다. [D]

2. **정확한 repetition cap, BPM unlock, airy-tone 시간 제한의 숫자는 연구로 확정되지 않았다.** 아래 제안하는 수치는 vocal health red flag와 motor learning 원칙을 반영한 보수적 제품 가드레일이다. [D] ([NIDCD][4])

3. **AI가 breathiness, strain, groove를 완전히 진단할 수 있다는 근거는 부족하다.** 앱의 acoustic feature는 교육용 proxy일 뿐이며, 의료적 판단으로 쓰면 안 된다. [D] ([MDPI][6])

| Groove phrase                | phrase를 beat 위, 살짝 뒤, 살짝 앞에 배치하되 tempo drift 없이 유지한다.         | onset/vowel anchor timing, tempo drift, dynamic accent          | [A/B/D] |
| Dynamic nuance & restraint   | 큰 기교 없이 phrase arc, silence, soft intensity, release를 설계한다.   | dynamic curve, phrase ending, over-singing flag                 | [B/C]   |
| Ad-lib preparation           | 제한된 note pool로 1–2 bar call-response를 만들고 원 melody로 돌아온다.     | harmonic landing, motif coherence, space ratio                  | [B/D]   |
| Recording review literacy    | 자신의 take를 pitch보다 groove, tone, vowel, phrase 기준으로 먼저 리뷰한다.   | self-rating vs app feedback agreement                           | [A/B]   |

### 5.2 Run / Riff Progression

| 단계                    | 학습목표                               | 훈련과제                                  | 피드백                                     | 졸업기준                      |
| --------------------- | ---------------------------------- | ------------------------------------- | --------------------------------------- | ------------------------- |
| 0. Safety + reset     | 사용자가 low-load 상태로 시작한다.            | hum, lip trill, straw, /v z m ŋ/ 중 선택 | effort, onset ease                      | 통증·쉰 목·피로 없음              |
| 1. Pitch map          | run을 “빠른 장식”이 아니라 음군으로 듣는다.        | 3개 음을 말하기→허밍→한 모음으로 sing              | pitch contour, note order               | 3회 중 2회 correct contour   |
| 2. 3-note run         | 짧은 run을 한 모음으로 연결한다.               | 1-2-3, 3-2-1, 1-3-2 등                 | vowel continuity, jaw motion self-check | 2 tempo에서 안정              |
| 3. 5-note run         | 음군을 chunk로 처리한다.                   | 1-2-3-5-3, pentatonic/blues fragment  | grouping, breath, rhythm                | chunk 2+3 / 3+2 모두 가능     |
| 4. Vowel-linked run   | lyric vowel로 전환해도 흐름을 잃지 않는다.      | /a/→/e/→/ɪ/ 또는 실제 lyric vowel         | vowel morph, consonant reattack flag    | 모음 바뀌어도 tempo drift 없음    |
| 5. Rhythm-locked run  | run을 subdivision 안에 넣는다.           | 8th, triplet, 16th-lite grid          | onset alignment, duration evenness      | pitch보다 rhythm 먼저 pass    |
| 6. Tone-stable run    | run 중 tone color가 무너지지 않는다.        | warm clean, controlled airy 금지/허용 비교  | tone variance, breath noise             | clean tone에서 먼저 pass      |
| 7. Phrase-context run | run이 가사와 phrase arc를 해치지 않는다.      | 1-bar line 안에 run 삽입                  | phrase arc, lyric clarity               | run 없는 take보다 음악적이어야 pass |
| 8. Ad-lib bridge      | run vocabulary를 짧은 response로 사용한다. | 2-bar call-response                   | harmonic landing, space                 | melody 복귀 성공              |

이 progression은 speed-first가 아니라 **slow accuracy → vowel continuity → groove placement → phrase usefulness** 순서입니다. [B/C] 

### 5.3 Mandatory Training Items

| 항목                       | 선행 조건                                                  | 훈련 방법                                               | 반복 제한                           | 안전 fallback                     | 녹음 리뷰 기준                                            |
| ------------------------ | ------------------------------------------------------ | --------------------------------------------------- | ------------------------------- | ------------------------------- | --------------------------------------------------- |
| **Slow run builder**     | health check pass, comfortable range, clean onset      | target tempo의 50–70%에서 hum→single vowel→lyric vowel | pattern당 6회 × 2세트, 세트 사이 45–60초 | lip trill, straw, hum, key down | pitch path, vowel continuity, jaw stability, effort |
| **3-note run**           | 3음 pitch map 인지, one-breath phrase 가능                  | 1-2-3 / 3-2-1 / 1-3-2를 한 모음으로 연결                    | 방향당 8회 이하                       | /ŋ/ 또는 /m/으로 축소                 | note order, rhythm, no glottal reattack             |
| **5-note run**           | 3-note run 2회 연속 pass                                  | pentatonic/blues 5음 fragment, 2+3 chunking          | pattern당 5회 × 2세트               | 3-note로 rollback                | chunk clarity, breath stability, tone 유지            |
| **Vowel-linked run**     | same-vowel 5-note pass                                 | /a-e-i/ 또는 실제 lyric vowel morphing                  | 5회 이하                           | single-vowel로 rollback          | vowel jump 없음, consonant reattack 없음                |
| **Groove phrase**        | clap/speak subdivision pass                            | spoken rhythm→one pitch→melody, drum loop 사용        | take 6개 이하                      | spoken-only, one-note chant     | tempo drift, consonant/vowel anchor, dynamic accent |
| **Tone A/B**             | clean modal phrase, no fatigue                         | 같은 phrase를 A warm clean / B target color로 녹음        | A/B pair 4개 이하                  | clean tone만 유지                  | 색채 차이, loudness bias, effort 변화                     |
| **Controlled airy tone** | clean tone pass, hoarseness 없음                         | low–mid phrase에서 짧은 airy color; clean take와 비교      | airy total 60초 이하/session       | hum, clean tone, SOVTE          | breath noise, fatigue, tone core 유지                 |
| **Ad-lib preparation**   | 5-note, groove phrase, tone A/B, harmonic landing pass | 1–2 bar call-response, 제한 note pool, rest 필수        | ad-lib take 6개 이하               | melody paraphrase only          | landing note, space ratio, phrase 복귀                |

반복 제한 숫자는 확정 연구값이 아니라 앱 안전 설계를 위한 보수적 cap입니다. 통증, 쉰 목소리, 목 조임, 갑작스러운 range loss, 피로가 있으면 수치와 무관하게 즉시 중지해야 합니다. [A/D] ([ASHA][1])

### 5.4 Groove / Timing Training System

| 레이어             | 사용자가 할 수 있게 되는 일                     | 앱 과제                              | 피드백                        |
| --------------- | ------------------------------------ | --------------------------------- | -------------------------- |
| Pulse lock      | beat를 잃지 않는다.                        | tap → speak → sing                | tempo drift                |
| Subdivision     | 8th, triplet, 16th-lite 위치를 느낀다.     | clap grid, spoken lyric grid      | subdivision accuracy       |
| Phrase anchor   | consonant와 vowel onset을 구분한다.        | “자음은 준비, 모음이 landing” 표시          | vowel anchor timing        |
| On-beat pocket  | 먼저 정위치 phrase를 만든다.                  | click/drum loop에 line 녹음          | timing spread              |
| Behind-the-beat | beat를 늦추지 않고 phrase anchor만 뒤에 둔다.   | same phrase: on-grid vs laid-back | anchor offset, tempo drift |
| Ahead-of-beat   | rushing 없이 phrase tension을 만든다.      | same phrase: on-grid vs pushed    | next downbeat recovery     |
| Groove phrase   | timing, attack, tone, dynamic을 통합한다. | 2-bar phrase 3-take review        | groove composite           |

초중급자에게는 “뒤에 불러라”가 아니라 **“beat는 그대로, 첫 모음 landing만 reference 뒤쪽 창에 놓아라”**라고 보여줘야 합니다. Behind/ahead는 tempo change가 아니라 placement입니다. [B/D] Groove는 microtiming만으로 결정되지 않고 attack shape, timbre, intensity가 함께 작용하므로, timing score 하나로 groove를 판단하지 않아야 합니다. [A] ([Cambridge University Press & Assessment][2])

### 5.5 Tone Color A/B System

| A/B 과제                                     | 사용자가 할 수 있게 되는 일                       | 피드백 기준                                        | 위험 관리                         |
| ------------------------------------------ | -------------------------------------- | --------------------------------------------- | ----------------------------- |
| Warm clean vs Speech-bright                | 같은 pitch에서 color만 바꾼다.                 | spectral tilt proxy, loudness control, effort | brightness가 shouting으로 변하면 중지 |
| Clean core vs Controlled airy              | airy를 default가 아닌 장식으로 쓴다.             | breath noise, phrase length, fatigue          | hoarseness/fatigue 시 lock     |
| Straight tone vs Gentle vibrato            | vibrato를 자동 습관이 아니라 선택지로 쓴다.           | vibrato onset, rate stability                 | jaw vibrato flag              |
| Dark vowel blend vs Lyric-neutral          | vowel color와 intelligibility 균형        | vowel consistency, lyric clarity              | 과도한 vowel modification 방지     |
| Intimate mic tone vs Open chorus tone      | recording context별 tone을 바꾼다.          | loudness normalization, mic distance          | 큰 소리 pushing 방지               |
| Legato color vs Rhythmic consonant-forward | Soul legato와 R&B rhythmic phrasing을 구분 | consonant timing, phrase flow                 | throat attack 방지              |

Tone A/B의 핵심은 “더 예쁜 소리”가 아니라 **같은 phrase에서 하나의 변수만 바꾸고, 나머지 pitch·rhythm·loudness·effort를 유지하는 능력**입니다. [B/C] ([Berklee Online][10])

### 6.2 App Feedback Architecture

제품은 **실시간 피드백 1개 + 녹음 후 리뷰 4개 레이어**로 설계하는 것이 안전합니다. 실시간 visual feedback은 pitch, intensity, spectrogram, airflow proxy 등을 시각화할 수 있지만, 과도한 실시간 feedback은 사용자의 주의와 자기조절을 방해할 수 있습니다. [A/B] ([MDPI][6])

**Live 중 표시할 것:**
현재 과제의 1개 핵심 지표만 표시합니다. 예를 들어 Slow Run Builder에서는 “tempo/subdivision”만, Tone A/B에서는 “loudness normalization”만 보여줍니다.

**Review 후 표시할 것:**

1. Timing lane: onset, vowel anchor, tempo drift
2. Tone lane: tone stability, breath noise proxy, loudness bias
3. Vowel/run lane: pitch contour, vowel continuity, note grouping
4. Safety lane: effort score, fatigue trend, red flag response

Pitch는 숨기지 않되, Advanced R&B/Soul Lab에서는 **Pitch 단독 점수로 pass/fail을 결정하지 않습니다**. [A/B]

## 7. Safety Considerations

### 7.1 Safety Cap Table

| 과제 유형                  |                기본 cap | 즉시 중지 조건                                          | fallback                       | 근거 수준                   |
| ---------------------- | --------------------: | ------------------------------------------------- | ------------------------------ | ----------------------- |

| Slow run / 3-note      |         pattern당 6–8회 | jaw/tongue tension, glottal attack, pitch squeeze | hum, /ŋ/, lip trill            | [B/D]                   |
| 5-note run             |     pattern당 5회 × 2세트 | breath grab, throat push, speed panic             | 3-note rollback                | [B/D]                   |
| Vowel-linked run       |                 5회 이하 | vowel가 턱 움직임으로만 바뀜, lyric collapse                | same-vowel rollback            | [B/C/D]                 |
| Groove phrase          |            take 6개 이하 | rushing/dragging 때문에 목으로 밀기                       | spoken rhythm, one-note chant  | [A/B/D]                 |

| High-intensity effects |               앱 기본 금지 | growl, scream, fry blast, pressed belt 반복         | 전문 지도 안내                       | [A/B]                   |
| Sick/hoarse day        | voiced challenge lock | 감기, 염증, 쉰 목, steroid 복용 후 heavy load              | rest / medical advice          | [A]                     |

NIDCD는 피곤하거나 쉰 상태에서 노래하지 말고, 아플 때는 voice rest를 고려하며, screaming·whispering 같은 극단적 사용을 피하라고 권고합니다. NIDCD의 hoarseness 자료는 과사용·오용이 nodules나 hemorrhage 같은 문제와 연결될 수 있다고 설명합니다. [A] ([NIDCD][4])

### 7.2 Breathy Tone 허용 / 차단 규칙

**허용:**
Controlled airy tone은 low–mid range, soft–moderate loudness, 짧은 phrase, clean tone으로 즉시 복귀 가능한 조건에서만 허용합니다. 사용자가 airy take 후 clean take를 다시 부를 수 있어야 pass입니다. [B/C]

**차단:**
지속적 breathy default, 고음 airy, 큰 소리 airy, fatigue가 있는 airy, hoarse day airy, throat pain이 있는 airy, phrase 끝마다 aspirated collapse가 있는 airy는 차단합니다. Breathy/weak/strained/hoarse quality는 voice problem sign으로도 나타날 수 있기 때문입니다. [A] ([ASHA][1])

### 7.3 고급 사용자에게도 금지해야 할 과제

1. 통증, 쉰 목소리, 피로 상태의 고강도 singing. [A]
2. “가능할 때까지 반복”하는 speed run challenge. [B/D]
3. whisper practice를 warm-up처럼 쓰는 과제. [A]
4. high belt + breathy onset + fast run 결합 과제. [A/B]
5. growl, scream, fry, pressed phonation을 앱 단독 과제로 제공하는 것. [A/B]
6. steroid 복용 또는 illness 상태에서 heavy vocal load를 유도하는 것. [A] ([더 보이스 재단][11])
7. AI가 “괜찮다”고 했다는 이유로 medical red flag를 무시하게 하는 UX. [A]

### 8.5 Portfolio Criteria

Advanced R&B / Soul Lab 졸업은 “높은 점수”가 아니라 **녹음 포트폴리오**로 판단합니다.

| Portfolio Artifact   | 제출물                                                           | Pass 기준                                       |
| -------------------- | ------------------------------------------------------------- | --------------------------------------------- |
| Tone A/B             | 같은 phrase의 warm clean / controlled airy 또는 warm / bright pair | 색채 차이가 들리지만 loudness와 effort가 과도하게 변하지 않음     |
| Slow Run             | 3-note와 5-note run slow/medium 비교                             | pitch path, rhythm, vowel continuity가 모두 pass |
| Vowel-linked Melisma | lyric vowel이 포함된 1-bar melisma                                | vowel reattack 없이 phrase 안에 통합                |
| Groove Phrase        | on-grid / behind / ahead 3 take                               | tempo drift 없이 placement 차이                   |
| Dynamic Restraint    | run 없이 Soul phrase arc                                        | over-singing 없이 phrase tension 유지             |
| Ad-lib Preparation   | 2-bar call-response                                           | harmonic landing, space, melody 복귀            |
| Recording Review     | blind A/B self-review                                         | pitch 외 기준 3개 이상으로 선택 이유 설명                   |
| Safety Log           | 4주 또는 6주 effort/fatigue log                                   | red flag 없이 완료, fallback 사용 기록                |

**Portfolio weighting 제안:** Groove/timing 25%, tone color 20%, vowel/run precision 20%, phrase/dynamic intent 15%, recording review literacy 10%, safety self-management 10%. Pitch는 run precision과 phrase clarity 안에 포함되지만, 단독 1순위 항목으로 두지 않습니다. [A/B/D] ([Cambridge University Press & Assessment][2])
