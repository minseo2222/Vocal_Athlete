# v8 Research Integration

## 목적

사용자가 제공한 20개 심층 리서치와 기존 음색 통합 리서치를 프로젝트의 장기 커리큘럼 근거로 편입한다. 원본을 바로 canonical 근거로 취급하지 않고, **출처 상태·근거 강도·대상 직접성·제품 가설**을 분리한다.

## 디렉터리

- `source-bundle/`: 사용자가 제공한 원본의 내용 보존본. 파일명만 정규화했다.
- `SOURCE-STATUS-MATRIX.md`: 문서별 출처 상태와 역할.
- `SOURCE-REGISTER.csv`: 원문에 포함된 URL을 추출·정규화한 레지스터.
- `EVIDENCE-TAXONOMY.md`: v8 이후 모든 커리큘럼 주장에 적용하는 이중 근거 태그.
- `EVIDENCE-MATRIX.md`: 제품 결정과 근거/가설 상태.
- `SOURCE-RECOVERY-BACKLOG.md`: 세션 종속 임시 인용 복구 대상.
- `RHYTHM-TIME-RESEARCH-GAP.md`: 독립 심층 문서가 없는 리듬 영역의 보완 계획.
- `VERIFIED-ANCHOR-SOURCES.md`: 공식 기관·원 논문에서 다시 확인한 최소 앵커.
- `RHYTHM-TIME-INTERIM-REVIEW.md`: 독립 리듬 문서 공백을 보완하는 간접 근거 리뷰.
- `SOVT-TRANSFER-INTERIM-REVIEW.md`: SOVT를 모음·프레이즈로 전이하는 정책.

## 적용 제한

- `01~05`는 내용은 반영하되 `turn...` 임시 인용이 복구되기 전 개별 주장 인용 근거로 사용하지 않는다.
- 임상 음성치료 근거는 건강한 가수의 성과 근거로 직접 일반화하지 않는다.
- 레슨 수, 반복 수, 주간 cap, 점수 임계치 등은 별도 검증이 없는 한 제품 가설 `[D-D]`로 표시한다.
- 고위험 기술은 연구 문서에 있어도 HITL·runtime cap·fallback 없이 공개하지 않는다.
