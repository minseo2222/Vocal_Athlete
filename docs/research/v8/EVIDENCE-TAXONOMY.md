# v8 Evidence Taxonomy

v8부터 근거를 **강도**와 **직접성/맥락**의 두 축으로 기록한다.

## 1. 근거 강도

| 코드 | 의미 |
|---|---|
| A | 체계적 문헌고찰·메타분석·공식 임상/정부 지침·반복된 고품질 연구 |
| B | 복수 연구의 일관된 경향 또는 전문 교육기관·현장 합의 |
| C | 전문가 종합, 단일 연구, 기관 관행, 제한적 직접 근거 |
| D | 제품 설계 가설, 수치 휴리스틱, 직접 검증 전 추론 |

## 2. 직접성/맥락

| 코드 | 의미 |
|---|---|
| S | 건강한 가수·가창 수행에 직접 적용된 근거 |
| C | 임상 음성치료·음성장애 대상 근거 |
| M | 일반 운동학습·음악인지·기억 연구의 간접 근거 |
| P | 보컬 페다고지 전문가 합의·대학/시험기관 커리큘럼 |
| D | 내부 데이터·제품 가설 또는 아직 검증되지 않은 설계 |

예: `[A-C]`는 강한 임상 근거, `[B-P]`는 반복되는 페다고지 합의, `[D-D]`는 제품 가설이다.

## 3. 제품 적용 규칙

- `[A-S]`, `[B-S]`: 학습 내용의 핵심 근거로 사용 가능.
- `[A-C]`, `[B-C]`: 안전한 과제 구조 참고 가능. 건강한 가수의 실력 향상 효과로 직접 표현 금지.
- `[A-M]`, `[B-M]`: 피드백·간격학습·전이 설계에 사용하되 보컬 직접 근거가 아님을 표시.
- `[B-P]`, `[C-P]`: 순서·레퍼토리 배치 참고 가능. 최적성·인과효과 주장 금지.
- `[D-D]`: 실험 플래그와 측정 계획이 있을 때만 구현. 안전 상한으로 단정 금지.
