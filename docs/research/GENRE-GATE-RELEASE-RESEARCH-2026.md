# 고급 장르 게이트 해제 — 안전 심의 연구 보고서 (2026)

> 출처: 자가 학습형(전문가 부재)·무채점·폰 기반 보컬 앱에서 고위험 발성 기법을 18세+ 일반
> 사용자에게 해제하는 문제에 대한 다학제(후두의학·SLP·발성교육·디지털헬스 규제) 심층 리서치.
> 운영 반영본은 `docs/verification/GENRE-RELEASE-SIGNOFF.md` §7. 근거 등급 A(강한 임상/실증)~F(반증).

## TL;DR (판정)
- **조건부 가능(CONDITIONALLY POSSIBLE) — 단 현 사양(F0·타이밍·자가보고만)에선 "기본 잠금 유지"가 정답.**
  통제 가능한 일부(저강도 메사 디 보체 크레셴도, 저강도 트왱)만, 강한 사전 스크리닝·노출 상한·증상
  기반 잠금·단계적 출시를 모두 갖춘 경우 해제 가능. 벨트/통성/하드 글로탈 고강도 변형은 **사실상 차단**.
- **결정적 한계:** 폰은 F0·타이밍만 신뢰 측정. 손상 핵심 인자(SPL·포먼트·충돌응력·부종)는 측정 불가
  → 앱은 "위험 감지" 불가, 오직 "노출 제한 + 자가보고 중단 유도"만 가능.
- **검증된 안전 도즈 부재:** "Researchers have yet to establish a safe baseline vocal dose for singers"
  (Zuim·Stewart·Titze, J Voice 2021·2023). 'enforced' 도즈 상한은 직접 근거 없는 보수적 외삽일 수밖에 없음.

## 핵심 발견(근거 등급)
1. 고위험 기법은 과기능·음성외상 경로 공유; 하드 글로탈 온셋이 MTD·양성병변과 가장 직접 연관 (A~B).
2. 다학제 합의(ASHA·NATS·PAVA·VASTA 공동성명, J Singing 2024)는 병리 의심 시 의학적 평가 요구,
   검토자는 후두과 전문의 + 음성 SLP + 스타일 보컬 교육자 조합 권고 (B).
3. 싱어 대상 안전 도즈 직접 근거 부재. Titze distance dose 안전한계(약 520 m ≈ 1,040초 ≈ 17분 연속
   발성)는 말하기/산업진동 유추 — 노래·고강도 직접 적용 불가, 보수적 하한 참조만 (C/D).
4. 폰은 F0만 r>0.90 신뢰; jitter·shimmer·CPP·SPL은 기기·환경 의존 커 위험판정 부적합 (A).
5. 검증 자가보고(VFI·VHI-10·EASE)는 사전 차단이 아니라 사후 증상 포착 도구. VFI 임상 컷오프는 잠금
   트리거로 활용 가능하나 자가-임상 평정 일치도 낮을 수 있음(SAVRa) (B).
6. 상용 발성법(Estill·CVT·SLS)의 "모든 소리는 건강하게" 주장은 임상근거 아닌 상용/합의 수준이며
   모두 전문가 실시간 피드백 전제 (E, commercial/consensus-level 강등).
7. 무채점·비진단·라이프스타일이면 FDA 일반웰니스(2026.1.6 개정 지침)·EU MDR 비의료기기 분류 가능성↑.
   단 질병 언급·진단 출력·"의료급" 주장 시 규제 대상 전환 (B).
8. 카나리(≤1% 시작)·피처플래그 kill-switch·즉시 롤백은 확립된 SW 모범사례, 게이트 모델에 직접 매핑.
   단 보컬 부작용 정량 임계는 임상 검증 부재 → 보수 설정 (B).

## 기법별 위험·게이트 매핑 (차원 1)
| 기법 | 기전·위험 | 근거 | 게이트 |
|---|---|---|---|
| 벨트 | TA 우세·고성문하압·firm adduction (Sundberg inverse-filtering) | B | 고강도 잠금 유지 |
| 통성 | 흉성 우세·고충돌; 판소리 결절·점막손상 반복 보고(RIICS 2021) | B/C | 고강도 잠금 유지 |
| 하드 글로탈 온셋 | 과기능 환자 65% 동반(Morrison/Nichol/Rammage 1986); MTD·병변군 빈도↑ | A~B | pending 유지 강력 권고 |
| 메사 디 보체 | 고급 기법(특히 디크레셴도); 저강도 크레셴도-only는 저위험 | C | 저강도만 signedOff 후보 |
| 트왱 | AES 협착·"safe shouting"; twang therapy 임상 사용(Lombard&Steinhauer 2007) | D~E | 저강도만 signedOff 후보 |
| 금기 대상 | 기존 병변·LPR·출혈위험·2주+ 쉰목소리·연하곤란·경부종괴·각혈·이통 → 즉시 의뢰(AAO-HNS) | A | 스크리닝 하드락 |

## 도즈·임계 근거(차원 3·5) — 전부 외삽/소표본/부재
- 안전 도즈: 부재(Zuim/Stewart/Titze 2021·2023; NCVS "threshold not established"). (D/부재)
- distance dose 안전한계 ≈ 520 m ≈ 1,040초(≈17분 연속) — 말하기 기준(Titze/Švec/Popolo 2003 JSLHR
  46:919; PMC3158591), 노래 직접적용 불가. (C/D)
- 조직 반응: 1시간 연속 큰소리 발성 후 IL-1β·TNF-α·MMP-8↑·경미 부종(Verdolini Abbott 2003, 건강 여성 1인
  예비; 로딩 75~90 dB@15cm 약 45분, 2012). (D 소표본)
- 충돌응력 in vivo <1~3 kPa(Verdolini/Hess/Titze 1999, 분석가능 7명); 일반 0.5~5 kPa(Titze 1994);
  비명 시뮬 ~20 kPa(Zhang 2020 계산모델). 손상확정 임계 미확립. (D+시뮬)
- 폰 측정: F0 r>0.90 (A); SPL·충돌응력·부종 측정 불가 → 위험 직접 감지 불가 (A).
- 자가보고 잠금: VFI(브라질판 총점 컷오프 11.50)·EASE 트리거 활용 가능, 민감도 한계(SAVRa 일치도 낮음) (B).

## A. Go/No-Go 게이트 체크리스트
| # | 항목 | 측정 가능 임계치 | 검증 주체 |
|---|---|---|---|
| A1 | 기법별 위험 문서화 | 6개 기법 위험·금기·기전 문서 + 후두과·SLP 서명 | 후두과 + 음성 SLP |
| A2 | 사전 스크리닝 하드락 | 적신호 1+ 양성 시 100% 차단 + 의료 의뢰 | 임상 자문 + QA |
| A3 | 노출 상한(enforced) | 고강도 연속시간을 17분/520 m보다 더 보수적(세션당 수 분), 강제 휴식 ≥24h, 주간 빈도 제한 | 음성 SLP + 엔지니어링 |
| A4 | F0·타이밍 집행 | F0 범위·세션 길이·휴식 간격 자동 제한 테스트 통과 | QA |
| A5 | 증상 기반 잠금 | VFI/EASE 컷오프 초과 또는 통증·쉰목소리 자가보고 시 자동 잠금 | 음성 SLP |
| A6 | 동의·면책 | 위험고지+위험인수 동의 100%, 관할별 문구 검토 | 법무 |
| A7 | 비의료기기 포지셔닝 | 질병 진단/치료 문구 0, "의료급" 주장 0 | 법무 + 규제 |
| A8 | 카나리 롤아웃 | ≤1% 시작, 부작용 자가보고율 사전 임계 미초과 시만 확대 | 제품 + 임상 |
| A9 | 롤백/킬스위치 | 임계 초과 시 자동 재잠금(revoked) 검증 | 엔지니어링 |

## B. 판정 근거 요약
조건부 가능, 기본 잠금. 트왱·메사 저~중강도만 A1~A9 전부 충족 시 해제 경로. 벨트·통성·하드 글로탈
고강도는 폰 측정 불가 + 안전 도즈 부재로 사실상 차단. 강한 근거(A~B)는 "위험"쪽(차원 1·2), 약한 근거(D)/
부재는 "안전 보장"쪽(차원 3·5)에 분포.

## C. 레드팀 — 위험·미지
위험: (1) 폰은 위험 감지 불가(SPL·충돌응력·부종 미측정, 손상 중에도 F0 정상으로 보일 수 있음).
(2) 자가보고 과소보고·일치도 낮음(SAVRa). (3) 잠재 병변·역류는 자기보고라 위음성 불가피.
(4) 하루 한계 내라도 연속일 누적효과(Hunter&Titze). (5) 상용 발성법 "안전" 마케팅 오인.
미지: 싱어 안전 도즈(부재), 손상확정 충돌응력/SPL 임계(미확립), 자가보고 잠금 민감도·특이도(미검증),
비감독 고위험 일반화 안전 증거(부재).

## D. 코드 게이트 매핑 (none→pending→signedOff→enforced→released→revoked)
- none→pending: 6개 기법 위험 문서화(A1) 착수.
- pending→signedOff: 후두과 + 음성 SLP(≥2인) + 스타일 보컬 교육자 서면 승인. 고강도 벨트/통성/하드 글로탈은
  이 단계에서 승인 보류(잠금 유지)가 기본.
- signedOff→enforced: 앱 캡 구현+테스트 — F0 범위 제한, 세션 연속시간·휴식 강제(A3·A4), 스크리닝 하드락(A2),
  증상 기반 잠금(A5).
- enforced→released: 동의·면책(A6) + 비의료기기 포지셔닝(A7) + 카나리 ≤1%(A8) 후 인적 최종 승인.
- released→revoked: 부작용 자가보고율 임계 초과 시 자동 즉시 재잠금(A9).

## 해제 가능 Top 3 vs 본질적 차단 Top 3
가능: (1) F0·타이밍 폰 신뢰 측정·집행(A). (2) 검증 자가보고 잠금(VFI 컷오프 등, B). (3) 카나리·즉시 롤백(B).
차단: (1) 싱어 안전 도즈 부재(Zuim/Stewart/Titze). (2) 폰 손상 인자 측정 불가(A). (3) 검증된 안전 기제는
사실상 전문가 핸드오프뿐, 비감독 고위험 경로 근거 부재(B).

## Caveats
일반 프로토콜 수준(개별 의학 조언 아님). 상용 발성법 주장은 commercial/consensus-level 강등. 도즈·임계는
말하기/산업진동/소표본 예비(예: Verdolini 2003 1인; 1999 7명) 외삽 — 노래·고강도 적용 불확실, ~20 kPa는
in vivo 아닌 시뮬(Zhang 2020). FDA(2026.1.6)/EU MDR 분류는 관할 법무·규제 최종 검토 필요. 불확실 시 잠금 유지.
