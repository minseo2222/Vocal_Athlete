# v15 Timbre Research Integration

업로드된 `TIMBRE-INTEGRATED-RESEARCH.md`를 v14 커리큘럼과 대조해 정규화한 묶음이다.

## 권위 순서

1. 제품·커리큘럼 규칙: `docs/curriculum/TIMBRE-TRAINING-SPEC.md`
2. 사용자 피드백 규칙: `docs/app/TONE-FEEDBACK-SPEC.md`
3. 음색 프로필 규칙: `docs/app/TONE-PROFILE-SPEC.md`
4. 근거 적용표: `TIMBRE-EVIDENCE-APPLICATION-MATRIX.md`
5. v15 재확인 앵커: `VERIFIED-ANCHOR-SOURCES.md`
6. 원문과 출처: `TIMBRE-INTEGRATED-RESEARCH.md`, `TIMBRE-SOURCE-REGISTER.csv`

## 근거 기호

- `S`: 건강한 가수·가창을 직접 다룬 연구
- `C`: 임상 음성치료·음성장애 근거
- `M`: 음향·운동학습·음악인지 간접 근거
- `P`: 공식 교육과정·전문기관·전문가 합의
- `D`: 제품 설계 가설

임상 근거는 건강한 사용자의 가창 향상을 직접 입증하는 자료처럼 사용하지 않는다. 고정 반복 수, 기간, 안전 상한은 별도 검증 전까지 `D`로 다룬다.
