# UNIVERSAL-CORE-RESEARCH-ADDENDUM — 2026-06-16 R3

## 1. 결정

장르 분기는 초급 직후가 아니라 Universal Vocal Core와 Repertoire Application 이후로 미룬다. 이유는 초급 직후 사용자는 장르별 technique보다 호흡, 발성, 청음, 리듬, 공명, 음색, 레지스터, 딕션, 짧은 곡 전이가 먼저 안정되어야 하기 때문이다.

## 2. 근거 축

- 보이스 페다고지 교육은 respiration, phonation, resonance, registration, articulation, health를 공통 시스템으로 다룬다.
- Berklee식 현대음악 교육도 technique, styles, performance, diction, ear training, rhythm, melody, recording/live sound 등 복합 역량을 다룬다.
- 고급 장르 technique은 safety risk가 크므로 고급 Lab + cap + HITL로 분리해야 한다.
- deliberate practice는 음악 성취와 관련 있지만, 무제한 반복이나 단순 시간 누적만으로 충분하지 않다. 목표, 피드백, 반복, 수정, 회복 cycle이 필요하다.

## 3. 제품 적용

- Universal Core 길이: 144레슨.
- Repertoire Application 길이: 72레슨.
- 고급 장르 Lab: 40-slot repeatable cycle.
- 초급 완료 UI: genre picker 제거, `중급 공통 코어 시작` CTA.
- 고급 picker: Repertoire Application 완주 후 노출.
