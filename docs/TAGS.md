# TAGS.md — 신규 도입 태그 정의

> 본 문서는 `docs/` 21개 파일에 신규 출처 통합 시 사용되는 태그의 표준 정의를 제공한다.
> Wave 1 이후 모든 수정에서 아래 5개 태그만 사용한다. 기존 *"출처 평가 태그"* 6필드(유형/저자 전문성/1차2차/상업성/최신성/교차검증)는 그대로 유지된다.

---

## 태그 일람

### 1. `[근거 부족]`
- **정의**: 1차 출처 부재, 또는 합의·전통 수준에 머물러 동료심사 검증이 없는 주장.
- **OCEBM 등급 대응**: 5(기전·전문가 의견) 또는 분류 불가.
- **사용 위치**: 카드 본문 끝 또는 "근거" 라인 직후. 본문에서는 최초 1회만 부착.
- **예**: "Placement 개념은 음향적으로 직접 측정되지 않는 운동감각 은유 `[근거 부족]`."

### 2. `[탐색적 근거]`
- **정의**: feasibility study, 비무작위 시험, 단일 케이스 시리즈, 파일럿(n<30) 등 RCT 미만의 시험적 증거.
- **OCEBM 등급 대응**: 2c~3.
- **사용 위치**: 해당 출처를 인용하는 같은 문장 또는 카드 "근거" 라인.
- **예**: "CVT 임상 적용은 Muscle Tension Dysphonia에서 feasibility 단계 통과 (McGlashan 2025 / *J Voice*) `[탐색적 근거]`."

### 3. `[Phase III RCT 부재]`
- **정의**: 브랜드 방법론(CVT/Estill/SLS/LMRVT/Somatic Voicework 등)에 대해 무작위 대조군 비교를 수행한 Phase III 임상시험이 2026년 5월 기준 부재함을 명시.
- **OCEBM 등급 대응**: 평가 자체가 미완.
- **사용 위치**: part 12 비교표·part MX Evidence Ladder·part 13 인물 카드의 "근거" 라인.
- **예**: "SLS의 핵심 명제 (후두 정지) 는 직접 측정 논문 부재 `[Phase III RCT 부재]`."

### 4. `[성악·CCM 병기]`
- **정의**: 동일 음향·기능 현상에 대해 클래식 성악과 CCM(현대상업음악) 학파의 정의·접근이 충돌하여 둘 다 보존하는 경우 사용.
- **사용 위치**: 충돌 현상의 본문 도입부, 그 직후 두 관점을 *"성악:"*, *"CCM:"* 으로 병기.
- **예**: "Twang의 정의 `[성악·CCM 병기]`. 성악: 코소리·비음 회피 대상. CCM: AES narrowing으로 의도적 사용 (Estill, McGlashan 2017)."

### 5. `[K-pop 산업관행]`
- **정의**: K-pop 기획사·트레이너 인터뷰·언론 보도 등 산업 1차 자료에 근거하지만 학술적으로 동료심사된 출처가 아직 없는 항목.
- **사용 위치**: K-pop 명명 연습(k-keok, kkook, siren, lip bubble 등) 카드, 트레이닝 시스템 표.
- **부속 원칙**: 항상 SOVT 또는 Estill 등 학술 대응을 함께 표기. 예: `(SOVT 대응: lip trill; Estill 대응: AES narrowing)`.
- **예**: "*k-keok* 자음 강화 드릴 `[K-pop 산업관행]` (SOVT 대응: 강한 어택 자음; Estill 대응: 성문 onset 컨트롤). 출처: Korea Herald 트레이너 인터뷰 (검증 필요)."

## 태그 부착 규칙

1. **한 항목에 복수 태그 가능**. 예: K-pop *kkook* 드릴이 학술 검증 미흡 + 산업 관행이라면 `[K-pop 산업관행] [근거 부족]` 함께 부착.
2. **대각괄호 표기 고정** (`[ ]`). 한국어 본문 내에서도 대괄호 사용.
3. **삭제 대신 태그**: 기존 내용이 근거 약하더라도 삭제하지 않고 태그를 부착해 "근거가 약함"을 명시한다 (사용자 지시 6번 원칙).
4. **인용과 동시 표기**: `(저자 연도 / 저널)` 형식의 인용과 함께 부착할 때 인용을 *앞*에 둔다. 예: "(Wicks 2019 / *J Singing*) `[Phase III RCT 부재]`".
5. **태그 인덱스**: Wave 5 종료 시 `[근거 부족]` / `[탐색적 근거]` / `[Phase III RCT 부재]` 부착된 모든 항목을 part 16 부록에 인덱스화한다.

## 기존 표기와의 관계

- 기존 `[CITE: KEY]` 플레이스홀더는 그대로 유지하되, KEY 값은 `CITATIONS.md`에 정의된 키와 일치시킨다.
- 기존 *"(검증 필요)"* 표기는 신규 태그로 대체하지 않는다(저자 의도가 다름). 다만 *"(검증 필요)"* 항목 중 동료심사 미달이 확인된 것은 본 태그를 *추가* 부착할 수 있다.
- 기존 카드 하단의 *"출처 평가 태그"* 6필드는 그대로 유지하며, 본 태그는 카드 본문 또는 "근거" 라인에 부착한다 (위치 분리).
