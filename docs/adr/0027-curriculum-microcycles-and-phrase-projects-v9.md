# ADR-0027 — v9 Curriculum Microcycles and Phrase Projects

- Status: accepted for design; learning efficacy unverified
- Date: 2026-06-19

## Context

v8 path는 Universal Core에서 같은 12-card loop를 반복하고, Repertoire Application에서 Global/Local/Recall/Transfer를 18일씩 분리했다. Recovery 카드도 일부 정상 manifest에 포함되어 있었다.

## Decision

1. Beginner/Universal/Repertoire/Advanced 정상 path에서 `CARD-18`을 제거한다.
2. Universal Core를 12일 microcycle 12개로 재작성한다.
3. formal `UC-17` checkpoint는 Day 36/72/108/144에만 둔다.
4. `UC-18~25`로 breath renewal, pitch memory, subdivision, vowel continuity, key fit, phrase intention, SOVT transfer, self-coaching을 보강한다.
5. Repertoire Application을 12일 phrase project 6개로 재작성한다.
6. 각 project는 `RA-09` baseline으로 시작하고 `RA-10` delayed retrieval/transfer로 끝낸다.
7. R&B/Soul, Rock/Band, Worship에 전용 저위험 카드군을 추가한다.
8. 12일·144일·72일 수치는 제품 가설로 유지한다.

## Consequences

- 주요 능력이 더 자주 재등장한다.
- 한 프레이즈 안에서 Global→Local→Global이 완결된다.
- 녹음 checkpoint 부담이 감소한다.
- 카드·음원·테스트·문서 유지 비용이 증가한다.
- 학습 효과는 파일럿과 retention/transfer 측정이 필요하다.
