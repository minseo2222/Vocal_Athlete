# REPERTOIRE-APPLICATION-SPEC — v15 곡 적용 훈련

> 작곡·편곡·노래 제작 기능이 아니다. Universal Vocal Core에서 익힌 기술을 훈련용 프레이즈에서 유지하고 전이하는 보컬 트레이닝 단계다.

## 1. v9 구조: 6개의 12일 phrase project

v8의 `18일 Global → 18일 Local → 18일 Recall → 18일 Transfer` 구조를 폐기한다. 한 프레이즈의 전체 맥락으로 돌아오기까지 너무 오래 걸리기 때문이다.

v9에서는 각 프로젝트가 12일 안에 다음 루프를 완결한다.

```text
Global baseline
→ Text/rhythm map
→ One-note speech-to-song
→ Hum/vowel/lyric transfer
→ Breath map
→ Project-specific skill
→ Difficult-section loop
→ Guide comparison
→ Backing entry
→ Integrated variation
→ Best take
→ Delayed retrieval/transfer
```

| Project | slots | 주 난이도 | 대표 전이 |
|---|---:|---|---|
| 1 | 1–12 | 2마디, 단순 pulse·음절 | 한국어 음절 |
| 2 | 13–24 | 2–4마디, 작은 contour | TONE-06 모음 색채 전이 |
| 3 | 25–36 | 4마디, 자음 timing | 새 시작음 |
| 4 | 37–48 | 4마디, tone/phrase arc | TONE-07 bright/warm A/B |
| 5 | 49–60 | 4–8마디, subdivision·key fit | TONE-11 마이크 조건·tempo/key |
| 6 | 61–72 | 8마디 이하, 복합 통합 | TONE-12 clean/warm/speech-like A/B/C와 독립 best take |

## 2. 프로젝트 시작과 종료

### Day 1 — `RA-09 Global Phrase Baseline`

- 전체 2–8마디를 먼저 듣는다.
- primary goal 하나만 정한다.
- 중간에 끊지 않는 낮은 부하 take를 한 번 남긴다.
- 교정은 take가 끝난 뒤 시작한다.

### Day 12 — `RA-10 Delayed Retrieval & Project Review`

- 가이드 없이 전체 phrase를 한 번 수행한다.
- 프로젝트 첫 take와 비교한다.
- key, tempo, lyric, tone 중 한 조건만 바꾼다.
- best take와 다음 cue 하나를 저장한다.

각 프로젝트의 시작/종료 take는 시험 점수가 아니라 학습 증거다.

## 3. 한 레슨의 방법론

1. 가능하면 첫 시도를 먼저 한다.
2. pitch, rhythm, breath, diction, tone 중 primary criterion 하나만 선택한다.
3. 어려운 1–2마디를 낮은 난이도로 분해한다.
4. 안전 문제가 없으면 짧은 시도 2–3회 후 묶음 피드백을 준다.
5. 레슨 마지막에는 전체 phrase로 돌아간다.
6. 사용자 자기판단 뒤 앱 nudge를 공개한다.

## 4. Guide fade

```text
guide vocal
→ guide melody
→ backing + entry cue
→ backing only
→ delayed no-guide take
```

가이드는 사용자가 오류를 스스로 발견할 수 있을 때 줄인다. 날짜만으로 강제 제거하지 않는다.

## 5. 난이도 축

- range와 duration-weighted tessitura
- melodic interval·방향 전환
- pulse·쉼표·pickup·subdivision
- phrase length·breath point
- vowel/consonant load
- accompaniment support
- register crossing
- guide dependence
- primary/secondary criterion 수

한 프레이즈에는 primary skill 1개, secondary skill 최대 1개를 지정한다.


## 6. v15 음색 전이 규칙

곡 적용 훈련에서 음색은 노래의 정답이나 미적 점수가 아니라 **같은 프레이즈에서 선택한 특성을 재현하는 과제**다.

- Project 2: 모음 하나를 바꿔 tone 차이를 듣는다.
- Project 4: 같은 프레이즈를 bright/warm으로 각 1회 녹음한다.
- Project 5: 동일 프레이즈에서 마이크 거리·clipping/noise 조건을 확인한다.
- Project 6: clean/warm/speech-like를 각 1회만 녹음하고 편안함·전달력을 기준으로 Best를 고른다.
- take 간에는 pitch, volume, vowel, tempo 중 한 변수만 바꾼다.
- 사용자가 선택한 tag는 `내 음색 팔레트`에 누적되지만 스타일 적합성이나 성대 상태로 판정하지 않는다.

## 7. 자동 피드백 경계

허용:

- 입력 신뢰도, clipping/noise
- relative pitch와 큰 contour 이탈
- 국소 early/late, tempo drift
- A/B 재생, tone/comfort self-tag

금지:

- 단일 노래 실력 총점
- 음색 미학의 정답 판정
- 성대 상태·발성 원인의 자동 진단
- 원곡자 유사도와 원키 강제

## 8. 졸업 산출물

- 여섯 프로젝트의 baseline/review pair
- guide 없는 take 최소 1개
- key 또는 tempo의 near-transfer take 최소 1개
- tone 또는 diction A/B 최소 1쌍
- 동일 프레이즈의 clean/warm/speech-like A/B/C 중 편안한 Best take 1개
- 사용자 self-review: 유지할 점 1개, 다음 cue 1개

정확한 합격 점수는 검증 전 제품 가설로 두며, daily unlock을 막지 않는다.

## 9. 안전

- 어려운 loop와 take 수는 카드 cap을 따른다.
- 쉰 느낌에는 no-voice 분석·가사 rhythm·breath map으로 전환한다.
- full take를 반복해 성공을 강요하지 않는다.
- 원곡 key, belt, run, 장르 고강도 기술은 Advanced Lab gate 전에는 요구하지 않는다.
