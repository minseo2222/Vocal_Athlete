# Advanced R&B / Soul Lab — v9

> 40-slot 반복형 장르 프로젝트. 가요 카드 재조합이 아니라 `RB-01~06` 전용 저위험 카드로 groove, melisma, tone color, ad-lib을 훈련한다.

## 1. 학습 목표

- 정박과 가벼운 layback의 구분
- clean/warm/slightly-airy tone의 짧은 조절
- 매우 느린 3음 melisma와 모음 연속성
- 가사·groove·pitch를 동시에 잃지 않는 phrase
- 제한된 contour 안의 ad-lib 선택
- 녹음 A/B와 편안함 기반 best take 선택

## 2. 전용 카드

| ID | 내용 | 안전 경계 |
|---|---|---|
| RB-01 | Groove Skeleton | tap→speech→one-note, 낮은 부하 |
| RB-02 | On-Beat / Layback Contrast | 반주를 잃으면 정박 복귀 |
| RB-03 | Slow Three-Note Melisma | 최대 4회, 속도 경쟁 없음 |
| RB-04 | Vowel Continuity in Run | 매우 느린 tempo, 최대 3회 |
| RB-05 | Controlled Tone-Color Contrast | airy는 짧게, 피로 시 clean만 |
| RB-06 | Ad-Lib Contour & Review | 마지막 2음 등 제한된 변형 |

## 3. 40-slot cycle

| Phase | slots | 주 내용 | 산출물 |
|---|---:|---|---|
| 1. Groove/Tone Baseline | 1–10 | groove skeleton, placement, tone palette | baseline phrase |
| 2. Slow Agility | 11–20 | 3음 melisma, vowel continuity, slow loop | slow agility set |
| 3. Phrase Integration | 21–30 | placement, ad-lib contour, mic take | 2–4마디 phrase |
| 4. Review/Recovery | 31–40 | restrained ad-lib, best take, delayed review | portfolio candidate |

## 4. 방법론

- 속도는 마지막 변형이며 통과 기준이 아니다.
- pitch, vowel, rhythm, ease 중 한 번에 하나를 우선한다.
- on-beat 성공 뒤에만 layback을 비교한다.
- ad-lib은 무작위 과시가 아니라 제한된 contour 선택이다.
- 고속 run, 장시간 breathy tone, rasp/growl/scream은 기본 Lab에서 제외한다.

## 5. 피드백

허용: pitch trajectory, onset/offset timing, tempo drift, tone/comfort tag, A/B. 금지: Soul 점수, 특정 가수 유사도, run 속도 랭킹.

## 6. 출시 조건

장르 전문가 검수, 실제 groove/backing 자산, take cap, 다음날 피로 확인, 사용자 파일럿을 완료하기 전 기본 미출시다.
