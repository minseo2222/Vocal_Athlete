# 초급 공통 커리큘럼 (0–6개월)

**대상**: 클래식·뮤지컬·CCM 모든 트랙 입문자 (만 18세 이상 성인 + 자기 보고 변성기 종료)
**18+ 정책**: 성대 성숙 (변성기 종료) + 자가주도 책임 능력 + 의학적 의뢰 자기 판단을 전제로 함. 청소년·미성년 변성기 학습자에는 별도 모듈이 필요 (part 16 §"잔존 갭" S 등급 + part HP §8 변성기 카드 참조). Cooksey stage V는 15–17세 종료 가능하나 *18세 + 자가 보고* 복합 조건으로 운영.
**운영 트랙 (3종)**:
- **자가주도 트랙** (기본) — 본 앱 단독 사용. 앱 AI는 *추정치(estimate)·자가 모니터링 보조 신호*만 제공 (*임상 평정자 ❌*). 도구·평가 모두 자가 수행. 학습자 다수 가정.
- **강사 동반자 트랙** (선택) — 본 앱 + 보컬 강사 협진. 강사는 *교육적 청감 코멘트·발성 습관 피드백·과제 수행 확인*만 제공 (*임상 평정 ❌*). CAPE-V/GRBAS 등 임상 도구는 강사 사용 불가. *유료 교습·강사 매칭·실시간 레슨·오프라인 수업·정기 교습료 운영*은 본 페다고지 문서 범위 외 — 학원법·교습소·개인과외교습 신고·교습비·환불·전자상거래 표시는 `app/01-B` 법무 운영 별도 처리.
- **SLP/의료기관 동반자 트랙** (선택) — 본 앱 + SLP·이비인후과 협진. *임상 음성 평정 = SLP/의료기관만*. CAPE-V/GRBAS 사용 가능. 진단 보유자·고위험·고급 학습자 권장. 운영은 `app/01-B` §평가 워크플로 참조.
**기간**: **24개 core session. 권장 달력 기간 20–32주.** 주 2회 진행은 가능하나 *12주 졸업 보장은 하지 않음*. 2회차는 *복습·녹음·SOVT·자가청취 위주*로 제한 (고부하 새 기술 ❌). 페이즈 전환은 주차가 아니라 **체크포인트 통과 + 다음날 피로 없음**으로 결정. 운동학습·청각-운동 매핑·점막 회복은 *시간 의존적*이며 빈도 ↑로 단축 ❌.
**핵심**: *몸 → 호흡 → 효율적 발성 → 자기 청취*. 스타일·고음·벨트는 다루지 않음.

## 1. 학습 목표 (졸업 시 8가지)

이 6개월이 끝나면 학습자는 다음을 *할 수 있다*:

1. **자기 컨디션을 5분 안에 점검·기록한다** (P8-01 컨디션 게이트)
2. **빨대·립트릴 등 SOVT 4종을 *혼자* 안전하게 워밍업으로 사용한다**
3. **자기 발성이 *과기식·균형·과압착* 중 어디인지 청지각으로 식별한다** — *입학 시 베이스라인 대비 향상* (절대 정확도 ❌, 상대 향상 ✓). 김형미 2025 성대접지 3분류 [CITE: KOR_KIM2025]
4. **자기 표준 샘플을 녹음하고 전후 A/B 비교한다** — *non-judgmental observation*으로 ([CITE: GREEN_GALLWEY1986])
5. **의학적 의뢰 또는 응급 평가가 필요한 적색 신호 12개를 이해하고, 하나라도 해당하면 발성 훈련을 즉시 중단한다** — 응급(A)/신속 ENT(B)/두경부 방사선·암(C) 3분기 (§3 참조)
6. **운동 학습 3단계(Fitts & Posner) 모델로 *학습 진도 일반*을 설명한다** — 자가 위치 분류는 *학습자 옵션* (졸업 의무 ❌). 모델 자체의 *언어 설명*만 졸업 기준 [CITE: FITTS_POSNER1967]
7. **Self-imitation drill (§5.6) + 시각 피드백 피치 매칭 (§5.7)을 자기-주도로 사용 가능하다** [CITE: PFORDRESHER2014SWY] [CITE: BERGLIN2022FB]
8. **7-Step Centering (§6.6)을 5–10초 단축판으로 적용곡 작업 *전* 실시 가능하다** [CITE: GREENE2002]

이 8개가 졸업 기준이다. 음역 확장·고음·스타일은 *목표 아님*.

§24 24주차 체크포인트는 §1 학습 목표 8개와 *1:1 일치* (검증 도구는 §7 평가 + §24 부록 참조).

## 3. 매 레슨 표준 시작 — 컨디션 게이트 (5분, 항상)

전 페이즈 공통. 첫 주에 가르치고 *모든 레슨 시작 시* 재실행.

### 절차
1. **컨디션 1–10 척도** 기록 (오늘 목 상태 주관 점수)
2. **적색 신호 12개 자가체크** — *3분기로 분리* (AAO-HNSF dysphonia guideline 4주 상한 [CITE: AAODHF2018] + NIDCD 3주 상한 [CITE: NIDCD_HOARSENESS] + Part 8 P8-12. 본 앱은 2주 상한으로 *더 보수적*).

**A. 즉시 응급 평가 (119 또는 응급실)**:
   1. 호흡곤란·흡기 천명(stridor)
   2. 객혈 또는 반복되는 혈흔 가래
   3. 급성 신경학적 증상 (말 어눌함·편측 약화·새로 생긴 심한 떨림)
   4. 삼킴곤란이 *호흡곤란·침 흘림·탈수와 동반*되는 경우

**B. 신속 이비인후과/후두 평가 (며칠~2주 내)**:
   5. 쉰 목소리·음성 변화 *2주 이상 지속* (NIDCD 3주·AAO-HNSF 4주보다 본 앱이 보수적)
   6. 발성·말하기·삼킬 때 통증 *또는* 호흡곤란 없는 새로 생기거나 지속되는 삼킴곤란
   7. 갑작스러운 음성 상실 며칠 이상 지속
   8. 목에 *만져지는 덩어리*
   9. 최근 삽관·두경부/흉부 수술·목 외상 + 음성 이상
   10. 흡연력 또는 직업적 음성 사용자에서 *지속되는 애성*
   11. 설명되지 않는 *체중 감소 + 음성 변화* 또는 목 증상

**C. 두경부 방사선·암 병력**:
   12. 두경부암·후두암 병력 또는 목 방사선 치료력 + 새 음성 변화 (AAO-HNSF guideline modifier [CITE: AAODHF2018])

3. **분기에 따라 안내**:
   - **A 양성** → 본 앱 사용 즉시 중단 + 119/응급실 안내
   - **B 양성** → 본 앱 발성 모듈 잠금 + 이비인후과 예약 안내
   - **C 양성** → 자가주도 발성 모듈 잠금 + 후두 평가 후 재입학 (동반자 트랙만 허용)
4. 모두 통과 → 본 레슨 시작
5. (격주) EASE 22문항 자기보고 추가

**중요 — 본 앱 정체성**: 본 앱은 *교육·훈련·웰니스 도구*이며, *진단·치료 도구가 아님* (`app/01-B §3` 의료 동의서). 위 적색 신호 양성자에게 본 앱이 *음성치료처럼 보이는 모듈*을 계속 제공하면 위험 — 자동으로 의학 평가 플로우 분기 (`app/01-B §6`).

## 4. Phase A — 몸·인지 (1–8주)

이 시기의 *목표*는 소리가 아니라 **자기 몸을 관찰하는 능력**. *노래·고음·긴 글라이드·큰 소리 ❌*. 단, **"소리 없음" ❌, "노래 없음" ✓** — 1주차부터 *저부하 발성 30–90초*를 매 레슨에 포함 (운동학습은 *시작 시점*이 중요, body mapping과 phonation 연결을 끊지 않기 위함). **Body Mapping 6 Places of Balance**(Malde 외 [CITE: MALDE2017])가 자세 모듈의 1차 토대.

**Phase A 저부하 발성 (1주차+)** — §4.5와 별도, 매 레슨 30–90초:
- 편한 /m/ 3회 (각 2–3초)
- /v/ 또는 /z/ 3회 (유성 마찰음 SOVT)
- 빨대 *무음 호기* 후 아주 가벼운 *유성 빨대* 3회
- *Speech-tone sigh* 3회 (한숨 같이, 음정 안 정함)
- *노래·고음·긴 글라이드·큰 소리 모두 ❌*

→ Phase A는 *노래는 없으나 가벼운 소리는 있음*. §4.5 가벼운 첫 소리(5–8주 후반 10분)와는 별도의 *최소 발성 connection*.

**황색 신호 정책** (NIDCD voice care 권고 [CITE: NIDCD_HOARSENESS]) — 다음 중 하나 시 *그날 voiced portion 생략*하고 무성 호기·constructive rest·자가 관찰만 수행:
- 감기·상기도 감염·발열·급성 알레르기 악화
- 전날 *과도한 음성 사용 후 피로*
- 오늘 *목쉼·따가움·말하기 effort 증가*
- 수면 부족 + EASE/VAS 악화

**황색 신호 계층** (3단계):
- *48–72시간 이상 지속/악화* → voiced portion *계속 생략* + 휴식·수분·비발성 관찰 위주, 필요 시 *의료 상담 권고*
- *2주 이상 음성 변화 지속* → 발성 모듈 잠금 + §3 B 분기 의학 평가
- *§3 A·C 적색 신호* 등장 → 즉시 중단 + 응급/신속 ENT 분기

### 4.1. 훈련 — 자세 정렬 + Body Mapping (Constructive Rest + 6 Places of Balance)

**무엇**: 누운 자세에서 척추·머리·어깨 정렬을 회복하고 호흡 공간을 확보. *6 Places of Balance* — A-O joint(목 위), 어깨, 요추, 고관절, 무릎, 발목 — 동적 균형 인지.
**근거**: Alexander Technique 가창자 RCT [CITE: DAVIES2020] — *단일 브랜드 방법론 중 가창자 대상 RCT 보유의 희귀 사례* (CVT·Estill·SLS·LMRVT 등은 *브랜드 단위 Phase III RCT 부재* [CITE: BARTLETT2020]; part 12 §방법론별 Evidence Status 참조). Body Mapping 가창자 표준 [CITE: MALDE2017] + Dimon Alexander×해부 [CITE: DIMON2018]. part HP §1 호흡 시스템 해부.

**절차**:
1. 매트·바닥에 등 대고 눕는다
2. 무릎 세움(발바닥 바닥), 두 발 사이 골반 너비
3. 머리 밑에 책 1–2권 (목 아치 채움 — 두께는 개인차)
4. 팔은 옆 또는 갈비뼈 위
5. **5분간 호흡만 관찰** — 인위적으로 깊게 ❌, 자연스러운 흐름 그대로
6. *Inclusive Awareness* — kinesthetic + auditory + visual 동시 유지 (Malde Ch. 1)

**확인** (Body Mapping 자가 관찰):
- A-O joint(귀 바로 앞 위)에서 머리가 *가볍게 매달려* 있는가
- 양 어깨 수평·이완
- 요추·골반·고관절 정렬
- 무릎·발목 *부드러운* 정렬

**시간**: 매 레슨 5분, 집에서 매일 5–10분
**언제 중단**: 어지럼·저림 → 즉시 일어남

### 4.2. 훈련 — 흉곽-복부 결합 호흡 + Breath Mapping

**무엇**: 들숨에 흉곽과 복부가 *둘 다* 늘어나는 것을 인지. 흔한 *오인식(mismapping)* 5가지 교정.
**근거**: Hixon speech breathing 모델 [CITE: HIXON2008] (part HP §1) + Body Mapping Ch. 3 [CITE: MALDE2017]. Part 14 *복식호흡* 카드.

**Body Mapping 핵심 원칙** (절대화 ❌, 관찰 중심): *어깨를 들어 고정하는 고흉식·배만 미는 복식 단독·최대 들숨 강요*는 회피. 실제 호흡은 늑골과 흉곽이 *여러 방향*으로 움직이며, 핵심은 *하부 늑골의 측면·후방 확장 + 복부의 부드러운 반응*. 들숨은 *"최대"가 아니라 "빠르고 조용하고 충분한"*.

흔한 오인식 (Body Mapping 교정 대상):
- "diaphragm is in the abdomen" ❌
- "어깨를 들어올려 호흡" ❌
- "최대한 들이마셔야 한다" ❌

**절차**:
1. 똑바로 앉거나 서기
2. 한 손은 옆 갈비뼈(옆구리), 한 손은 배꼽 위
3. 들숨 — *두 손 모두* 자연스럽게 늘어남 (시간은 자기 호흡에 맞춤)
4. 날숨 — 천천히 모음 길게 내쉬기 (*4초/6초/8초는 *옵션*이지 의무가 아님*)
5. 점진적 확장은 *어지럼 없음 + 목 조임 없음 + 어깨 고정 없음 + 다음 소리가 편함*을 만족하는 한에서

**핵심 지표** (시간 카운트보다 우선):
- 어지럼 없음
- 목 조임 없음
- 어깨 고정 없음
- 다음 소리가 편한가

**금기**:
- 어깨 들리는 *고흉식* ❌
- 가슴 안 움직이는 *복식 단독* ❌
- *최대 들숨 강요* ❌ — 4초/6초/8초 카운트는 *옵션·자가 가이드*, 의무 아님
- 양쪽 자연스럽게 ✓

**시간**: 매 레슨 10분
**언제 중단**: 과호흡·어지럼 → *즉시 일반 호흡으로 복귀*

### 4.3. 훈련 — 흡기 자세 유지 (Appoggio 입문)

**무엇**: 들숨 끝에서 *벌어진 갈비뼈 자세*를 날숨 동안에도 일정 시간 유지. (Part 14 *Appoggio* 용어 카드 — *appoggiare* = "기대다", "앉다" ❌)
**근거**: Miller 1986/1996 정전, 음성과학 정의 [CITE: MILLER1996] + part HP §1.3.

**절차**:
1. 흉곽-복부 결합 호흡으로 4초 들숨
2. 들숨 끝에서 갈비뼈 *벌어진 상태*를 의식
3. 입을 살짝 벌리고 /sss/ 또는 /fff/ 무성음으로 *천천히* 날숨
4. **갈비뼈가 즉시 좁혀지지 않게** 3–5초 유지 시도
5. 끝까지 가지 말고 70%에서 다음 들숨

**감각 언어**: "들숨 자세를 날숨 동안에도 잡고 있다" / "기댄다" (눌러 앉지 않음)

**진도**:
- 1–2주차: 3초 유지 시도
- 5–6주차: 5초 유지
- 7–8주차: 8초 유지 (가능 시)

**금기**: 가슴·갈비뼈를 *밀어 넓히는* 인위적 압박 ❌

### 4.4. 훈련 — 턱·혀·목 긴장 해소 + Silent / Voiceless Ah Awareness

**무엇**: 발성 전 외재후두근·턱·혀의 과긴장 풀기. **Silent / Voiceless Ah Awareness** — Alexander Technique 라인 *whispered "ah"*의 안전 변형판. *속삭이는 목소리로 연습* ❌, *무성 자세·흐름 관찰* 만 의도.
**근거**: Dimon 2018 *Anatomy of the Voice* Ch. 5 [CITE: DIMON2018] + part HP §2 외재후두근.

**절차**:
1. **턱 마사지**: 양 검지로 깨물근(masseter, 광대 아래) 천천히 원형 마사지 30초
2. **혀 풀기**: 혀를 입 밖으로 길게 → 안으로 → 좌우 양 끝 → 5회 반복
3. **목 회전**: 천천히 좌→앞→우→앞 (뒤로 절대 ❌, 척추 보호) 좌우 3회씩
4. **어깨 떨구기**: 어깨 으쓱 들고 3초 → 갑자기 떨구기, 5회
5. **Silent / Voiceless Ah Awareness** (Alexander 라인 *whispered "ah"*의 안전 변형판) — 성대를 *긁는 속삭임 말하기 ❌*. 턱·혀·연구개·호흡 흐름을 확인하는 *무성 동작*. 4단계 분해 시각화:
   - 턱 이완 (TMJ)
   - 후두 안정 (suspensory muscles 균형)
   - 연구개 거상
   - 호흡 흐름 (가슴·복부 결합)

**시간**: 매 레슨 시작 5분 *통합* (턱·혀·목 풀기 4분 + Silent Ah 1분). 단독 심화는 집 연습 추가 권장.
**금기**:
- 통증 시 즉시 중단, TMJ 진단자는 턱 마사지 ❌
- *목이 쉬었거나 피곤하거나 통증 시 생략* — NIDCD voice care 가이드 (whispering 같은 음역·강도 극단 회피) [CITE: NIDCD_HOARSENESS]
- *숨을 세게 밀지 않음* — 강한 속삭임은 성대 자극 가능
- "속삭이는 목소리로 연습"은 ❌ — *무성(voiceless) 자세·흐름 관찰* 만 의도

### 4.5. 훈련 — 가벼운 첫 소리 (Primal Sound 도입)

8주차에 가까워지면서 도입. **Primal Sound** — 가창의 출발점은 *원초적 발성 반사*(울음·웃음·신음).
**근거**: Chapman 2017 *Singing and Teaching Singing* Ch. 2 [CITE: CHAPMAN2017].

**절차**:
1. **/h/ 한숨** — 음정 안 정함, 강도 약함, 한숨 같이 길게 5초 (*sigh* — 한숨이 가창의 전조)
2. **/m/ 짧은 허밍** — 입 다물고 코끝 진동 확인
3. **/n/ 허밍** — 혀끝이 잇몸에 살짝
4. *원초음 inspiring* — 부드러운 웃음 흉내 ("후후"), 가벼운 신음 (가창 모방 ❌, 반사적 ✓)
5. 음역 좁게: 편한 중음 한 음만, 글라이드 ❌

**시간**: Phase A 후반 (5–8주) 매 레슨 끝 10분
**확인**: 코끝·입술·얼굴 주변에 *주관적 진동감이 살짝* 느껴질 수 있음. *앞이마 감각은 일부 학습자에게만 나타나며 필수 기준이 아님*. 감각을 만들려고 *힘주지 않음*.

### 4.6. 훈련 — 골 전도 vs 공기 전도 자기 청취 인지 (NEW — 첫 주 필수)

**무엇**: 학습자가 *처음 자기 녹음을 들었을 때 충격*받는 이유의 해부학적 정당화 + 인식 전환.
**근거**: part HP §6 청각 시스템 + Sundberg 1987 [CITE: SUNDBERG1987]. *왜 내 녹음이 다르게 들리나*에 대한 1주차 필수 교육.

**절차** (1주차 한 번 + 매 녹음 시 짧게 환기):
1. *내가 듣는 내 목소리*: 골 전도 + 공기 전도 결합. 저주파 ↑ (두개골 직접 진동)
2. *다른 사람이 듣는 내 목소리*: 공기 전도 단독.
3. **녹음**은 골 전도가 빠진 *외부 청취에 더 가까운 표본* — 단, 마이크·방·거리·재생기 영향을 받으므로 *한 번의 녹음이 절대적 진실은 아님*. 같은 조건의 반복 녹음으로 외부 청취 표본에 익숙해진다.
4. 학습자 첫 표준 샘플 녹음 → 들어보고 *충격 정상화*
5. *non-judgmental observation*: "어디가 어떻게 들렸는가" (✓) vs "좋다/나쁘다" (❌) — Inner Game [CITE: GREEN_GALLWEY1986]

**시간**: 1주차 15분 + 매 녹음 후 1분 환기
**메시지**: "녹음이 낯선 것은 정상. 같은 조건의 반복 녹음으로 *외부 청취 표본*에 익숙해진다."

## 5. Phase B — 효율 발성 (9–16주)

이 시기의 메인 도구는 **SOVT 4종 + 청각-운동 통합 훈련**.

**근거 등급 — 정확한 표기** (GPT Pro 검토 반영):
- SOVT는 음성치료·발성훈련에서 *널리 사용*되며 *일부 프로토콜*은 RCT/체계적 고찰 근거 보유. 단, **도구별·대상별 근거 강도는 다르며**, "초급 건강 보컬 앱 전이"는 *임상 RCT의 직접 근거 영역과 다름*.
- *Kapsner-Smith et al. 2015 RCT* [CITE: TITZE2006SOVT 라인]은 *dysphonia·vocal fatigue 환자 n=20*에서 FRT vs VFE 비열등 보고 — **건강 성인 자가주도 앱으로 일반화는 *중간 근거***.
- SOVTE 체계적 고찰은 SOVT가 *다른 치료보다 우월하다고 단정하기 어렵지만 유리한 경향* 정리.
- **Pfordresher 라인 4편**은 *피치 모방·자기청취·시각 피드백 모듈*의 핵심 근거 (L2–L3) — *전체 24주 커리큘럼 토대가 아님*.

**도구별 근거 등급 표** (정확한 차등):

| 도구 | 등급 | 비고 |
|---|---|---|
| 빨대/FRT (§5.1) | **임상 RCT 근거 있음 (Kapsner-Smith 2015)·건강 보컬 전이는 중간 근거** | 음성치료 적응증 ≠ 자가주도 앱 |
| 립트릴 (§5.2) | **중간 근거 (1b~2b)** | 현장 채택도 높으나 프로토콜별 근거 차이 큼 |
| /m·n·ŋ/ 허밍 (§5.3) | **기전·임상 관행 근거 (2b~5)** | 직접 RCT 근거 제한적 |
| 물저항 빨대 (§5.4) | **중간 근거 (1b+5)** | 깊이·시간·대상자별 안전 프로토콜 중요 |
| VFE (§5.8) | **임상 기원, 중등도~강한 근거. 초급 자가주도 앱은 *선택·잠금 모듈*** | "최대" 표현 회피 |

### 5.1. 훈련 — 빨대 발성 (9–10주 도입, Part 3 P3-13)

**무엇**: 입술에 빨대/튜브를 물고 코로 새지 않게 공기 흐름을 빨대에 통과시키며 유성 발성. SOVT(상수형) 대표 도구. 적은 노력으로 안정적 진동 조건 학습.

**근거**: Titze 2006 SOVT 합리화 [CITE: TITZE2006SOVT] + 임상 RCT (FRT vs VFE 등) + Andrade 2024 SOVT 프로토콜 비교 [CITE: ANDRADE2024]. OCEBM 1b. part HP §1 호흡·§2 후두.

**준비물**: 일반 음료 빨대 (직경 5–6mm, 너무 좁은 것 ❌)

**절차**:
1. 빨대 한 쪽 끝을 입술 안에 *부드럽게* 물고 봉인 (이로 물기 ❌, 옆으로 새기 ❌, 코로 새기 ❌)
2. 자연스러운 호흡 한 번
3. **편안한 음높이**에서 빨대 통해 부드러운 sustain — 10–20초 (또는 한 호흡 끝까지, 무리 ❌)
4. 짧은 글라이드 (위 2도 → 본음 → 아래 2도) 5회
5. 익숙해지면 모음 형태를 혀로 변화 (가능 범위 내)
6. 빨대 빼고 같은 음으로 /u/ 모음 — 빨대 때 *느낌 그대로* (*carryover*)

**Self-imitation 변형** (11주 이후): 빨대 sustain 후 *바로 자기 녹음* → 5초 후 *재모방* (§5.6 연결)

**시간**: 워밍업 2–5분, 세션 중간 리셋 30–60초. 한 번에 5분 이내.

**금기·언제 중단**:
- 너무 좁은 빨대 또는 과도한 밀기 (폐압 과다) ❌
- 어지럼·과호흡 → 즉시 중단
- 천식·호흡기 질환자는 강도·시간 보수
- 빨대 발성 직후 통증·쉰목소리 악화 → 의학 의뢰

**자가 관찰 체크리스트** (매 세트 후):
- [ ] 어지럽지 않았다
- [ ] 입술이 빨대를 부드럽게 봉인했다 (이로 물지 않음)
- [ ] 10–20초 sustain 가능했다
- [ ] 음정이 안정적이었다 (큰 변동 없음)
- [ ] 강도가 편안했다 (짜내는 느낌 없음)

**[근거 — 임상 RCT 보유, 자가주도 앱 전이는 중간]** Kapsner-Smith 2015 RCT (FRT vs VFE, *dysphonia·vocal fatigue n=20* — 건강 성인 자가주도 직접 근거 ❌) + 2b(프로그램 연구) + 5(SOVT 기전) [CITE: TITZE2006SOVT] [CITE: ANDRADE2024]. 단, *모두 RCT 검증* 표현은 과장이며 *도구별·대상별 차등* 필요.

**변이 옵션** (§13 훈련 변이 정책): 음역(중음→약간 낮은/높은 음) → 모음(/u/→/a/→/i/) → 글라이드 패턴(sustain→사이렌→옥타브) → 멜로디 응용(11주차+, §5.9). *한 세션 1–2축*만 변이.

### 5.2. 훈련 — 립 트릴 (11–12주, Part 3 P3-17)

**무엇**: 입술을 느슨하게 닫고 호기를 보내 *입술이 진동*하며 소리 나도록 하는 SOVT (oscillatory). 가장 흔한 평생 워밍업 도구. EGG 연구는 일부 oscillatory SOVT가 *이중 진동원 (성대 + 입술)*을 가짐을 보고.

**근거**: Andrade 2014 EGG 측정 + 임상 샴대조 3주 프로그램 [CITE: TITZE2006SOVT] [CITE: ANDRADE2024]. OCEBM 2b~1b. part HP §2.

**절차**:
1. 입술을 가볍게 닫고 *진동* — "brrrrr" 소리 (오토바이·전화벨 흉내)
2. 안 되는 사람: 양 검지로 입꼬리 옆 살짝 받쳐 입술 모양 잡기
3. 편안한 피치에서 5–10초 sustain
4. 짧은 글라이드 (저→고→저, 5도 범위) 3–5회
5. 익숙해지면 한 옥타브 글라이드 또는 멜로디 패턴 (가사 없이)
6. 입술 떼고 같은 모음으로 transfer (*carryover*)

**시간**: 누적 2–3분 (초급), 총 3–5분 이내 (중급). 매 레슨 10분, 집에서 매일 5분.

**금기·언제 중단**:
- 턱 고정·입술 압착 → 강도↓·속도↓
- 공기 과다로 어지럼 → 즉시 중단
- 소리 안 나서 *힘으로 밀기* ❌ — straw(상수형 P3-13)로 대체 후 재시도
- 트릴 후 쉰목소리 지속 악화 → 의학 의뢰

**자가 관찰 체크리스트**:
- [ ] 입술 진동이 *입술에서만* 일어났다 (혀·턱 동원 없음)
- [ ] 글라이드 시 음정이 끊기지 않았다

**[근거 중간]** OCEBM 2b~1b. 건강 성인 대상 결과는 혼합 — *프로토콜 설계*(총 트릴 시간 제한)가 효과 좌우.

**변이 옵션** (§13): 음역 → 글라이드 패턴 → 멜로디 응용 (11주차+, §5.9 — 입술 진동이 자연스러운 시점부터).

### 5.3. 훈련 — 허밍 /m/, NG-hum /ŋ/ (13–14주, Part 3 P3-19·P3-20)

**무엇**: /m/ 또는 /n/, /ŋ/을 지속 발성하는 상수형 SOVT (VP 개방, nasal continuant). 가장 자연스러운 *말 → 노래* 전이 가교. /ŋ/은 혀 위치가 후방이라 *모음 전이 브릿지* 역할.

**근거**: SOVT 분류 정전 + intraoral pressure 측정 [CITE: TITZE2006SOVT]. /m n/은 상대적으로 *낮은 압력*을 만들며 다른 고압 SOVT와 *분리* 사용 권고 (Part 3 P3-19 주석). part HP §1·§2.

**절차 — M-hum**:
1. 입을 다물고 /m/ 부드럽게 5–10초 sustain — 코끝 손가락으로 진동 확인
2. 편한 중음에서 글라이드 (작게, 5도 이내)
3. /m/ → /a/ 전환: /mmm-aaa/ — 입을 자연스럽게 열어 모음으로 (*carryover*)

**절차 — NG-hum (/ŋ/)**:
1. "응~" 끝 발음 — 혀 뒷부분이 입천장에 닫힘
2. /ŋ/ sustain 5초 — 혀 뒤·연구개 정렬 + 후두 자유도 확보
3. /ŋ/ → /i/ 전환: /ŋŋŋ-iii/ (모음·포먼트 전이 브릿지)
4. 작은 사이렌 (저→고→저)

**시간**: 1–3분 리셋, 매 레슨 10분.

**금기·언제 중단**:
- 비강 *과장* (모음 전이 후 /a/ 구간에서 *코를 막아 음질이 크게 변하면* 과도한 비강 공명 가능성·nasal 고착) → 모음 전이로 중립화. *허밍 자체*에서 코 막기 변화는 정상 (자가 관찰 체크리스트 §5.3 참조).
- 혀뿌리 과긴장 → Part 1·2 턱·혀 이완 선행

**자가 관찰 체크리스트**:
- [ ] 코끝·입술·얼굴 주변 *주관적 진동감 살짝* (앞이마 감각은 선택, 필수 ❌, 강요 ❌)
- [ ] /m/ → /a/ 전환 시 음질 큰 변화 없이 *카리오버* 유지
- [ ] **모음 전이 후** /a/ sustain 중 *코를 막아도 음질이 크게 변하지 않음* (모음 구간만 적용)

**중요 — 코 막기 테스트의 정확한 적용**:
- /m/, /n/, /ŋ/ **허밍 자체** 중 코를 막으면 *음질 변하거나 진동 줄어드는 것이 정상* — velopharyngeal port가 열려 비강 통로로 소리·공기가 흐름 (Children's Hospital of Philadelphia resonance disorders 정의)
- 코 막기 테스트는 **/m/ → /a/, /ŋ/ → /i/ 모음 전이 후 *모음 구간*에서만** 적용
- 모음 구간에서 코 막기에 따라 음질이 *크게 변하면* → *과도한 비강 공명 가능성* 또는 모음 전이 미흡 → 강도 ↓·SOVT 복귀·모음 전이 재학습. *반복되거나 말소리에서도 비강 공명이 두드러지면 SLP/ENT 상담 권장* (자가주도 앱은 resonance disorder 진단 도구 ❌)

**[근거 중간]** OCEBM 2b~5 (분류·측정). RCT 직접 증거 부족하나 현장 채택도 매우 높음.

**변이 옵션** (§13): 모음 전이(M-hum → /a/, NG-hum → /i/) → 멜로디 응용(13주차+, §5.9 — *말→노래 가교* 직접 활용).

### 5.4. 훈련 — 물저항 빨대 (15–16주, 선택, Part 3 P3-15 / Lax Vox·WRT)

**무엇**: 튜브 말단을 물에 담가 침수 깊이에 따라 정압 저항을 추가한 진동형 SOVT. 버블로 인한 압력 변동이 *추가* 자극. 임상 RCT에서 PTP 감소 등 공기역학 지표 개선 보고.

**근거**: WRT/Lax Vox 임상 RCT [CITE: TITZE2006SOVT] + 모델·생리 연구. OCEBM 1b + 5. part HP §2.

**준비물**: 빨대 (직경 8mm 권장 — 일반 음료 빨대보다 약간 굵음), 투명 컵, 물.

**절차**:
1. 컵에 물 절반 채움
2. 빨대 끝을 물에 **2–3cm만** 담금 (첫 도입 깊이, 깊은 침수 ❌)
3. 빨대 입에 물고 부드러운 sustain — 물에 *작은 거품 연속* 보이면 OK
4. 편한 음 sustain → 짧은 글라이드 (작게)
5. 익숙해지면 깊이 3–5cm까지 (점진)
6. 빨대 빼고 순모음 transfer

**시간**: 초급 30–60초 × 2–3세트, 총 2–4분. 한 번에 5분 이내.

**금기·언제 중단** (보강):
- **깊이 5cm 초과는 권장 ❌** — 모델·임상 관찰에서 깊은 버블링은 adductor 피로·불편 증가. *2–3cm는 시작 깊이일 뿐 "최적"은 아님* (체감 부하는 폐압·빨대 직경·튜브 길이·버블 강도에 따라 다름)
- *작은 거품·조용한 소리·편안한 압력*만 허용 — *큰 거품·세게 부는 느낌·목 압박감*이면 즉시 중단
- *빨대를 통해 들이마시지 않기* — 호기 전용 (들이마시면 물 흡입 위험)
- *컵·빨대 위생 관리* — 매 사용 후 세척, 공유 ❌
- 어지럼 → *즉시* 중단 (가장 흔한 위험)
- 장시간 지속 ❌
- 큰 소리로 압착 ❌
- 천식·호흡기 질환·어지럼 병력자 → *선택 모듈로 제한*, 의학적 적응증 확인
- *물저항은 회복 도구 — 고강도 훈련 도구가 아님* (정체성 명시)

**자가 관찰 체크리스트**:
- [ ] 어지럽지 않았다
- [ ] 거품이 *작고 연속적*이었다 (큰 거품·간헐 ❌)
- [ ] 침수 깊이 2–3cm 유지
- [ ] 강도가 편안했다 (압착 없음)

**[근거 중간]** OCEBM 1b (RCT 존재) + 5 (모델). *깊은 침수 vs 얕은 침수* 효능 우열은 단정 불가. 회복·쿨다운 운영 권장.

**변이 옵션** (§13): 침수 깊이(2–3cm → 3–5cm) + 음역. *회복일 도구*라 변이 적게 — *멜로디 응용 ❌* (회복 정체성 유지).

### 5.4-A. SOVT 4종 통합 권고

위 4종은 *상호 대체 가능*이 아니라 *기능별 분담*:
- **빨대 발성** = 기본 효율 세팅 (가장 안전, 평생 1차)
- **립 트릴** = 진동·주기성 안정
- **허밍·NG-hum** = 말→노래 전이 가교
- **물저항 빨대** = 회복·쿨다운 (선택)

학습자는 매 세션 1–2개 도구 선택 — 모든 도구 매번 사용 ❌.

**Phase B 주차별 도구 도입·운영 표**:

| 주차 | 신규 도입 | 기존 운영 | 권장 1차 도구 |
|---|---|---|---|
| 9–10 | 빨대 발성 (P3-13) | — | 빨대 (집중 학습) |
| 11–12 | 립 트릴 (P3-17) | 빨대 | 립 트릴 + 빨대 격일 교대 |
| 13–14 | M-hum·NG-hum (P3-19·20) | 빨대·립 트릴 | 허밍 (말→노래 전이) + 빨대 (효율 유지) |
| 15–16 | 물저항 빨대 (P3-15, 선택) | 빨대·립 트릴·허밍 | 학습자 *선호 도구 1–2개* + 회복일 물저항 |

**도구 선택 우선순위**: (1) 그 주의 *신규 도구* 학습 → (2) 학습자가 가장 효과 본 도구 → (3) 회복일은 저강도 (M-hum 또는 물저항).

### 5.5. 훈련 — 균형 발성 찾기 (Phase B 전체 병행)

**무엇**: 자기 발성이 과기식·균형·과압착 중 어디인지 *듣고 식별*. (Part 3 P3-07)
**근거**: 한국어 분류 — 김형미 2025 성대접지 3분류 [CITE: KOR_KIM2025] + part HP §3 성대 5층 (Hirano body-cover) [CITE: HIRANO1974] [CITE: HIRANO1981].

**절차**:
1. SOVT 워밍업 후
2. /h/ 부드럽게 시작 → /a/로 자연 연결: /haaa/
3. 5초 sustain
4. 자기 청취:
   - **숨소리 많이 섞임** → 과기식 (저접지) — *살짝 더 모아*
   - **꽉 막힌 압박감, 강한 어택** → 과압착 (과접지) — *살짝 힘 빼*
   - **명료하면서 편함** → 균형 ✓
5. 녹음 들으며 자가 검토 — 앱은 과기식·균형·과압착 가능성에 대한 *교육용 추정치와 신뢰도 등급*만 표시. *자가주도 트랙*에는 "평정자" 표현을 쓰지 않음. *강사 동반자 트랙*은 강사가 교육적 청감 코멘트만 제공. *SLP/의료기관 동반자 트랙*에서만 임상 평정. 신뢰도 등급 UI는 `app/01-A` §AI 분류 신뢰도 참조.

**진도**:
- 9–12주: 앱 추정치 또는 동반자 트랙 전문가 관찰을 참고해 청취 훈련 (입학 시점 *베이스라인*은 §10 입학 학습 평가 결과)
- 13–16주: 학습자 *시도* — 입학 베이스라인 대비 *향상* 목표 (절대 % ❌, 상대 향상 ✓)
- *왜 절대 컷오프 ❌?*: Pfordresher 2021 SSAP은 *대다수가 정확*하다고 보고 (n=632, 약 70%가 정확 분포). 입학 시점에 이미 50%+인 학습자가 다수 — 절대 컷오프는 변별력 부족. 본 커리큘럼은 *상대 향상*으로 측정.

### 5.6. 훈련 — Self-Imitation Drill (NEW — 자기 모방)

**무엇**: 학습자가 자기 녹음을 모방. *"All singers imitated sung pitch more accurately when imitating recordings of themselves"* — Pfordresher & Mantell 2014 [CITE: PFORDRESHER2014SWY] (학술 유효성 근거; 도입 시점은 본 커리큘럼의 페이즈 설계 — 11주 본격 도입).
**근거**: 청각-운동 통합의 *역방향 모델 (inverse modeling)* — 자기 녹음이 일반 모델보다 효과적. 음치 분포 꼬리(~30%) 학습자에 특히 효과 [CITE: PFORDRESHER2021SSAP].
**도입 흐름**: Phase A 후반 §4.6 골 전도 인지의 *매 녹음 후 짧은 환기*가 self-imitation의 *전조*. 본격 drill은 Phase B 11주 시작.

**절차**:
1. 학습자가 편한 음 1개를 짧게 (2초) 녹음 — /a/ sustain
2. 녹음을 *바로 재생*
3. 학습자가 다시 모방 — 같은 음 sustain
4. F0 비교 시각화 — 시각 도구로 학습자가 두 시도의 차이 확인
5. **5회 반복**으로 자기-자기 청각-운동 매핑 강화
6. **빈도**: Phase B 동안 주 1회 5분 (의무). 분포 꼬리 학습자는 §10 "자기 청취 강화 트랙"에 따라 주 3회로 빈도 ↑. 그 외 세션은 SOVT carryover로 흡수 (Phase B 매 레슨 표 참조).

**적용**: Phase A 후반 *전조*(§4.6 골 전도 인지의 매 녹음 후 환기)에서 시작. Phase B 11주에 *본격 drill* 진입. 자가주도 앱에서 *일반 모델 모방 모듈 전*에 self-imitation 배치.

### 5.8. 훈련 — VFE 4-과제 (선택·심화, Part 3 P3-08~12)

**무엇**: Stemple Vocal Function Exercises — *임상 원형*은 RCT 검증 4-과제 패키지. *자가주도 앱 적응판*은 안전 완화 차용 — 동일 효능 주장 ❌.

**근거**: 임상 원형 VFE는 Stemple 1994 RCT + Angadi 2019 체계적 고찰에서 *중등도~강한 근거* 보고된 음성 기능 훈련 [CITE: STEMPLE_VFE]. Part HP §9 운동 생리학 음성 적용. *다만 본 문서의 자가주도 앱 적응판은 최대 지속·MPT·고정 피치 요구를 완화한 안전 적응판이므로, 임상 원형과 동일한 효능을 주장하지 않음*. 본 앱에서는 *워밍업·기능 점검·자가 관찰 도구로 제한 사용*.

**4-과제 절차 — 자가주도 앱 적응판** (한 세트, 매 운동 *2회 반복*. 임상 원본의 *최대·MPT*·*고정 피치 강요*는 자가주도 과부하 위험으로 *완화*):

1. **Warm-up — /i/ sustain (P3-09)**: 편안한 중음에서 /i/를 *편안하게 유지 가능한 시간* (comfortable sustained duration)만 지속. 피치는 *개인 편안한 중음 기준* (임상 원본 여 F4·남 F3 기준은 SLP/의료기관 동반자 트랙 지도 시에만). *Soft·engaged·non-breathy*. 비강화 onset. *"knoll"은 본 과제에 사용하지 않음* (P3-12 power 과제 영역).
2. **Stretching — 상행 글라이드 (P3-10)**: /o/ SOVT 자세로 *편한 저음 → 편한 고음* 천천히 글라이드 (*"가장 낮은·가장 높은"* ❌). 피치 브레이크 없이.
3. **Contracting — 하행 글라이드 (P3-11)**: /o/ SOVT 자세로 *편한 고음 → 편한 저음* 글라이드. *vocal fry로 떨어지지 않게*.
4. **Power — sustain (P3-12)**: /o/로 *개인 편한 중음 5음 정도* 각각 *편안하게 유지 가능한 시간* (*최대·MPT* ❌). MPT 측정은 *동반자 트랙*에서만.

**시간**: 자가주도 앱 적응판은 한 세트 6–8분, *주 1–2회부터 시작*. 임상 원형 프로토콜의 *2회/일 × 4–6주*는 참고 정보이며 자가주도 초급 학습자의 목표 빈도가 아님 — 동반자 트랙·SLP 지도 시에만 임상 빈도.

**금기·언제 중단**:
- 강제로 음역 확장 ❌, *최대 지속* 시도 ❌
- 균형 발성(§5.5)이 *4주 이상 안정* + 다음날 피로 없음 + 적색 신호 통과 후 *잠금 해제*형 모듈로 도입
- 통증 참고 지속 ❌ (프로토콜이 "운동"이라 과훈련 유혹 — *최대·MPT 단어 회피*)
- adductor 피로 (특히 과긴장형) → 즉시 중단
- 레지스터 브레이크를 힘으로 누름 ❌

**자가 관찰 체크리스트**:
- [ ] 4-과제 모두 *통증 없이* 완수 가능
- [ ] /i/ sustain을 *편안하게 유지 가능한 시간*으로 반복했을 때 effort·음질·다음날 피로가 안정적
- [ ] 글라이드에서 *힘으로 브레이크를 누르지 않음*
- [ ] 다음날 피로 없음

**[근거]** *임상 원형 VFE: 중등도~강함 (OCEBM 1b RCT + 1a 체계적 고찰)*. *자가주도 앱 적응판: 안전 완화 차용, 직접 효능 검증 필요 — 임상 원형과 동일 효능 주장 ❌*. 스타일 전이는 별도 검증 필요.

**선택 기준**: §5.5 균형 발성이 *4주 이상 안정* 후 15–16주 도입. 학습자 대면 지도 권장 (피치 지정 정확도 필요).

### 5.9. 훈련 — 학습자 자기 곡 SOVT 모방 (11주차+ 도입, 동기·변이 핵심)

**무엇**: 학습자가 *좋아하는 곡* 한 구절을 *SOVT 도구(빨대·립 트릴·허밍)로 따라 부르기*. 가사 ❌, 멜로디만. 본 카드는 §13 *훈련 변이 정책*의 *멜로디 응용 축*을 구체화한 모듈.

**왜 11주차?** — Phase B 시작 직후, 빨대 발성·립 트릴이 학습된 시점. *너무 늦으면 이탈, 너무 일찍이면 cognitive 단계 학습 방해*. Schmidt & Lee variation 원리 + Pfordresher self-imitation 결합 [CITE: SCHMIDT_LEE2019] [CITE: PFORDRESHER2014SWY].

**근거**: §13.1 학술 토대 + Patel OPERA 가설 [CITE: PATEL2011_OPERA] (음악·언어 전이 5조건 중 *Emotion·Repetition·Attention* 강화). 자가주도 앱 동기 유지의 *학술 정당화*.

**준비물**: 학습자 본인 좋아하는 곡 1곡 — *음역 1옥타브 이내*, *강도 중간*, *학습자 친숙*. 장르 무관 (K-pop·발라드·팝·뮤지컬 모두 가능). 단 belt·고음·distortion 곡 ❌ (16주까지 그런 곡은 SOVT 모방으로도 위험 — 곡 선택 시 앱 가드레일).

**절차**:
1. 곡의 *매우 짧은 구간* 선택: **4–8마디 또는 15–30초 이내** (1옥타브 이내)
2. **원곡 음원을 앱에 업로드하지 않음** (저작권 보호)
3. 학습자는 *기억한 멜로디*를 무반주 또는 *앱이 제공하는 라이선스 클리어된 기준음*만으로 수행
4. **빨대 발성**으로 멜로디만 따라 부르기 — 가사 ❌, 빨대 sustain·글라이드로 음정만
5. 익숙해지면 **립 트릴**로 같은 구절
6. 다음으로 **M-hum**으로 같은 구절
7. *SOVT 도구 빼고* /u/ 또는 /a/ 모음 한 종류로 같은 구절 (*carryover*)
8. 절대 가사 추가 ❌ (Phase C 17주차 이후에만 가사)

**시간**: 매 세션 5–10분, 주 2–3회. SOVT 본 워밍업 *후*에 배치.

**금기·언제 중단**:
- 곡의 *원곡 강도·음역 따라하기* ❌ (학습자 음역 내로 *조옮김*)
- 가사 추가 ❌ (16주까지)
- belt·고음·distortion 곡 선택 ❌
- 어지럼·피로 → 즉시 SOVT 단순 sustain로 복귀
- *3분 이상 한 구절 반복* ❌ (cognitive 부담)

**자가 관찰 체크리스트**:
- [ ] 곡 멜로디를 *내 음역 안*에서 따라 부를 수 있다 (조옮김)
- [ ] SOVT 도구 빠지고 모음만 했을 때 *느낌 carryover*된다
- [ ] 가사 없이 *멜로디만*에 집중한다
- [ ] 다음날 피로 없다

**학습자 동기 메시지** (앱 표시):
- "이제 *네가 좋아하는 곡*으로 — 단, *멜로디만*. 가사는 17주차부터."
- "왜 가사 ❌? — 가사를 더하면 *발성 + 발음 + 리듬* 3중 부하. 11주차는 *멜로디 모방*만으로 충분히 변이 효과."

**[근거 통합]** OCEBM 변이 원리 (Schmidt & Lee L5) + self-imitation 효과 (Pfordresher L2) + 동기 유지 페다고지 합의 (L5). 본 모듈의 *효능 RCT는 부재* — 본 커리큘럼의 *동기·변이 운영 원칙*. `[탐색적 근거]` (효능 측면).

**저작권·음원·녹음 정책** (한국 저작권법 + 대법원 2012다109798):
- *원곡 음원 업로드·스트리밍·공유 금지*
- 저작권 있는 곡의 *멜로디를 학습자가 직접 부른 녹음*도 서버 저장·클라우드 동기화·다운로드 제공·공유·AI 학습에 사용할 경우 *복제권·전송권/공중송신권 검토 필수* (사적 이용 복제는 전송 면책 ❌)
- **V1 기본값**: *로컬 단말 내 일시적 개인 학습 확인만 허용*. 서버 업로드·클라우드 보관·커뮤니티 공유·AI 학습 *기본 비활성*
- 서버 저장이 필요한 경우: *권리 처리된 곡·자작곡·퍼블릭도메인·라이선스 클리어 샘플*만 허용 또는 *별도 권리 검토 후 허용*

- 운영 워크플로 — `app/01-B` 저작권·동의 정책 위임

## 6. Phase C — 기초 공명 + 무대 자가 관리 (17–24주)

이 시기에 *처음* 노래에 가까운 작업이 나오지만 *짧고 보수적*. **무대 공포 자가 관리**(Greene 7-Step + Inner Game)가 신규 모듈로 통합.

### 6.1. 훈련 — 모음 안정 (Part 4) — 훈련용 5모음 + 한국어 모듈

**무엇**: 모음을 *흔들리지 않게* 5초 sustain. 음량·음질 일관성. **두 트랙으로 분리**:
- **훈련용 5모음** (국제 IPA 표준): /a, e, i, o, u/
- **한국어 적용 모듈**: ㅏ /a/, ㅓ /ʌ~ə/, ㅗ /o/, ㅜ /u/, ㅡ /ɯ/, ㅣ /i/, ㅔ≈ㅐ /e~ɛ/ — 현대 서울 한국어 단모음 7–10개 체계 (연구자별 차이, /ㅐ/–/ㅔ/ 합류 진행 중) [CITE: KOR_SPEECHRATE]. *교육용 대표값이며 세대·지역·장르에 따라 실현 차이 있음*. 클래식 diction·뮤지컬 diction·CCM/K-pop diction은 중급 이후 장르별 분리.

**근거**: 훈련 5모음은 Hillenbrand 1995 미국 영어 표준 (한국어 가창 formant DB 부재) [CITE: LEE2017CGU]. 한국어 모음 체계는 한국 음성학 1차 자료 [CITE: KOR_SPEECHRATE] [CITE: KOR_SOPRANO_ACOUSTIC]. part QI §5 + part HP §4. `[근거 부족]` (한국어 가창 formant 표준 부재).

**절차**:
1. SOVT 5분 워밍업 후
2. 편한 중음 한 음에서 /i/ 5초 sustain — *부드러운 onset* (Part 3 허밍·무성 마찰음 기반 전이)
3. 같은 음·강도로 /e/, /a/, /o/, /u/ 차례로 sustain (5초씩)
4. 모음만 변경, 강도·피치는 *동일 유지*
5. 녹음 후 *모음마다 음량·음질 일관성* 자가 검토
6. 단계별: (초) 단음 5개 → (중) 1옥타브 스케일 → (고) 짧은 프레이즈

**시간**: 매 레슨 10–15분, 주 3–5회.

**금기·언제 중단**:
- 고음에서 모음 붕괴 시 *강도 ↑* ❌ — 포먼트 조정으로만 처리 (중급+)
- 혀 긴장 → Part 1·2 이완 선행
- 큰 음량 ❌, 음역 확장 ❌

**자가 관찰 체크리스트**:
- [ ] 5개 모음이 청취 시 *구별*된다
- [ ] 각 모음에서 강도가 *균등*하다 (큰 모음·작은 모음 없음)
- [ ] 후두 위치가 모음마다 *심하게* 흔들리지 않는다
- [ ] 턱이 모음마다 *새로 잡히지* 않는다 (거울 확인)

**[근거 약함]** OCEBM 3b~5 (관찰·이론). 한국어 가창자 formant DB는 `app/01-C` §음정 통과 기준와 별도 — *현재 부재*.

**한국어 가창 저부하 딕션 모듈** (K-pop·CCM·뮤지컬 트랙 학습자 대상, Phase C 후반 도입):
한국어 가사 가창은 *발성 + 발음 + 리듬 3중 부하*. 본 모듈은 *부하 관리* 중심.
- **받침 처리**: 자음 종성을 *짧게·정확히* (가사 sustain 시 받침 ↓·모음 ↑)
- **연음**: 자음 + 모음 연결 시 *부드러운 carryover*
- **된소리·거센소리** (/ㄲ/, /ㅋ/ 등) 반복은 *vocal load ↑* — 짧게·소량
- **빠른 자음군** (예: /ㄹㅎ/, /ㄴㅎ/): *과긴장 회피*
- **모음 유지 vs 자음 명료도 균형** — 음표 sustain 80–90%는 모음, 자음은 짧게

운영: 적용곡 §6.4에서 *한국어 가사 곡* 선택 시 자동 활성. *짧은 한 구절*만 — 곡 풀 가사 ❌.

**[근거 부족]** OCEBM 5 (페다고지 합의). 한국어 가창 부하 측정 RCT 부재 — `[탐색적 근거]`.

### 6.2. 훈련 — 모음-모음 전환 (Part 4)

**무엇**: 같은 피치·강도에서 모음 전환 (/i/→/e/→/a/→/o/→/u/) — *legato* 감각.

**근거**: Vowel modification (aggiustamento) 페다고지 [CITE: CHAN_DO2021]. part HP §4. OCEBM 3b~5.

**절차**:
1. 편한 중음에서 /i-e-a-o-u/ 한 호흡에 끊김 없이 (각 1초)
2. *전환 중 glottal stop 없이* 부드럽게 변형 — 후두·턱 *움직임 최소화*
3. 거울 앞에서 — 턱이 모음마다 *새로 떨어지면* 잘못된 것
4. 후두 위치 손가락으로 부드럽게 확인 (인위적 통제 ❌, 관찰만)
5. 익숙해지면 역순 /u-o-a-e-i/, 그 후 짧은 글라이드와 결합
6. 단계별: (초) 5도 이내 동일 음역 전환 → (중) 반음 상향 반복 → (고) 실제 레퍼토리 구간

**고음 접근 시 정책 선택** (학습자가 의식):
- *명료 우선*: 원래 모음 형태 유지 (클래식 가곡 적합)
- *효율 우선*: 중립화·모음 색 완화 (CCM·뮤지컬 적합)

**시간**: 매 레슨 10분 (Phase C 전반), 주 2–3회 기술 세션.

**금기·언제 중단**:
- "명확한 정책 없이" 모음을 자의적으로 바꾸면 음정·공명 불안정
- glottal attack 위험 시 즉시 SOVT 복귀
- 고음 무리 ❌

**자가 관찰 체크리스트**:
- [ ] 전환이 *끊기지 않았다*
- [ ] 턱·후두 움직임 최소화
- [ ] 녹음에서 명료도 vs 편안감 *둘 다 만족*

**[근거 약함]** OCEBM 3b~5. *명료-효율 정책 선택*은 페다고지 합의 사항.

### 6.3. 훈련 — 기초 Placement 감각 (은유 명시) (Part 14)

### 6.6. 훈련 — 무대 공포 7-Step Centering + Graded Exposure (NEW — 17주 도입, Phase C 전체 병행)

**무엇**: 매 세션·연주 전 *수행 전 루틴 / 주의 조절 / 불안 관리 보조 도구*. 자가주도 학습자의 *수행 안정 지원* (단, 7-Step만이 *유일한* 자가 관리 도구는 ❌ — *graded exposure*와 결합).
**근거 등급 — *낮음~중간***: Greene 2002 [CITE: GREENE2002] (1차 원형 Nideffer 1976 [CITE: NIDEFFER1976]) + Helding 2020 [CITE: HELDING2020] + Kenny K-MPAI [CITE: KENNY2011]. Inner Game [CITE: GREEN_GALLWEY1986] 보조. part HP §10. **음악 수행불안(MPA) 개입 연구는 일반적으로 RCT 부족·표본 제한**으로 *최선 치료 단정 어려움* (구체 체계적 고찰 출처 미인증 — part HX §5 추적 필요). SOVT/VFE 같은 *강한 생리학 근거*와 같은 층위 ❌. *수행 전 루틴*으로서 가치는 인정.

**의학적 의뢰 트리거**: *갑작스러운 극심한 불안 발작에 해당할 수 있는 증상·회피로 인한 일상 기능 저하·무대 상황의 호흡곤란·실신감* → 정신건강 전문가 상담 권고. 본 모듈은 *수행 전 루틴·주의 조절 보조 도구*이며, *불안 장애 진단·치료 ❌*.

**7-step 절차**:
1. **Pick a focal point** — 시야 외부 한 점 선택 (예: 화면 한 점·바닥 표시)
2. **Form a clear intention** — 단일·긍정·동사형 ("let it sing", "release")
3. **Breathe mindfully** — *4초 들숨 / 6초 날숨은 예시일 뿐*. 학습자는 *어지럼·가슴 답답함·공황감 없는 자기 호흡 길이* 선택. 불안 민감자는 *"발바닥 감각 3초 관찰"* 으로 대체 가능.
4. **Scan and release tension** — 머리 → 목·어깨 → 가슴·복부 → 다리 신체 스캔
5. **Find your center** — *hara/단전* (배꼽 약 2인치 아래) — *해부학적 중심이 아니라 수행 전 주의 집중을 돕는 신체 은유*. 한국 한의학·일본 무도 문화권 용어로 *문화 배경에 따라 의미 다름*.
6. **Repeat a process cue** — 결과 단어 ❌ ("perfect"/"잘"), 과정 단어 ✓ ("breathe"/"호흡")
7. **Direct your energy** — focal point으로 에너지 방출 → 수행 시작

**진도**:
- 17–18주: 7-step 학습
- 19–20주: 2–5분 단축판
- 21–24주: 30초–1분 단축판 또는 5–10초 cue-only 버전

*단축 속도는 개인차가 크며, 1–2주 단축은 보장하지 않는다*. MPA 개입 연구는 일반적으로 RCT 부족·표본 제한으로 최선 치료 단정 어려움 (구체 체계적 고찰 출처는 part HX §5 추적 필요).

**Inner Game 보조 — Self 1·Self 2 인식 (자가 코칭 변형판)**:
원문은 강사 코칭 도구이나, 자가주도 학습자는 *self-talk* 형태로 적용:
- *Self 1* (비판·분석·언어): "이 부분 또 틀렸어!" — 학습자가 *자기 인식* 후 거리 두기
- *Self 2* (직관·신체·통합): 가창 자체에 몰입
- *Awareness drill*: 자가 녹음 리뷰 시 *non-judgmental prompt* — "어디가 어떻게 들렸는가" (좋다/나쁘다 ❌)

**금기**: 결과 단어 사용 ("perfect"·"잘 해야지"), 과도한 자기 비판 강박

**Graded Exposure 5단계** (앱 페다고지 차원의 *체계적 수행 노출* — 7-Step보다 실제 훈련 설계에 더 강한 작동 가능):
1. **혼자 녹음** (Phase B 11주차+ 자기 곡 모방으로 자연 시작)
2. **앱에 제출** — 동료 커뮤니티 ❌ (V1 비활성), AI 분석 추정치 확인만
3. **신뢰하는 한 명에게 들려주기** — 가족·친구 1명
4. **2–3명 앞에서 30초 부르기** — 비공식·짧게
5. **작은 온라인/오프라인 발표** — 졸업 후 (옵션)

각 단계 통과 후 다음 단계, *역순으로 후퇴 가능* (불안 시). 7-Step Centering은 각 단계 *전*에 사용.

## 7. 평가 — 무엇을 어떻게 보나

### 자기보고 (학습자)
- **매주**: VAS 1–10 자기평가 (P7-03)
- **격주**: EASE 22문항 (P7-04) — *가창 용이성·피로·불편감 추세 모니터링 도구*. **EASE 점수 ↑ = 악화 가능성** (UI에 명시). EASE *단독 ≠ 진단* — 질환 진단 도구 ❌. *치료 효과 판정 단독 지표 ❌*. EASE 상승 단독 = 훈련 강도 조절·휴식 권고. EASE 상승 + 적색 신호(§3) → 레슨 중단 + 의학적 의뢰.
- **월간**: 표준 샘플 재녹음 + 직전월 비교 메모 *(non-judgmental prompt)*

### 청감 평가 — *자가주도 트랙*과 *동반자 트랙* 분리

> 본 절은 페다고지 정의. **CAPE-V·GRBAS는 임상·연구용 평정 도구이며 *임상가가 평정*하는 절차** [CITE: KEMPSTER_CAPEV]. 본 앱이 임상 평정을 수행한다고 *주장하지 않는다* (의료기기법 회피, `app/01-B §9` 법무 검토).

**자가주도 트랙** (학습자 단독, 앱 AI 보조):
- **매 세션**: 자세·턱·후설 긴장 자가 관찰 체크리스트 (Part 7 §"관찰 항목") — 자가 거울 + 앱 시각 분석
- **추세 모니터링** (8·16·24주차): 앱 AI는 *녹음에서 관찰되는 청지각 특성 가능성 및 음정 안정성의 교육용 추정치(estimate)*만 제공. *임상 평정 ❌*. 본 추정치는 *변화 추세·연습 가이드*에만 사용, 진단·치료 결정에 사용하지 않음.
- **자동 기록·자가 모니터링 보조 도구**: VOQANet [CITE: VOQANET2025] — *자가 모니터링 보조 신호*. 컨슈머 마이크·환경 변동성으로 신뢰도 한계 (Manfredi 2017 [CITE: MANFREDI2017]) — 임상급 결정 ❌.

**강사 동반자 트랙** (선택, 보컬 강사 협진):
- **매 세션**: 강사가 *교육적 청감 코멘트* + 발성 습관·기법 피드백 + 과제 수행 확인. *임상 평정 ❌*.
- **CAPE-V·GRBAS 등 임상 음성 평정 도구는 강사가 사용하지 않음**.
- 강사는 동일 녹음을 보더라도 *교육적 관찰*로만 기록.

**SLP/의료기관 동반자 트랙** (선택, SLP·이비인후과 협진):
- **8·16·24주차 체크포인트**: GRBAS 5차원 + CAPE-V 전체 — *SLP/의료기관 임상 평정자가* 0–3 척도 / 0–100 VAS [CITE: HIRANO1981] [CITE: KEMPSTER_CAPEV]
- 앱 AI 추정치는 *교차검증* 보조 자료로만 사용
- 운영 워크플로 — `app/01-B §평가 워크플로` 참조

### Anatomy Self-Quiz — *형성 평가* (졸업 필수 ❌)

**문진 양성자 처리 분기** (17개 항목 모두):

- **1번 양성** (현재 쉰 목소리·통증·음성상실):

  - 새 음성 변화 동반 → 자가주도 발성 모듈 잠금 + 신속 ENT/후두 평가 후 재입학

## 12. 학습자 안내 — 운동 학습 3단계 (NEW, 1주차 필수 교육)

**Fitts & Posner 1967** [CITE: FITTS_POSNER1967] + Schmidt & Lee 2019 [CITE: SCHMIDT_LEE2019]. *왜 24주 진도가 그런 속도인가*에 대한 학습자 자기 이해.

| 단계 | 특성 | 보컬 적용 | 대략 매핑 |
|---|---|---|---|
| **Cognitive (인지)** | 의식적 사고로 절차 구성, 오류 多 | "빨대 어떻게 무는가" 의식 | Phase A 초기 |
| **Associative (연합)** | 절차 통합, 오류 ↓ | SOVT 자동에 가까워짐 | Phase B 중·후반 |
| **Autonomous (자율)** | 자동화, 다른 과제와 동시 가능 | SOVT를 *생각 없이* 워밍업 | Phase C·중급 |

**학습자 메시지**: "초급 24주는 *cognitive → associative*가 목표. 자동(autonomous)은 중급 이후."

**OPERA 가설 보조 동기부여** — Patel 2011 [CITE: PATEL2011_OPERA]: OPERA는 음악 훈련과 말소리 처리 간 *전이를 설명하는 가설적 신경기전 틀*. 5조건(Overlap·Precision·Emotion·Repetition·Attention)이 만족될 때 전이 가능성. *본 앱의 발음·말소리·자신감 개선 효과를 직접 입증하는 근거로 사용 ❌*. 본 커리큘럼에서는 *친숙한 곡·반복·주의 집중이 학습 동기를 높이는 간접 근거*로만 사용.

## 13. 훈련 변이 정책 (지루함·이탈 방지)

자가주도 앱 학습자에게 *동일 훈련 반복*은 이탈 1순위 위험. 본 §은 *학술 안전성(Fitts & Posner cognitive 단계의 반복 필요성)*과 *동기 유지(retention 향상의 variation 필요성)*의 균형을 정의한다.

### 13.1. 학술 토대

**Schmidt & Lee 2019** [CITE: SCHMIDT_LEE2019] 의 *Blocked vs Random* 원리:
- **Blocked practice** (같은 과제 반복) — *즉시 수행*에 강함, *cognitive 단계*(Phase A 초중반)에 적합
- **Random / Variable practice** (다양한 과제 섞음) — *retention·전이*에 강함, *associative 단계+*(Phase B 후반·C)에 핵심

→ 본 24주는 *blocked 우세 + 단계적 variation 도입*. 완전 단조 ❌, 무작위 변이 ❌. *원칙적 변이*.

### 13.2. 변이 5축 (모든 SOVT·발성 카드 공통)

같은 운동 메커니즘 안에서 *표면을 바꾸는* 5가지 축:

| 축 | 변이 예시 | 도입 시점 |
|---|---|---|
| **음역** | 오늘 중음 → 내일 약간 낮은 음 → 내일 약간 높은 음 | Phase A 후반부터 |
| **모음** | /u/ → /a/ → /i/ → /o/ | Phase B 중반부터 |
| **글라이드 패턴** | sustain → 사이렌(5도) → 한 옥타브 글라이드 → 멜로디 | Phase B 후반부터 |
| **멜로디 응용** | *친숙한 곡* 한 구절을 SOVT로 따라 부르기 | **11주차부터** (§5.9 참조) |
| **세션 컨텍스트** | 워밍업 / 본 훈련 / 쿨다운 / 회복일 위치 변경 | Phase B 전반 |

원칙: *한 세션에 1–2개 축 변이*. 5개 축 동시 변경은 *random practice*로 cognitive 단계 학습자에 부적절.

### 13.3. 학습자 자율 + 앱 가드레일

자가주도 앱 운영:
- **학습자 선택권**: 매 세션 시작 시 *오늘 어떤 도구로 시작할까?* 학습자 선택
- **앱 가드레일**: 그 주의 신규 도구는 *소개·관찰·선택 실습* 기회를 제공. 단 *금기·어지럼·호흡 불편·통증·피로 시 즉시 건너뛰기 또는 이전 안전 도구로 대체 가능*. 의무 시간은 *금기 없음 + 불편 없음 + 학습자 동의* 조건에서만 적용.
- **균형 보장**: 7일 단위로 *사용 가능한 SOVT 도구 중 2–3개 경험* 권장. *물저항 빨대는 선택/회복 도구이며, 천식·호흡기 질환·어지럼 병력자는 자동 체크 대상에서 제외 가능*. 신규 도구 학습 주간에도 불편·어지럼·피로 시 이전 안전 도구로 대체.

### 13.4. 게이미피케이션·UI 위임

> 본 절은 페다고지 정의. 실제 게이미피케이션·진도 시각화·streak·배지·1주차 vs 현재 비교 UI는 `app/01-A` §게이미피케이션 사양에서 정의. 본 문서는 *학술 토대(13.1)·변이 5축(13.2)·자율 정책(13.3)*만 정의한다.

### 13.5. 페이즈별 변이 비율 권장

| Phase | Blocked 비율 | Variable 비율 | 학습자 메시지 |
|---|---|---|---|
| **A** (1–8주) | 80% | 20% (음역 변이만) | "지금은 *반복으로 몸에 새기는* 시기" |
| **B** (9–16주) | 60% | 40% (음역·모음·멜로디 응용) | "변이가 retention을 만든다" |

### 13.6. *반복은 학습, 단조는 이탈* — 학습자 첫 주 교육 메시지

학습자에게 *명시적*으로 가르침:
- "왜 같은 빨대 발성을 며칠 반복하나? — *cognitive → associative 자동화*에 필수"
- "왜 11주차부터 내 곡을 쓰나? — *변이가 retention을 만든다*"
- "왜 Phase A는 변이 적고 C는 많나? — *학술 검증된 단계적 도입*"

→ 학습자가 *반복의 학술 정당화*를 이해하면 지루함 자체가 *동기 유발 요인*으로 전환. 단순히 게이미피케이션이 아닌 *과학 교육으로 동기*.
