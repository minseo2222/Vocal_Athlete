# Advanced CCM / Worship Lab — v9

> 여기서 CCM은 Christian Contemporary Music / Worship을 뜻한다. Contemporary Commercial Music과 구분한다.

## 1. 학습 목표

- 가사 의미와 congregational clarity
- 긴 phrase의 breath economy
- 반복 후렴에서 pitch/tone/effort drift 관찰
- 밴드 반주와 마이크 환경의 명료도
- core melody의 안정된 entry
- 신앙적 진정성을 음량·압착으로 대체하지 않는 표현

## 2. 전용 카드

| ID | 내용 | 안전 경계 |
|---|---|---|
| WC-01 | Text & Intention | 감정을 음량으로만 만들지 않음 |
| WC-02 | Long-Phrase Economy | 숨 참기 대신 breath mark/catch breath |
| WC-03 | Repeated-Chorus Drift | 최대 2 take, 피로 증가 시 종료 |
| WC-04 | Band & Mic Clarity | 반주보다 크게 밀지 않음 |
| WC-05 | Congregational Entry | 장식보다 core melody 우선 |
| WC-06 | One-Take Review | 최대 2 take, 듣기 후 결정 |

## 3. 40-slot cycle

| Phase | slots | 주 내용 | 산출물 |
|---|---:|---|---|
| 1. Text/Phrase Baseline | 1–10 | 의미, phrase map, mic context | verse baseline |
| 2. Long Phrase/Tone | 11–20 | catch breath, warm/clean tone | phrase pair |
| 3. Chorus/Band | 21–30 | repeated chorus, core melody, band clarity | first/last pair |
| 4. One-Take/Recovery | 31–40 | limited one-take, self-review, deload | portfolio candidate |

## 4. 방법론

- 긴 phrase는 숨을 많이 들이마시는 과제가 아니라 의미 단위와 key 조정으로 해결한다.
- 반복 후렴은 첫/마지막 take의 pitch, tone, effort를 따로 본다.
- 밴드 조건에서는 consonant timing, mic distance, accompaniment density를 조정한다.
- 원곡 key와 무제한 반복을 강제하지 않는다.

## 5. 피드백

가사 전달, phrase completion, first/last chorus drift, mic quality, effort/recovery를 본다. 신앙적 진정성이나 감정의 옳고 그름을 AI가 판정하지 않는다.

## 6. 출시 조건

장르 전문가 검수, worship/band 자산, 반복 후렴 부하 파일럿, mic QA 전 기본 미출시다.
