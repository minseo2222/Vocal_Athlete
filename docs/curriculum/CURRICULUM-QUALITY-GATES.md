# CURRICULUM QUALITY GATES — v9

새 카드·경로·장르 트랙은 아래 조건을 통과해야 canonical curriculum에 들어간다.

## 1. 학습 설계

- 학습 목표가 관찰 가능한 행동으로 쓰였는가
- 선행 카드와 다음 전이가 정의됐는가
- acquisition뿐 아니라 retention 또는 transfer 위치가 있는가
- 한 세트의 primary criterion이 하나인가
- 전체 프레이즈 맥락으로 돌아오는가

## 2. 안전

- voice state에 따른 축소/회복 대안이 있는가
- 고위험이면 HITL, cap, fallback, release flag가 있는가
- maximum range·maximum sustain·원키를 성공 기준으로 삼지 않는가
- 통증·쉰 목소리·피로를 무시하는 streak 설계가 없는가

## 3. 피드백

- 자동화 가능한 결과와 사람이 판단할 영역을 분리했는가
- 낮은 신뢰도 데이터가 숨겨지는가
- 성대 상태·원인·음색 미학을 진단하지 않는가
- 사용자 자기판단 뒤 피드백을 제공할 수 있는가

## 4. 콘텐츠

- 실제 exemplar/guide/backing/가사 timing이 존재하는가
- 권리·라이선스 기록이 있는가
- key/tempo/난이도 variant가 정의됐는가
- 음원 없이 문서만 있는 카드를 출시 카드로 표시하지 않는가

## 5. 평가

- completion과 mastery를 구분하는가
- delayed retention 또는 transfer artifact가 있는가
- 단일 총점 대신 영역별 증거를 제공하는가
- 평가자간 신뢰도 또는 사용자 이해도 검증 계획이 있는가

## 6. 출시 상태

```text
draft
→ research-reviewed
→ expert-reviewed
→ asset-complete
→ device-QA
→ pilot-validated
→ released
```

단계 하나라도 누락되면 다음 단계로 자동 승격하지 않는다.
