# LEARNING-METHODOLOGY-SPEC — v9

## 1. 학습의 정의

보컬 학습은 당일 화면 점수가 아니라 세 가지 증거로 본다.

1. **Acquisition**: 모델·cue가 있는 상태에서 과제를 이해하고 시도한다.
2. **Retention**: 시간이 지난 뒤 도움을 줄여도 재현한다.
3. **Transfer**: 모음, 시작음, tempo, key, 가사, 프레이즈 중 하나가 바뀌어도 전략을 사용한다.

일일 해금은 completion 기반을 유지하고, 레벨·포트폴리오는 retention과 transfer 산출물을 요구한다.

## 2. v9 attempt-first 원칙

안전 문제가 없고 과제를 이해한 뒤에는 교사가 말하듯 계속 개입하는 대신, 사용자가 짧게 시도할 시간을 확보한다.

```text
과제 확인
→ 첫 시도
→ 1–2회의 추가 시도
→ 사용자 자기판단
→ 묶음 피드백 1개
→ 재시도 1회
```

- 실시간 피드백은 clipping, 권한, 입력 신뢰도, 명확한 박자 entry처럼 즉시 보정 가치가 큰 항목에 제한한다.
- pitch·timbre·phrase는 기본적으로 take 뒤에 확인한다.
- 안전 cue는 즉시 개입할 수 있다.
- 2–3회라는 수치는 검증 전 제품 기본값이며 카드 부하와 목 상태에 따라 줄인다.

## 3. 10–15분 레슨 템플릿

| 단계 | 권장 시간 | 행동 | 피드백 |
|---|---:|---|---|
| Readiness | 30–60초 | 목 상태·오늘 부하 확인 | 정상/축소/회복 모드 |
| Task map | 1–2분 | exemplar 듣기, 기준 하나 선택 | 짧은 외적 cue |
| Attempt set | 4–7분 | 짧은 시도 2–6회 | 매회 점수 금지 |
| Self-judgment | 30–60초 | 높음/낮음, 빠름/느림, comfort, tone tag | 앱 피드백 전에 수행 |
| Feedback/retry | 1–2분 | nudge 하나 뒤 재시도 | 결과형·deferred |
| Global return | 1–2분 | 전체 phrase 또는 원 과제로 복귀 | 재통합 확인 |
| Cooldown/log | 1–2분 | 가벼운 회복 또는 no-voice 기록 | next cue 하나 |

활성 발성 시간은 연구 지표로 기록할 수 있으나, 고정 최소시간을 해금 게이트로 쓰지 않는다.

## 4. 초점과 cue

- 한 세트의 primary criterion은 하나다.
- 신체 부위 조작보다 들리는 결과, 리듬 목표, phrase 방향 같은 외적 cue를 우선한다.
- 내부 감각 cue는 안전하고 구체적인 경우에만 보조로 쓴다.
- “더 세게”, “더 높게”, “성대를 붙여라” 같은 과잉 동원 cue를 피한다.
- 사용자에게 답을 먼저 주기보다 자기 오류 탐지를 훈련한다.

## 5. 연습 배치

- 새 기술은 짧은 blocked practice로 시작한다.
- 이후 모음·리듬·프레이즈를 한 축씩 바꾼다.
- Universal Core는 12일 microcycle마다 pitch, rhythm, phrase, retrieval을 다시 호출한다.
- Repertoire Application은 매 12일 프로젝트에서 Global→Local→Global을 완결한다.
- 고급은 기술 카드 소비가 아니라 곡/구간 프로젝트를 중심으로 한다.
- 정확한 D0/D1/D3/D7 간격은 검증 전 가설이며 사용 데이터로 조정한다.

## 6. 피드백 fade

피드백은 날짜가 아니라 다음 조건에 따라 줄인다.

- 사용자가 오류를 스스로 찾는가
- 모델 없이 지연 재현하는가
- 다른 조건에서도 전략을 사용하는가
- 낮은 신뢰도 데이터에 집착하지 않는가
- 목 상태에 맞는 안전 선택을 하는가

```text
모델 + cue
→ 선택형 cue
→ 결과 요약
→ 요청형 피드백
→ 독립 take
```

## 7. 회복도 학습이다

피곤하거나 쉰 상태에서는 voiced task를 강행하지 않는다.

- guide 듣기와 특징 찾기
- 이전 take A/B
- rhythm tap
- 가사 리듬 말하기
- breath mark·phrase planning
- 자기평가와 다음 cue 기록

`CARD-18`은 이러한 런타임 recovery fallback이며 정상 curriculum slot이 아니다.

## 8. 단계별 적용

| 단계 | 중심 방식 |
|---|---|
| Beginner | blocked practice, 짧은 모델, deferred feedback |
| Universal Core | 12일 spiral, 지연 재현, 한 변수 변형 |
| Repertoire Application | 12일 phrase project, Global→Local→Global, guide fade |
| Advanced Genre Lab | project cycle, 장르 산출물, 부하 cap |
| Portfolio | delayed one-take, transfer, 자기평가·선택형 전문가 리뷰 |

## 9. 검증 상태

시도 횟수, 레슨 시간, checkpoint 간격, active singing 비율은 제품 가설이다. 사용자 학습효과와 안전을 대상으로 별도 파일럿 검증이 필요하다.
