# Beginner Foundation — v16 초급 커리큘럼

> 코드 권위: `buildPlaceholderManifest()` = 48 slots. 음색은 관찰·자기태그까지만 다루며, `CARD-18`은 정상 경로가 아닌 목 상태 기반 회복 대체 카드다.

## 1. 역할

초급의 목적은 노래를 빨리 완창시키는 것이 아니라, 이후 공통 코어를 안전하게 시작할 수 있는 최소 기반을 만드는 것이다.

- 짧고 편한 발성 습관
- 자세·호흡·턱·혀·목의 불필요한 긴장 관찰
- easy onset과 낮은 부하 SOVT
- 듣기→상상→허밍의 기초
- 4박 pulse와 2–3음 contour
- 한국어 음절로의 저부하 전이
- 자기 녹음과 확인형 피치 피드백 사용
- 허밍→모음과 모음 색채의 차이를 듣고 편안함 기록

곡 완창, 고음 확장, belt, run, passaggio handling, 장르 음색은 초급 범위가 아니다.

## 2. 진행과 안전

- 해금용 진도는 1일 1레슨, completion 기반이다.
- Day 1/24/48에 같은 조건의 짧은 표준샘플을 남긴다.
- 시작 전 `괜찮음 / 조금 피곤함 / 쉰 느낌`을 선택한다.
- `CARD-18`은 일정에 배치하지 않는다. 피곤하거나 쉰 상태에서 원래 카드를 대체하는 recovery fallback으로만 사용한다.
- 쉰 느낌에는 no-voice 듣기, 리듬 tap, 가사 말하기, 호흡 표시를 완전한 학습으로 인정한다.
- 통증·호흡곤란·각혈·급격한 음역 손실 등은 즉시 중단 안내 대상이다.

## 4. 카드 구성

### 정상 경로 카드 ID 19개

- `CARD-01~05`: 정렬, 호흡, 이완, easy onset, 자기청취
- `CARD-06~10`: straw, lip trill, hum/NG, water resistance, balanced phonation
- `CARD-11~12`: self-imitation, 상대 기준선 피치 확인
- `CARD-13`: Day 1/24/48 표준샘플
- `CARD-14`: 듣고-상상하고-허밍하기. v9에서 세 번 이상 재등장한다.
- `CARD-15`: 4박 pulse 리듬 허밍
- `CARD-16`: 2–3음 contour mimic
- `CARD-17`: 한국어 모음·자음 bridge
- `TONE-02`: Hum-to-Vowel. Day 37 상세 blueprint에서 낮은/중간 prototype cue 중 하나를 고르고 허밍의 편안함을 모음으로 옮긴다.
- `TONE-03`: Vowel Color Taste. Day 38 상세 blueprint에서 같은 높이·작은 음량을 유지하며 모음만 바꾼다.

### 동적 회복 카드

- `CARD-18`: 정상 path에는 없다. 목 상태가 피곤하거나 쉰 경우 낮은 부하/SOVT-only/no-voice 루틴으로 대체할 때만 호출한다.

## 5. 표준샘플

`CARD-13`은 최대 발성 검사가 아니다.

- `/a/ /i/ /u/` 각 3초
- 표준 문장 1줄
- 작고 편한 저→고→저 글라이드
- take 1회
- 같은 기기·거리·환경을 가능한 범위에서 유지
- 점수 대신 tone/comfort tag와 A/B 재생
- 저장된 자기태그는 `내 음색 팔레트`에 누적되지만 음색 유형이나 성대 상태로 판정하지 않음

## 6. 피드백

- 피치 그래프는 기본적으로 시도 후 공개한다.
- 한 세트에는 한 가지 기준만 제시한다.
- 낮은 신뢰도 프레임은 숨긴다.
- 음색·성대 상태·과압착 유형을 자동 진단하지 않는다.
- 사용자 자기판단 후 앱 피드백을 보여준다.

## 7. 졸업 의미와 증거

초급 졸업은 가창 능력 인증이 아니라 Universal Vocal Core를 시작할 준비가 됐다는 뜻이다.

필수 기록:

1. Day 1/24/48 표준샘플
2. SOVT→모음과 Hum-to-Vowel의 짧은 전이 경험
3. 기준음 듣기→내적 상상→허밍 경험
4. 4박 pulse와 2–3음 contour 경험
5. 편한 한 음에서 모음 색채 차이를 듣고 자기태그를 남긴 경험
6. 한국어 음절 bridge 경험
7. 목 상태에 따라 회복 루틴을 선택한 기록

점수 컷으로 졸업을 막지 않는다.
