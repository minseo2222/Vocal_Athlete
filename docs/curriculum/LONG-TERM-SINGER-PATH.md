# LONG-TERM-SINGER-PATH — v9 장기 보컬 성장 경로

> V1 출시는 Beginner Foundation으로 제한한다. 장기 비전은 completion 수가 아니라 유지·전이·녹음 산출물로 성장하는 보컬 트레이닝 플랫폼이다.

```text
Beginner Foundation
48 lessons
↓
Universal Vocal Core
144 lessons = 12-day microcycle × 12
↓
Repertoire Application
72 lessons = 12-day phrase project × 6
↓
Advanced Genre Labs
40-slot repeatable project cycles
↓
Portfolio / Performance
best takes, delayed one-takes, optional expert review
```

## 단계별 역할

| 단계 | 역할 | 전이 증거 |
|---|---|---|
| Beginner | 안전한 루틴, SOVT, 자기청취, 기본 pitch/rhythm/timbre | Day 1/24/48 sample + bridge 경험 |
| Universal Core | 공통 호흡·발성·청음·리듬·음색·range·딕션·phrase | 4 formal checkpoints + retention/transfer |
| Repertoire Application | 짧은 훈련 프레이즈에 기술 적용 | 6 baseline/review project pairs |
| Advanced Genre Lab | 장르별 곡/구간 프로젝트 | 16–32마디 artifact + load/recovery log |
| Portfolio | 서로 다른 조건의 독립 녹음 | best take 3개 이상 + self-review |

## 장르 분기 원칙

장르 취향은 초급부터 관심 태그로 받을 수 있지만 실제 장르 트랙은 공통 코어와 곡 적용 훈련 뒤에 열린다. 공통 기능은 공유하되, 고급에서는 장르마다 음색·리듬·딕션·증폭 환경·레퍼토리 요구가 다르므로 별도 방법론을 사용한다.

## 고급은 무한이지만 무제한이 아니다

- 무작위 기술 피드가 아니라 한 곡/구간 프로젝트를 중심으로 한다.
- 고강도·gated 카드는 일/주간 cap, fallback, rest, HITL이 필요하다.
- 쉰 느낌에는 no-voice planning/review로 전환한다.
- 원곡 key·최대음역·최대음량을 성장 기준으로 삼지 않는다.

## 성공 문구

금지: 가수급 보장, 원곡자 복제, 음색 총점, 고음 랭킹.

권장: 확인된 기술, 완료한 프레이즈, 이전 take와 비교한 변화, 편한 key와 tone palette를 설명한다.
