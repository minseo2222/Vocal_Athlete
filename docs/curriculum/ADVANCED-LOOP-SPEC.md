# ADVANCED-LOOP-SPEC — v9 고급 장르 Lab 반복 구조

## 1. 정의

고급은 날짜 제한 없는 반복형이지만 무제한 발성 피드가 아니다. 사용자는 **한 곡/프레이즈 프로젝트**를 정하고, 필요한 기술만 골라 40-slot cycle을 반복한다.

## 2. 40-slot 공통 cycle

| Phase | slots | 목적 | 필수 산출물 |
|---|---:|---|---|
| 1 Baseline & Intent | 1–10 | 목 상태, key, text/character/tone goal, baseline take | project brief + baseline |
| 2 Skill Contrast | 11–20 | 장르 핵심 기술을 낮은 부하로 A/B | contrast takes |
| 3 Phrase Integration | 21–30 | 2–16마디에서 guide fade·반주·timing 통합 | section take |
| 4 Performance & Recovery | 31–40 | limited one-take, review, deload, 다음 cycle 계획 | portfolio candidate + recovery log |

40 slots는 `[D-D]` 제품 단위다. 사용자는 no-voice day와 휴식으로 캘린더 기간을 늘릴 수 있다.

## 3. cycle 상승 규칙

한 cycle에서 다음 중 **하나만** 올린다.

- phrase length
- range/tessitura
- tempo/rhythmic density
- accompaniment density
- text/acting complexity
- stylistic contrast

고음·음량·belt intensity를 자동 상승 변수로 두지 않는다.

## 4. 프로젝트 중심 운영

고급 홈은 “오늘의 랜덤 기술”보다 다음을 중심으로 보여준다.

`project → target section → primary skill → load budget → last best take → next cue`

## 5. 안전

- 정상 cycle에 `CARD-18`을 배치하지 않고 voice-state override로만 recovery를 호출한다.

- traffic-light voice state override
- daily/weekly load cap
- max take count
- high-risk fallback
- required rest
- HITL signoff
- persistent symptoms referral

## 6. 졸업 대신 cycle 산출물

고급에는 최종 완주가 없다. 각 cycle은 baseline, one section/full take, self-review, delayed transfer, recovery log를 남긴다. 여러 cycle의 best take가 Portfolio Mode로 이동한다.
