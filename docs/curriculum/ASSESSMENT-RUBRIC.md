# 보컬 학습 평가 루브릭 — v9

## 1. 목적

평가는 단일 “가수 점수”를 만드는 기능이 아니다.

- 시간이 지난 뒤 유지되는지
- 조건이 바뀌어도 전이되는지
- 사용자가 자기 녹음에서 한 가지 수정 목표를 선택할 수 있는지
- 목 상태에 따라 부하를 안전하게 조절하는지

일일 진도는 completion 기반이며, checkpoint와 포트폴리오는 녹음 산출물을 사용한다.

## 2. 증거 계층

| 증거 | 의미 | 예시 |
|---|---|---|
| E0 | 레슨 완료 | daily completion |
| E1 | 모델·cue와 즉시 수행 | guide와 3음 contour |
| E2 | 지연 유지 | 다음 microcycle에서 no-overlay 재현 |
| E3 | 근접 전이 | 새 모음·시작음·tempo·key |
| E4 | 프레이즈 적용 | 2–8마디 take |
| E5 | 독립 산출물 | 도움을 최소화한 one-take |

`mastered`라는 표현은 최소 E2 이상에서만 고려한다. 장르 인증은 E4–E5를 요구한다.

## 3. 영역별 루브릭

각 영역은 `관찰 / 부분 재현 / 안정 재현 / 독립 전이`로 기록하며 총점으로 합산하지 않는다.

| 영역 | 자동 보조 | 자기/사람 판단 |
|---|---|---|
| Pitch & Ear | F0, contour, 신뢰도 | 음악적으로 허용되는 변형 |
| Rhythm & Time | entry, beat offset, drift | groove·의도적 placement |
| Breath/Phrase | duration, voiced segment | effort, phrase landing |
| Phonation | onset 경향 | 편안함·strain 느낌 |
| Timbre/Vowel | 동일 조건의 A/B trend | 목표 tone의 미학·재현성 |
| Range/Key | F0 범위 | usable key와 무리감 |
| Diction | 음절·자음 timing 보조 | 실제 가사 전달력 |
| Phrase/Expression | 제한적 | 의미, arc, 서사 |
| Recording/Mic | clipping, noise, duration | best take 선택 |
| Safety | load log, voice-state choice | 통증·피로·중단 판단 |

## 4. 단계별 증거

### Beginner Foundation

- Day 1/24/48 짧은 표준샘플
- SOVT→모음 경험
- 4박 pulse와 짧은 contour
- 청음→내적 상상→허밍
- 회복 모드 선택 기록

### Universal Vocal Core

정식 `UC-17` checkpoint는 Day 36/72/108/144에만 있다.

- pitch memory + 새 시작음
- subdivision/rest entry
- SOVT→가사
- vowel/tone A/B
- usable range/key fit
- 한국어 neutral phrase
- 모델 없는 `UC-25` 자기 코칭 재시도

각 12일 microcycle의 `UC-25`는 학습용 retrieval이며 정식 인증 checkpoint가 아니다.

### Repertoire Application

여섯 개 12일 프로젝트마다 다음을 남긴다.

- `RA-09` whole-phrase baseline
- local scaffold 기록
- `RA-08` best take
- `RA-10` delayed retrieval/transfer

최소 한 프로젝트는 guide 없는 take, 최소 한 프로젝트는 key 또는 tempo 전이를 포함한다.

### Advanced Genre Lab

- 장르별 16–32마디 project artifact
- 곡 목표와 연결된 기술 로그
- 부하 cap·rest 준수
- 장르 루브릭과 recovery log

### Portfolio

- 서로 다른 곡/조건의 best take 3개 이상
- before/after sample
- tone palette reference
- usable range/key profile
- 자기평가와 선택형 전문가 리뷰

## 5. 피드백 규칙

- 한 take의 우선 수정 목표는 하나다.
- 사용자 자기판단을 먼저 받는다.
- 자동 피드백은 측정 가능한 결과만 표현한다.
- 낮은 신뢰도 프레임은 판단에서 제외한다.
- 실패는 영구 차단이 아니라 review prescription을 만든다.
- “과압착형”, “음색 78점”, “가수급 합격” 같은 진단·총점·정체성 라벨은 금지한다.

## 6. 검증 계획

1. 교사 2인 이상의 독립 평가로 문항 정의를 조정한다.
2. 사용자 self-rating과 교사 rating의 불일치를 분석한다.
3. F0/timing은 Android 기기별 오차를 검증한다.
4. checkpoint 간격과 transfer 조건은 파일럿으로 조정한다.
5. 레벨 문구는 능력 보장이 아니라 확인된 산출물을 설명한다.
