# SINGER-LEVEL-OUTCOMES — 가수형 성장 결과 정의

## 1. 목표 정의

본 프로젝트의 장기 목표는 사용자를 “앱만으로 즉시 가수처럼 만드는 것”이 아니라, 초급자도 장기 경로를 끝까지 따라가면 **안전한 발성, 음정·박자, 음색 조절, 곡 적용, 녹음 수행까지 갖춘 준가수형 사용자**가 되도록 설계하는 것이다.

## 2. 레벨 체계

| 레벨 | 명칭 | 핵심 결과 |
|---|---|---|
| Level 1 | Safe Beginner | 48일 초급 Foundation 완주. 목 상태를 보고 light-mode를 고를 수 있음. |
| Level 2 | Universal Core Starter | 중급 초반. 호흡·onset·SOVT 전이를 짧은 phrase로 연결. |
| Level 3 | Pitch & Time Stable | 단일음, 2–3음 contour, 4박 pulse, 간단한 반주 진입 가능. |
| Level 4 | Timbre Controller | 밝음/따뜻함/clear/speech-like 톤을 낮은 부하에서 A/B 비교하고 재현. |
| Level 5 | Song Ready | 장르 중립 4마디 phrase를 말하기→허밍→모음→가사→반주로 전이. |
| Level 6 | Genre Performer | 고급 장르 Lab에서 장르별 phrase, tone, diction, mic/recording 수행. |
| Level 7 | Portfolio Singer | 여러 take를 비교하고 3곡 이상 포트폴리오 산출. |

## 3. 졸업 기준의 3층 구조

1. **Completion** — 레슨을 끝냈다.
2. **Skill Check** — 짧은 과제를 낮은 부하로 수행했다.
3. **Performance Check** — 실제 phrase/녹음에서 적용했다.

해금은 completion 기반을 유지한다. 다만 장기 성장 리포트와 고급 인증은 skill/performance check를 함께 본다.

## 4. 음색 관련 결과

- 초급: 내 소리를 녹음하고 tone tag를 선택할 수 있다.
- 중급: 같은 음/문장을 bright/warm/clear/speech-like로 낮은 부하에서 비교할 수 있다.
- Repertoire Application: 같은 4마디를 2–3가지 tone으로 녹음하고 선호 take를 고른다.
- 고급: 장르별 tone preset을 안전 cap 안에서 반복하고 portfolio take에 적용한다.

## 5. 평가에서 금지하는 것

- 성대 건강 자동 진단.
- 음색 점수로 우열 판정.
- 유명 가수 매칭률.
- 고음/음량/긴 sustain 랭킹.
- 통증·쉰 목소리 상태에서 streak 압박.


## v9 evidence requirement

- Level 상승은 daily completion 수만으로 인증하지 않는다.
- Foundation은 Day 1/24/48, Universal Core는 Day 36/72/108/144 formal checkpoint와 microcycle retrieval, Repertoire Application은 6개 project baseline/review pair, Advanced는 16–32마디 project artifact, Portfolio는 서로 다른 best take 3개 이상을 권장 증거로 사용한다.
- 단일 가수 점수 대신 pitch, rhythm, breath, phonation, timbre, diction, phrase, expression, recording, safety의 영역별 증거를 보여준다.
