# PORTFOLIO-SPEC — v8 보컬 포트폴리오·수행 모드

## 1. 목적

“레슨을 끝냈다”가 아니라 **다른 조건에서도 재현 가능한 노래 산출물이 좋아졌다**를 보여준다. 공개 랭킹이나 의료 인증이 아니다.

## 2. 평가 구조

### 공통 rubric

| 영역 | 관찰 대상 | 자동화 범위 |
|---|---|---|
| Pitch | 시작음, 음정 방향, 안정 구간 | F0 신뢰 구간만 |
| Rhythm | entry, 음가, 쉼표, tempo drift | 국소 timing |
| Breath | phrase 완결과 끝 밀림 | 사용자/전문가 review 중심 |
| Phonation | 시작·지속의 편안함과 재현 | 자동 원인 진단 금지 |
| Timbre | 목표 tone 선택과 반복성 | tone tag + A/B |
| Diction | 모음 유지·자음 timing·가사 회수 | 국소 timing/self review |
| Phrase | arc, breath placement, section continuity | rubric |
| Expression | text intention·contrast | 자기/전문가 평가 |
| Recording | clipping, noise, mic consistency | 기술적 자동 피드백 |
| Safety | effort, next-day change, recovery choice | 자기보고 + gate |

### 장르 rubric

공통 rubric 위에 장르별 3–5개 항목을 추가한다. 예: 가요 mic delivery, 뮤지컬 text action, 성악 legato/diction, R&B groove/melisma, Rock dense-mix clarity, Worship repeated-chorus recovery.

단일 총점은 기본 UI에 표시하지 않는다.

## 3. 레벨 산출물

| Level | 필수 artifact |
|---|---|
| Foundation | Day 1/24/48 sample + 안전 루틴 기록 |
| Universal Core | 8-domain checkpoint set + delayed neutral phrase |
| Repertoire Ready | Map/Recall/Transfer phrase set |
| Genre Performer | 16–32마디 또는 장르 equivalent + recovery log |
| Portfolio Singer | best take 3개, before/after, tone palette, range/key map, 자기평가 |

## 4. one-take 정의

one-take는 완벽한 한 번이 아니라, 정해진 load cap 안에서 멈추지 않고 수행한 지정 구간이다. 장르·수준에 따라 4마디, 16마디, 1절, full song 중 하나를 쓴다. 반복 횟수 상한을 넘겨 완성도를 올리는 방식은 금지한다.

## 5. 인증

- 자동 시스템: 측정 가능한 국소 결과와 기술 품질만.
- 사용자: 목표, 편안함, 전달력, 다음 cue.
- 전문가: 고위험 기술, 장르 미학, 최종 포트폴리오 선택형 review.

“가수급 보장”, “성대 건강 인증”, “전문가와 동등” 문구를 금지한다.
