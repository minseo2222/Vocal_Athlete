# Teacher Guide Pedagogy Review Checklist

## Performance

- [ ] low and middle options are used instead of gender labels;
- [ ] example stays in a conservative range and moderate-soft intensity;
- [ ] onset is easy and neutral;
- [ ] vowel opening does not add obvious pressure or volume;
- [ ] no high-risk technique is demonstrated;
- [ ] exact-pitch imitation is not required;
- [ ] anti-patterns are explained rather than imitated by the learner.

## Instruction

- [ ] one primary learning goal;
- [ ] one changed condition at most;
- [ ] learner attempt cap is stated;
- [ ] no-voice recovery alternative is stated;
- [ ] stop signals are clear;
- [ ] tone tags are presented as self-reports, not AI judgments;
- [ ] no medical, diagnostic, or guaranteed-effect language.

## Release evidence

- [ ] performer consent complete;
- [ ] rights record complete;
- [ ] reviewer name/ID and date recorded;
- [ ] final file hash recorded;
- [ ] Android and iOS playback smoke test complete;
- [ ] beginner comprehension pilot reviewed.
