# Teacher Guide Preparation Pack — v18

This package prepares the first timbre vertical slice for human-teacher recording. It does **not** approve the current synthetic cues for release and does not unlock high-risk techniques.

## Covered lessons

- Beginner Day 37 — `TONE-02` Hum-to-Vowel Basic
- Beginner Day 38 — `TONE-03` Vowel Color Taste
- Universal Core Cycle 1 Day 6 — `TONE-02` retained transfer

## Required release sequence

1. script review;
2. performer consent and rights assignment;
3. teacher recording using low and middle reference options, not gender labels;
4. vocal-pedagogy safety review;
5. editing and loudness/clipping QA;
6. `rights.json` completion;
7. SHA-256 manifest regeneration;
8. Android/iOS playback smoke test;
9. beginner comprehension pilot.

## Prohibited demonstrations

- belt or pushed high mix;
- pressed onset presented as a task to imitate;
- strong twang;
- rasp, growl, scream, distortion;
- maximum-range or maximum-volume targets;
- medical claims or vocal-health scoring.

Peak normalization and a clean waveform do not prove a safe sound-pressure level on every device. Release review must therefore combine file QA, conservative playback copy, device testing, and user volume control.
