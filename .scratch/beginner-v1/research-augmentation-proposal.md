# 초급 커리큘럼 — 외부 리서치 기반 미세 보강 제안서

> 상태: **제안(미적용)** · 입력: 보컬 발성 외부 리서치(SOVT/Titze, appoggio/Miller, Estill·CVT, passaggio formant tuning, messa di voce, twang/AES)
> 적용 전 **발성안전 HITL 검토 필수**(cards.md §검토 요청 절차). 본 문서는 canonical 커리큘럼을 수정하지 않는다.
> 준거: ADR-0002(무납득) · ADR-0005(초급 범위 분할) · ADR-0006(blocked→variable) · ADR-0015(Card 스키마) · issue 26(변주 엔진, done)

---

## 결정 로그

- **P1 = (b) 채택** — 빨대 **5–6mm 유지** + cue에 오용 차단 한 줄 추가 `"가는 빨대 ❌(굵은 5–6mm)"`. *운동 지시*라 무납득 위반 아님. **상태: HITL 검토 대기**(cards.md 미수정).
- **P3 = 보류** — cue 문구 변주 축 신설은 범위확장이라 별건. 필요 시 추후 이슈화.
- **P2 = 변경 없음** — 안전 중단 cue 갭 없음(외부 검증 기록).
- 후속 후보: 중급 코어 갭 분석(messa di voce·공간↔트왱 다이얼·periodization).

> 되돌리기 쉬움: 본 문서는 제안일 뿐 canonical 카드 미수정. P1을 (a) 순수 무변경 또는 (c) 중급 이관으로 바꾸려면 한마디면 됨.

## 0. 요약 (정직한 결론)

초급은 이미 잘 범위가 잡혀 있어 **외부 리서치가 추가할 여지가 매우 적다.** 조사 자료의 대부분(Appoggio 정교화·포먼트튜닝·트왱/핀치택·passaggio·고음·placement)은 **ADR-0005/§8에 의해 초급 OUT**이며, 이미 *중급 코어* 또는 *장르 분기*에 매핑돼 있다(연구는 그 설계를 외부 출처로 검증해준 셈).

따라서 본 제안은 **신규 기법 0개**. 실질 항목 3개이며, 그중 2개는 "변경"이 아니라 **설계 결정 확인**이다.

| # | 항목 | 성격 | 스키마/코드 영향 |
|---|---|---|---|
| P1 | 빨대 지름(3.5mm vs 5–6mm) | **결정 확인** | 없음(결정에 따라 cue 1줄) |
| P2 | 안전 중단 cue 완전성 재확인 | **검증(갭 없음)** | 없음 |
| P3 | 기존 카드 cue 표현 변주(선택) | **선택·범위확장 주의** | 변주 축 신설(기능 변경) |

## 1. 준수해야 할 제약 (체크리스트)

- [ ] **무납득(ADR-0002)**: cue는 *과제를 정의하는 운동 지시*만. "왜"(생리학적 근거) 금지. 허용 예: "이로 물지 마세요", "밝게, 크게 아님"(§3).
- [ ] **범위(ADR-0005)**: 곡·파사지오·고음·벨트·믹스·모음정밀·Appoggio정교화·placement 추가 금지.
- [ ] **고정 선형**: 경로는 변주로 갈리지 않음. 적응형 분기 없음.
- [ ] **유성 마이크로윈 ≥1 / 무성 레슨 0** 유지.
- [ ] **인-레슨 피드백 비차단 · 시각 전용 · 저신뢰 수치 비표시** 유지.
- [ ] 실제 cards.md 수정 전 **발성안전 HITL** 통과.

## 2. P1 — 빨대 지름 결정 확인 (CARD-06)

**현황**: CARD-06 = `5–6mm 빨대 /u/`.
**리서치**: Titze는 역압(inertive reactance) 최적이 **~3.5mm 얇은 빨대**라고 보고 — 발성역치압↓·충돌력↓ 효과가 더 큼.

**판단**: 이건 **오류가 아니라 트레이드오프**로 보임.
- 3.5mm = 고저항 → 효과 강하지만 초보에게 과부하·어지럼 위험↑·"이로 물기"/짜내기 유발 쉬움.
- 5–6mm = 저저항 → 초보 안전·실패율 낮음. **초급 "최소 입문 토대" 원칙과 정합.**

**제안**: 현행 5–6mm **유지 권장**. 단 소유자/HITL이 아래 중 택:
- (a) 그대로 유지(권장) — 변경 없음.
- (b) 명시 문구만 추가: cue에 `"빨대는 굵은 편(5–6mm)으로 — 가는 빨대 ❌"` (가는 빨대를 좋다고 오인해 과저항 쓰는 사용자 차단). *운동 지시*라 무납득 위반 아님.
- (c) 가는 빨대를 *중급* 고저항 변주로 이관(이미 중급 코어 P3-13 SOVT 소관 — **중급에서 다룰 일**).

> 결정 필요: **(a)/(b)/(c)?**

## 3. P2 — 안전 중단 cue 완전성 재확인 (갭 없음)

리서치(Titze SOVT 안전, breath-support 근거)를 기존 중단 cue와 대조:

| 카드 | 현행 중단 cue | 리서치상 추가 위험? |
|---|---|---|
| CARD-02 호흡 | 과호흡·어지럼 | 없음 — 충분 |
| CARD-06 빨대 | 어지럼·시야흐림·가슴통증 | 없음 — 충분 |
| CARD-09 물저항 | 천식·호흡기 이력 대체·호흡곤란·쌕쌕·어지럼 | 없음 — 충분 |

**결론**: **신규 위험 신호 없음.** 기존 안전 설계가 리서치 기준을 이미 충족함을 *확인*(= 변경 없음, 안심 근거로 기록).

---

## 4. P3 — cue 표현 변주 (선택 · 범위확장 주의)

**아이디어**: 변주 엔진(issue 26)이 같은 카드의 cue *문구*를 일자별로 교체해 신선도↑. 예(전부 과제정의 운동 지시 — 무납득 OK):
- CARD-02 호흡 대체 cue: `"촛불을 흔들리지 않을 만큼만 길게 불기"`(거리·세기 과제 정의).
- CARD-06/07 SOVT 대체 cue: `"버블/트릴이 일정한 굵기로 유지"`(이미 유사 문구 존재).

**주의(정직)**: issue 26 변주 축은 **음역·모음·글라이드·멜로디·세션위치 5축**으로 *기법 표면*만 변경한다. **cue 문구 교체는 6번째 축 신설 = 기능/스키마 변경**이지 "미세 보강"이 아니다.

**제안**: 기본 **보류**. 채택 시 별도 이슈로 분리("변주 엔진: cue 문구 축 추가")하고, 표현은 *과제정의*에 한정·rationale 금지 가드 필요.

> 결정 필요: **보류 / 별도 이슈화?**

---

## 5. 명시적 "추가 안 함" (추적용)

아래는 리서치에 나왔으나 **초급에 추가하지 않음** — 귀속처 표기:

- Appoggio 길항 정교화 → 중급 코어 §4.3
- 모음조정·포먼트튜닝·passaggio → 중급 코어 P4-09/10, P5-03/06
- 트왱/AES/핀치택 → 중급 코어 P4-12 + 뮤지컬 분기(belt)
- 싱어즈 포먼트 → 성악 분기
- 후두 높이 컨트롤 → 중급 코어 P4-07
- messa di voce / VFE 심화 → 중급 코어 P3-08~12
- "공간↔트왱 독립 다이얼", periodization/디로드 → **어느 커리큘럼에도 없음 → 중급 갭 분석 후보**(별건)
- placement 은유 → 컷(ADR-0012)
