# P4 — 졸업/전이 메시지 (transition_day 패턴)

Status: ready-for-agent

## What to build

졸업 레슨(경로 마지막 과)은 *그날 치 레슨*이므로 같은 날 다음 단계 시도 시 1일1레슨 캡에 막힌다 — 밋밋한 "이미 했음" 에러 대신 *전이 화면 메시지*로 표현(옵션1, 캡 규칙 불변, ADR-0010 보강). 프로토타입이 인코딩한 결정: 코스 전이 발생일 `transition_day` 1필드.

- 졸업 + 장르 미선택 + 오늘 소진 → "🎉 경로 완주! 오늘은 여기까지 — 장르 고르고 내일부터"
- 장르 선택한 *같은 날* 시도 → "🎉 전이 완료 — 내일 [다음 코스] 1과부터"
- 그 외 같은날 2회 → 일반 캡 메시지

## Acceptance criteria

- [ ] `transition_day == 오늘`이면 캡 메시지 대신 전이 메시지
- [ ] 졸업·장르미선택 분기 메시지 구분
- [ ] 다음날 정상 진행(유지/다음코스 1과)
- [ ] 캡 규칙 자체는 불변(ADR-0003)
- [ ] 3경로 단위테스트(졸업당일·전이당일·일반2회)
