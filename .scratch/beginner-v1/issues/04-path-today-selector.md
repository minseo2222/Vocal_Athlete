# P1 — 선형 경로 + 오늘 레슨 셀렉터

Status: ready-for-agent

## What to build

인메모리 단일 고정 선형 경로(순서 있는 레슨 ID 목록) + 현재 포인터 + "오늘의 레슨" 셀렉터. 적응형 분기 없음(ADR: 단일 고정 선형). 콘텐츠는 아직 플레이스홀더(C2에서 교체). 디버그 표면(현재 레슨 id/인덱스 표시)으로 검증 — state+최소 UI+test의 얇은 수직 절편.

## Acceptance criteria

- [ ] 순서 있는 경로 + 현재 인덱스 모델(인메모리)
- [ ] "오늘의 레슨" 셀렉터가 현재 레슨 반환
- [ ] 디버그 화면에 현재 레슨 id/인덱스 노출
- [ ] 셀렉터 단위테스트
