# U5 — 선택형 "다시?" 넛지

Status: ready-for-agent

## What to build

인-레슨 피드백이 크게 빗나갔을 때 *선택형* "다시 한 번" 넛지 1개 + 1줄 교정 팁(시트 안 인라인). **완료를 절대 막지 않음**(막지 않는 인-레슨 피드백, ADR-0002 개정). 강제 재시도 ❌, 스킵 자유.

## Acceptance criteria

- [ ] 큰 편차 시 선택형 넛지 노출(인라인)
- [ ] 넛지 무시하고 완료 가능(차단 없음)
- [ ] 강제 재시도 없음
- [ ] 편차 임계·노출 로직 테스트
