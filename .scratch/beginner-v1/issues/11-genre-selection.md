# P8 — 비구속 장르 선택

Status: ready-for-agent

## What to build

졸업 후 장르 트랙 선택(뮤지컬/성악/가요). **비구속·변경 가능** — 메뉴에서 언제든 다른 장르로(페널티 없음, ADR-0010). 선택은 이후 라우팅(해당 장르 중급 있으면 진입 / 없으면 유지 모드)을 결정하나 V1엔 중급 미존재 → 대개 유지 모드行(P9/P10).

## Acceptance criteria

- [ ] 졸업 후에만 선택 가능
- [ ] 장르 변경 가능, 변경 시 페널티 없음
- [ ] 선택이 라우팅 입력으로 기록됨
- [ ] 단위테스트(선택·재선택)
