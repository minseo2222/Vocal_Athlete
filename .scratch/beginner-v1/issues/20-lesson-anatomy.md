# U3 — 레슨 해부 (진입/본/쿨다운, 쿨다운 스킵)

Status: done

## What to build

레슨 흐름에 해부 구간 반영: 진입/워밍업 ~1–2분 → 본운동 ~7–11분 → 쿨다운 ~1–2분. 스테퍼가 현재 구간 표시, **쿨다운은 권장이나 스킵 가능**(시트 헤더 "쿨다운 건너뛰기" chip, 게이트 아님 — ADR/CURRICULUM 레슨 해부). 무성 레슨 0 원칙 유지.

## Acceptance criteria

- [ ] 진입→본→쿨다운 구간 전이, 스테퍼 동기화
- [ ] 쿨다운 스킵 chip 동작(완료/진행 막지 않음)
- [ ] 구간 전이 테스트
